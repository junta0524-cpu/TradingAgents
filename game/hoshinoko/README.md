# ホシノコ 〜星屑の郵便配達人〜

TradingAgents リポジトリとは独立したミニゲームです。Canvas + Vanilla JS + Web Audio API のみで動く単一の HTML ファイルなので、追加のビルドや依存パッケージは不要です。

## 遊び方

ブラウザで `index.html` を直接開くか、簡易サーバーを立てて開いてください。

```bash
cd game/hoshinoko
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 操作

- `← / →`（または `A / D`）: 移動
- `↑ / Space`（または `W`）: ジャンプ
- 光のかけらに触れて拾い、光っていない灯台まで運んで届ける（一度に運べるのは1個まで）
- すべての灯台に光を届けるとステージクリア。全3ステージ。

## 制作チーム（役割分担）

- **シナリオ**: 世界観・ステージ構成
- **プログラム**: Canvas 上の物理演算・当たり判定・状態管理
- **画像**: ベクター/ジオメトリベースの見た目（画像ファイル不使用）
- **音楽**: Web Audio API によるプロシージャル SE / アンビエント
- **アニメーション**: パーティクル・イージング・スクワッシュ&ストレッチ

今後、ステージ追加やギミックの拡張、見た目やサウンドのブラッシュアップを重ねていく想定です。

## デバッグ

`index.html?debug=1` で開くと `window.__hoshinoko`（プレイヤーの座標・速度・ステージ番号など）がコンソールから参照できます。動作確認・調整用のフックです。

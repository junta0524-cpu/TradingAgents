# ホシノコ 〜星屑の郵便配達人〜

TradingAgents リポジトリとは独立したミニゲームです。Canvas + Vanilla JS + Web Audio API のみで動く単一の HTML ファイルなので、追加のビルドや依存パッケージは不要です。

## 遊び方

ブラウザで `index.html` を直接開くか、簡易サーバーを立てて開いてください。

```bash
cd game/hoshinoko
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## ゲームの流れ

タイトル → **灯台からの依頼**（星の一覧・ハブ画面） → 依頼内容の確認 → ステージ攻略 → 想いの欠片（報酬）を受け取る → ハブへ戻る、を繰り返して全3章を巡るクエスト形式です。

- ハブ画面で挑む星を選ぶ（未クリアの章をクリアすると次の星が解放される）
- 星ごとに短い依頼の言葉（しじまに沈んだ星の訴え）が表示される
- ステージをクリアすると「想いの欠片」という名前つきの報酬を受け取る
- 全3章をクリアするとエンディングで集めた想いの一覧が表示される

## 操作

- `← / →`（または `A / D`）: 移動 / ハブ画面ではクエスト選択
- `↑ / Space`（または `W`）: ジャンプ / 決定（依頼を受ける・報酬を受け取る・タイトルやリザルトの先送り）
- 光のかけらに触れて拾い、光っていない灯台まで運んで届ける（一度に運べるのは1個まで）
- すべての灯台に光を届けるとステージクリア
- 右上の ↺ ボタンはハブ・タイトル・リザルトでは「最初からやり直す」、ステージ攻略中は「ひきかえす」（そのステージを中断してハブへ戻る。他章の進行には影響しない）

## 世界観

星は誰かを想う気持ちが結晶になったもの。**しじま**と呼ばれる現象によって思い出されなくなった星は光を失って眠ってしまう。主人公ホシノコは生まれきれなかった半端な光のかけらで、他の星の光を運んで届ける「郵便配達人」を自任している——という設定です。詳しい章立てやキャラクター設定は開発時のやり取りを参照してください。

## 制作チーム（役割分担）

- **シナリオ**: 世界観・章立て・依頼と報酬の文章
- **プログラム**: Canvas 上の物理演算・当たり判定・状態管理（ハブ／依頼／攻略／報酬の画面遷移）
- **画像**: ベクター/ジオメトリベースの見た目（画像ファイル不使用）
- **音楽**: Web Audio API によるプロシージャル SE / アンビエント
- **アニメーション**: パーティクル・イージング・スクワッシュ&ストレッチ

今後、章の追加やサブキャラクター、隠し要素などでさらにブラッシュアップしていく想定です。

## デバッグ

`index.html?debug=1` で開くと `window.__hoshinoko`（プレイヤーの座標・速度・現在の章・選択中のクエスト・クリア状況など）がコンソールから参照できます。動作確認・調整用のフックです。

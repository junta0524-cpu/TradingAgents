# CLAUDE.md — 魔王が仲間になりたそうな顔でこちらを見ている（ゲーム版・統一版）

ゲーム版の資料（CLAUDE.md・characters.js・maps.js）を、今のゲームに合わせて書き直したもの。
ユーザーの決定で「ボリュームのある方（今のゲーム＝小説の本文 約27.5万字を使った、第一章〜第十二章・エピローグ・クリア後）」に統一した。
資料にあって今のゲームと食い違わないもの（大穴での両世界の行き来、レベル上限99、地名の由来）は、ゲームのほうに取り入れた。

## プロジェクト概要

- **タイトル**：魔王が仲間になりたそうな顔でこちらを見ている
- **ジャンル**：コマンド式RPG
- **物語の軸**：プレイヤーは善良な魔王ベルイザナとして、オオナムチが「名を呼ぶ者」になるまでを見守る
- **原作**：同名の小説（`docs/novel/`）。セリフは小説からそのまま取る
- **仕様**：`docs/仕様書.md`

## 技術スタック

- HTML5 Canvas ＋ JavaScript（ライブラリなし）
- `index.html` をダブルクリックで開くだけで動く（`type="module"`・`fetch()` を使わない）
- セーブは `localStorage`（読み書きは try/catch で囲む）
- 絵はすべてプログラムで描いたドット絵。音も Web Audio で鳴らす（外部の素材なし）

## ゲームのルール

### ゲームオーバー

- **ベル以外の仲間が倒れたら、ゲームオーバー**（臨時の仲間も含む）
- 一番新しい記録に戻る
- ベルは倒れない（体力は1で止まる）。仲間への致命の一撃を、1戦に1度だけ止める

### 力の体系「言霊」（5系統・全54個）

| 神 | 系統 | 例 |
|---|---|---|
| オオヤマツミ（山） | 守護・強化 | 堅め、心鎮め、岩戸 |
| ホノカグツチ（火） | 攻撃 | 火種、火焔、雷 |
| イザナギ（生） | 回復・蘇生 | 癒やし、生き返し |
| ツクヨミ（月） | 幻惑・封印・見破り | 見破り、先読み |
| アメノミナカヌシ（和） | 調和 | 調和の光、まことの名 |

- 名の剥奪には、名呼び（12章でオオナムチが覚える）で対抗する

### 四すくみ（11章で教わる）

- 鬼族 → 嵐狼族 → 土蜘蛛族 → 鴉族 → 鬼族（左が右に強い）
- オオナムチは最後に唱えた言霊の系統で「構え」が決まる（山＝土蜘蛛、火＝鬼、生＝鴉、月＝嵐狼）
- 構えが敵に強ければ1.5倍、弱ければ0.75倍（受けるときも同じ）

### ベルの手加減（第四〜九章）

| しくみ | 内容 |
|---|---|
| 冒険者ベルの強さ | その章の推奨レベル＋10のオオナムチと同じ（下の表） |
| 阻害ゲージ | ベルが言霊・本気・致命傷の阻止を使うと減る。ゼロで正体が露見 |
| 作戦 | ベルは最初「うまくやって」。自分からは力を使わず、打撃だけ |

- 第一〜三章：魔王の姿で全力。こうげきは敵全体へ2回
- 第十章から先：魔王の姿に戻る。修行とアマツ王戦は、オオナムチが一人で戦い、ベルは見守る

## フィールドマップ

- 人間界と魔界。どちらも横32×縦22マス、1マスが一つの土地（ユーザーの地図のとおり）
- 物語の町は小説の名前で置き、その章から入れる。ほかの地名はユーザーの地図の名前で、立つと名前と由来が出る
- 人間界：ミナモ（4章〜）、ひなた野（4章・野犬戦のあと）、聖の森（5章〜）、炉ヶ岳（6章〜）、獣ノ原（7章〜）、天津京（8章〜）
- 魔界：11章とクリア後だけ、土蜘蛛族の畑の南から出られる。黄泉津の宮・魔界の市場・土蜘蛛族の畑・角ヶ原・嵐ヶ峰
- 大穴：クリア後だけ、人間界[16,10] ⇔ 魔界[15,10] を行き来できる
- 敵は章ごとに、その土地の敵が出る。道と町の上では出ない

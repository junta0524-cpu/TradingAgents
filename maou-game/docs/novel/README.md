## 小説とゲームをそろえるときの決まり
- 小説か場面を直すときは、同じ文を両方で直す。`python3 tools/novel_to_scene.py`（寄り道・前日譚・名の欠片・番外編）と `python3 tools/apply_plus_to_game.py`（本編の加筆）で場面に反映し、`python3 tools/build_novel_site.py` で小説サイトを作り直す。
- すでに起きたことは、あとの話で「初めて起きる」ように書かない（例：十四の名は番外編五で石に刻まれた。名の欠片が戻ったのは番外編三）。

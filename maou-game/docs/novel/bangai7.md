# **番外編七　名の帳**

# **一**

春の朝、やすらぎの院の門は、開け放たれていた。

白い塀の内側の花壇は、半年のあいだに、ずいぶん、乱れていた。刈り込まれて揃っていた花が、思い思いの高さに伸び、思い思いの向きに咲いている。風が吹くたびに、花々は、ばらばらに揺れた。

ベルは、門の前で、足を止めた。

懐の奥に、手を当てる。擦り切れた小さな帳面の感触が、掌に伝わった。

「ベルさん」

隣で、オオナムチが、小さく声をかけた。

「入りましょう。シロエさんが、待っています」

「……ああ」

二人は、門をくぐった。

玄関の扉が、内側から開いた。

「お待ちしておりました」

出てきたのは、指の曲がった男だった。痩せた頬に、無精髭はもうない。丁寧に剃られた顎の線が、少し、照れくさそうに、ひきつっていた。

「シロエだ」

男は、深く、頭を下げた。

「書記の仕事に、戻りました。院の者たちの、名を、写しております」

「名を」

「はい。ここにいた人たちの、名を」

男は、廊下の奥を、手で示した。

「どうぞ。大広間へ」

# **二**

大広間には、長い机が、いくつも並んでいた。

机の上には、白い紙の束と、墨と筆。紙には、名前が、びっしりと、書き込まれている。

「ヨシ」

「タケゾウ」

「フミ」

「オチカ」

小さな声が、あちこちから、聞こえた。机に向かった元・入所者たちが、一人ずつ、自分の名前を、紙に書き入れているのだった。字は、震えていた。それでも、一画ずつ、確かめるように、筆を運んでいた。

「ここは」

オオナムチが、感嘆の声を漏らした。

「名を、取り戻す場所に、なったんですね」

「そうです」

シロエは、頷いた。

「院が閉じられたあと、ここを、名簿の場にしました。名を忘れた人は、ここで、思い出せる限りの名を、書きます。思い出せなければ、周りの人が、呼んで、書きます」

「呼ぶ」

「はい。呼ばれて、頷いた名を、書くのです」

シロエは、机の列の間を、ゆっくり歩いた。

「千を超える名が、集まりました。けれど、まだ、足りません」

「足りない」

「この国には、名を、削られた人が、もっと、大勢いるはずです。院に入らなかった人。街に残った人。村に帰れなかった人。その人たちの名は、まだ、どこにも、ありません」

シロエは、足を止めて、ベルを見た。

「だから、お願いがあります」

「聞こう」

「あなたの、帳面を、写させてください」

# **三**

ベルは、すぐには、答えなかった。

懐から、帳面を取り出した。擦り切れた表紙。端は丸まり、紙は、手の脂で、黄ばんでいる。

「これは」

「先代の頃の、宮の書庫で、拾った」

「拾った」

「ある夜、昔話を読んだ帰りに。白紙だった。何も書かずに、持ち帰った」

ベルは、表紙を、指でなぞった。

「そこに、名を、書くようになった。最初は、宮の者の名。次に、魔界の者の名。人間界に渡ってからは、出会った人の名」

「拝見しても、いいですか」

「ああ」

シロエは、手袋を外した。曲がった指で、そっと、表紙をめくる。

最初の頁に、細い、角ばった字が並んでいた。

『オモイカ　参謀。灰色の目。帳面の端を折る癖』

『ハニヤス　土蜘蛛。畑番。甘いものを、素直に喜ばない』

『ミカヅチ　鬼族の頭領。笑うと、腹が揺れる』

頁をめくるたびに、名前が、増えていく。

『トマリ　ミナモの荷運び。よく喋る』

『アサギ　網元の娘。網を編む手が、速い』

『イサナ　老いた漁師。薄い。呼ぶと、輪郭が戻る』

「……」

シロエは、頁を繰る手を、止めた。

「これは」

声が、掠れていた。

「顔と、癖と、好きなものまで。一人ずつ」

「覚えるために、書いた」

「覚えるために」

「忘れてしまう前に」

ベルは、低く言った。

「名は、呼ばれなければ、薄くなる。呼ぶためには、覚えていなければならない。覚えるには、書き留めるのが、いちばんだった」

シロエは、帳面を、しばらく、見つめていた。それから、静かに、言った。

「これが、名簿の、最初の頁になります」

# **四**

帳面を写す作業は、三日かかった。

大広間の長机の端で、シロエとコトシロが、並んで筆を動かした。コトシロは、軍務局の制服を脱いで、薄い麻の上着で、袖をまくっていた。

「ベル殿の字は、読みにくいですな」

「悪かったな」

「いえ。検品官の目で見れば、癖が分かります。ここの払いは、イサナ殿。ここは、アサギ殿」

「字で、分かるのか」

「名前の書き癖には、書いた人の気持ちが、出ます」

コトシロは、小さく笑った。自分の机の引き出しから、すり切れた古い帳面を、一冊、取り出す。

「私にも、あります。二十年かけて、鍛冶の名を書き溜めました」

「ああ。それも、写そう」

シロエが、静かに、言った。

「二冊を、並べれば、名簿に、厚みが出ます」

机の上で、二つの帳面が、並べられた。一つは、鉄の名。一つは、人の名。違う手が、違う時に、違う場所で、書き留めた名前たち。

それが、一枚の紙の上で、ひとつながりの列になっていく。

オオナムチは、その様子を、少し離れた窓辺から、見ていた。

窓の外で、花壇の花が、ばらばらに揺れていた。

(いい光景だ)

そう思った。名を呼ぶことが、こんなふうに、静かな、手仕事になる日が、来るとは。

「オオナムチ殿」

背後から、声がした。

振り向くと、痩せた男が、立っていた。三十代の半ば。以前は、頬がこけ、目が虚ろだった。いまは、頬に、ほんのり、血色が戻っている。

「ヒナの、お父さん」

「そう呼んでもらえると、嬉しい」

男は、はにかむように、笑った。

「娘と妻は、王都の家で、元気にしています。娘は、毎朝、鉢に水をやるのを、まだ、やめません」

「花は、咲きましたからね」

「ええ。白い、小さな花が」

男の目が、潤んだ。

「あの花を見るたびに、思うのです。私は、娘に、名を呼んでもらえた。それが、どれほど、ありがたいことか」

男は、机のほうへ、視線を向けた。

「だから、今度は、私が、誰かの名を、呼びたい。私は、字を、書くのが、得意でした。先生と呼ばれた頃は、子どもたちに、字を教えていた」

「先生」

「だから、私に、名を、書かせてほしい。ここにいる、一人ずつの名を」

# **五**

その夜、閉館のあと、大広間には、ベルとオオナムチだけが、残っていた。

机の上には、写し終えた名簿が、積み上げられている。千二百の名。それぞれの名の隣に、小さな字で、顔や癖が、書き添えられていた。

「ベルさん」

オオナムチが、静かに、言った。

「この名簿に、ひとつ、足りない名があります」

「足りない」

「ベルさんの名前です」

ベルは、黙った。

「帳面に、書いてませんでしたよね。ほかの人の名は、全部」

「……」

「俺、気づいたんです。ベルさんは、いつも、誰かの名を、覚える側で。自分の名を、書いてもらう側には、立たなかった」

ベルは、長い間、何も言わなかった。

窓の外で、夜風が、花壇の花を、揺らしていた。

「私の名は」

ようやく、口を開いた。

「ベルと、ベルイザナの、二つがある。どちらも、私の名だ。だが、どちらも、自分で、選んだものではない」

「そうでしたか」

「偽りの名は、人の世に入るために、自分でつけた。まことの名は、生まれたときに、与えられた。いつからか、どちらにも、馴染めなくなった」

ベルは、自分の掌を、見つめた。

「私は、誰に、名を、呼ばれたい」

「俺が、呼びます」

オオナムチは、即答した。

「ベルさん。ベル。ベルイザナ。どれでも、呼びます。ベルさんが、一番、落ち着く名で」

ベルは、顔を上げた。灰色の瞳の奥に、紅が、かすかに揺れていた。

「……ありがとう」

そのとき、広間の扉が、静かに開いた。

ヒナの父が、立っていた。手に、筆を持っている。

「失礼します。ベル殿」

「何か」

「名簿の、最後の頁に、書いておきたいことが」

男は、机の前に、膝をついた。白い紙を、一枚、広げる。筆先を、墨に浸した。

「あなたの名を、私に、書かせてください」

ベルは、息を止めた。

「私は、字を、書く者です。名を、書くことは、祈りに近い。あなたの名を、あなたの代わりに、書いて、よろしいですか」

「……」

「書かれた名は、呼ばれるために、そこに、あります」

ベルは、ゆっくりと、頷いた。

筆が、動いた。

迷いのない、まっすぐな線だった。一画、一画、丁寧に。

『ベルイザナ』

その隣に、少し、小さな字で、もうひとつ。

『ベル』

そして、その下に、短く、添えられた。

『名を覚える者。名を呼ばれる者』

ベルは、紙を、じっと、見つめていた。

「それで、よろしいですか」

「……ああ」

声が、かすれた。

「それで、いい」

# **六**

朝、院の門の前に、長い列ができていた。

近隣の村から来た人。街から来た人。遠い魔界から、鴉族に運ばれて来た人。名を忘れた人。名を呼ばれなくなった人。名を呼びたい人。

列の先頭に、小さな少女が、立っていた。

両手に、素焼きの鉢を、抱えている。鉢の中で、小さな白い花が、ひとつ、咲いていた。隣で、父が、少女の肩に、そっと手を置いている。後ろで、ミオが、涙を拭きながら、二人を見守っていた。

「お父さん」

「ああ」

「私も、名簿に、書いてもらっていい?」

「もちろんだ。おまえの名は、父さんが、いちばん最初に、書きたい」

「ううん。ベルさんに、呼んでほしいの」

少女は、鉢を抱えたまま、まっすぐ、前を見た。

シロエが、大広間の入口に、立っていた。机の端に、新しい帳面が、一冊、置かれている。白い表紙に、まだ何も書かれていない。

「ベル殿」

「何だ」

「この帳面に、名簿の題を、お書きください」

ベルは、筆を取った。

しばらく、考えた。それから、表紙の中央に、ゆっくりと、書いた。

『名の帳』

「よい題です」

シロエは、深く、頭を下げた。

「では、最初の一人を、お呼びください」

ベルは、門のほうを、見た。

列の先頭で、鉢を抱えた少女が、父の手を握って、こちらを見ていた。花が、風に、ふわりと揺れた。

ベルは、口を開いた。

「ヒナ」

少女の顔が、ぱっと、明るくなった。

「はい」

その返事が、春の朝の空気に、澄んで、響いた。

シロエの筆が、白い紙の上に、最初の名を、記した。

『ヒナ』

そして、次の人が、前に進み出た。

名を、呼ぶ声が、また、ひとつ、重なった。

門の外では、花々が、ばらばらに、思い思いの向きで、風に揺れていた。

誰かが、列の後ろで、小さく笑った。

誰かが、手を、握り合った。

名を、呼ぶ者と、呼ばれる者のあいだに、細い、細い、糸が、一本ずつ、結ばれていく。

その糸は、のちに、国じゅうに、広がっていくことになる。

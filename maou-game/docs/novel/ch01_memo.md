# 第一章（口調改訂版）　改訂メモ（ユーザー提供・原文）

直した台詞は5か所です。「すまぬ」「誇ってよい泥だ」「教えてくれて、感謝する」「感謝する。まだ、成ると決まったわけではないが」、ハニヤスへの指示（「守れるなら守ってほしい。無理なら、命を第一にせよ」「四天王を呼べ。〜来いと伝えよ」）です。

市場の「噂は何だ」は「噂とは」に直し、ハニヤスへの返事は「はい」から「おう」に変えました（対等な信頼関係のため）。

ベルの台詞は短く言い切る形にそろえ、礼節は保っています。他の人物の台詞と地の文は変えていません。

確認したい点
- 「私」は維持し、語尾を「〜ぬ」「〜せよ」に寄せました。武骨さが足りなければ、「俺」への変更や、さらに短い言い切りにできます。
- 薄すぎる、強すぎる、など手触りを教えてください。

# **第二章　静かなる迎撃**

# **一**

道は、焼けていた。

根の洲の丘陵は、三日前までは緑だったらしい。今は黒い土と、骨のように立つ木の幹ばかりが続いている。先頭の隊列は、その上を整然と進んでいた。足並みは乱れない。誰も口を利かない。口を利く必要がなかった。

兵は歩きながら、懐の紙の感触を確かめた。娘への手紙だ。書きかけのまま、三日、書き足せずにいる。

『戦が終われば、英雄の凱旋で街が祝うそうだ。おまえにも土産を』

そこまで書いて、止まっていた。次の言葉が出てこない。自分の言葉が、どこかで途切れているような気がした。

「正義は我らにあり」

誰かが小さく呟き、周りが頷いた。兵も頷いた。その言葉は、胸のどこかにすっと収まる。昔から自分の考えだったように。

魔族は、話の通じない者たちだ。だから、これは仕方がない。王様がそう仰った。

焼けた地には、小さな畑の跡があった。畦が崩れ、苗が炭になっている。兵は、それを見ないようにして歩いた。見なければ、考えずに済んだ。

# **二**

最初に気づいたのは、風だった。

先頭の隊列の前方で、風が止んだ。焦げた匂いを運んでいた風が、ぴたりと。

「止まれ」

誰かが言った。隊列が止まる。丘の稜線の向こうから、一人の男が歩いてきていた。

兵は目を細めた。遠くて、顔は見えない。外套の頭巾を被っておらず、黒い髪が風もないのに揺れていた。額の脇に、黒い角。背には、畳まれた黒い翼が見えた。剣は帯びていない。杖も、盾もない。ただ、歩いている。

足音が、聞こえなかった。

「……一人か」

隣の兵が呟いた。声が、わずかに掠れていた。

「魔族の斥候だろう。囲め」

隊長の声が飛ぶ。弓兵が前に出て、矢をつがえた。兵は槍を握り直した。掌が汗で滑った。

男は、歩調を変えなかった。一歩、また一歩。丘の黒い土を、まるで庭の小道のように。

兵は、不意に思った。あの男は、畑の畦を踏まないように歩いているのではないか。馬鹿げた考えだった。焼けた丘に、畦などない。

# **三**

矢が放たれた。

それが、最後の音だった。

矢は男に届かなかった。届く前に、空中で止まった。止まって、落ちた。乾いた葉が落ちるように。

隊列の最前列で、兵が一人、膝をついた。叫びはなかった。膝をついて、そのまま前に倒れた。倒れた体は、地面に着く前に薄れ、黒い土と区別がつかなくなった。

もう一人。その隣が、さらにもう一人。

手前から順に、静かに、隊列が消えていった。

男は、歩いていた。手を上げもしない。何かを唱える唇の動きもない。ただ歩き、その歩みの前にいる者が、そこにいなくなる。

「撃て、撃て！」

隊長の声は途中で消えた。声の主ごと。

兵は槍を構えたまま、足が動かなかった。逃げようと思った。思っただけで、体が言うことを聞かない。恐怖が、体の真ん中を凍らせていた。

隣の兵が、こちらを見た。目が合った。唇が「あ」の形に動いた。次の瞬間、その兵はいなかった。鎧だけが、中身を失って、崩れ落ちるはずだった。それすらなかった。鎧も、剣も、懐の何もかも、跡形もなく。

風の音だけが残った。

兵は、気づいた。血の匂いがしない。悲鳴がない。何も壊れていない。ただ、人が、いなくなっていく。

男の顔が、見えた。

静かな顔だった。怒りも、憎しみも、そこにはなかった。ただ、深く、底のない、凪いだ水面のような。

その顔を、兵は知らない。それなのに、どこかで見たことがあるような気がした。祭りの夜に、卓の端で酒を飲んでいる誰かの顔に似ていた。そんなはずはない。

# **四**

「下がれ、下がれ！」

鋭い声が、混乱を裂いた。

勇者タケルが、隊列の前に飛び出していた。白銀の鎧が、焼けた空の赤を映している。人間界最強と呼ばれる剣士が、剣を抜き放つ。

「魔王ベルイザナ！ これ以上の蛮行は許さん！」

澄んだ声だった。迷いのない声だった。兵は、その声に縋った。あの人がいる。英雄がいる。あの人が、なんとかしてくれる。

男は、足を止めなかった。

タケルが踏み込んだ。剣が、閃いた。人間界最強の一撃が、まっすぐに男の首筋へ向かう。

届かなかった。

剣が男の外套に触れる寸前で、タケルの膝が折れた。力が抜けたように、がくりと地面に沈む。剣が手から離れ、からんと音を立てて転がった。

「な……」

タケルが顔を上げた。目に、初めて困惑が浮かんだ。何をされたのか、分かっていない。

男は、タケルを見下ろした。何も言わなかった。

その後ろで、参謀格らしい男たちが、次々と膝をついていく。誰も悲鳴を上げなかった。立っている者の数が、減っていく。

兵は、槍を取り落とした。

視界が、白くなっていく。恐ろしいとは、もう思わなかった。ただ、手紙のことを思った。書き足せなかった、続きのことを。

土産は、何がいいだろう。娘の好きな菓子を、買って帰ろう。この戦が終わったら、街で、一番いい店で。

あいつは、甘いものが好きだったから。

娘に――

# **五**

ミカヅチが丘の稜線に立った時、戦場は静まり返っていた。

息が止まった。

視界の端から端まで、何もなかった。焼けた黒い土の上に、足跡さえ残っていない。鎧の破片も、折れた槍も、血の染みも。万を超えていたはずの軍勢が、最初からそこにいなかったかのように、消えていた。

風が吹いている。何も運ばない風が。

ミカヅチは、鬼族の頭領として、数え切れない戦場を見てきた。屍の山も、血の川も知っている。だが、これは違った。何もない。何もないことが、これほど恐ろしいとは知らなかった。

一騎討ちの記憶が、蘇る。全てをぶつけ、一撃を受けきった。あの時、王は手加減をしていた。受けきれる一撃を選んでいた。今なら分かる。あれが、王の本気であるはずがなかった。

「……王」

呼びかけは、掠れた。

戦場の中央に、ベルイザナが立っていた。背を向けている。その足元に、六つの影が膝をついていた。白銀の鎧の勇者と、参謀格の者たち。生きている。息をしている。立ち上がる力だけが、奪われていた。

ミカヅチは、ゆっくりと歩み寄った。足音が、やけに大きく響く。

「避難は終えました。各族とも、無事です」

「そうか」

ベルイザナの声は、平らだった。振り返らない。

「ご苦労だった」

その一言に、ミカヅチは、言葉を失った。礼を言われたことに、ではない。声に、何の色もないことに。魔界の民を、一人の例外もなく気にかける王の声から、温度だけが抜けていた。

足元のタケルが、顔を上げた。唇を噛み、血を滲ませ、それでも目に力を残している。

「殺せ。魔王」

タケルは、まっすぐに言った。

「俺は、お前を許さない。殺せ」

ベルイザナは、タケルを見下ろした。長い間、何も言わなかった。

「殺さない」

やがて、言った。

「おまえたちには、聞きたいことがある。命を取るのは、それが済んでからだ」

「俺は何も話さん」

「それでもいい」

ベルイザナは、初めて振り返った。ミカヅチを見て、静かに告げた。

「この者たちを、捕らえてくれ。傷つけるな。飢えさせるな。必要なものは与えろ」

「……は」

ミカヅチは頭を下げた。顔を上げる時、見てしまった。

ベルイザナの右手が、外套の陰で、小さく震えていた。

怒りか、悲しみか、あるいは別のものか。ミカヅチには分からなかった。ただ、その震えが、先ほどまでの静かな恐ろしさとは別の何かを語っているように思えた。

震えは、すぐに止まった。ベルイザナは手を握り込み、何事もなかったように、焼けた根の洲の丘を見渡した。

遠くで、鴉が一羽、鳴いた。

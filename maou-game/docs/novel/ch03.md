# **第三章　問うても答えぬ者**

# **一**

目を覚ますと、天井が低かった。

タケルは石の床に横たわったまま、しばらく動かなかった。体のどこにも縄がない。鎖もない。腕を動かすと、肩に布が巻かれているのが分かった。誰かが、傷を手当てしている。

(死んでいない)

次に思ったのは、それだった。魔王の前で膝をついたところまでは覚えている。その先は白い。

牢は狭いが、清潔だった。窓は高く、赤い光が細く差している。床には藁の寝床があり、隅には水の入った甕が置かれていた。毒かもしれない、と疑って、タケルは水に手を触れなかった。

扉の小窓が開いた。鬼の顔が覗いた。額に二本の角があり、牙が口の端から覗いている。

「起きたか。飯だ」

差し入れ口から、盆が滑り込んできた。湯気の立つ粥と、焼いた根菜と、干し肉が一切れ。

「毒など入れておらん。入れるつもりなら、寝ている間にやっている」

鬼は無愛想に言った。

「飢えさせるなとの王命だ。食え」

タケルは盆を見つめた。魔族は話の通じない者たちだ。人を食らい、嘲り、約束を踏みにじる。そう聞いてきた。王が、そう仰った。

目の前の粥は、ただ温かかった。

腹が鳴った。タケルは唇を噛み、それでも盆を引き寄せた。一口食べると、米の甘みがあった。それが、ひどく悔しかった。

「……礼は言わん」

「いらん。王命だ」

鬼は小窓を閉めかけて、少し止まった。

「だが、残さず食うのは感心だ。鬼族では、食い物を残す奴は弱いと言う」

小窓が閉まった。タケルは粥の椀を、最後の一粒まで空にした。

# **二**

二日目の夜に、男が来た。

足音は、ほとんどしなかった。牢の前に立ったのは、黒髪の静かな男だった。額の脇に、黒い角が二本。背には、畳まれた黒い翼。それでも、顔だけを見れば、人間と変わらない。ただ、その男の周りだけ、空気の密度が違った。

魔王ベルイザナ。戦場で、タケルを膝から折った男だ。

「傷は痛むか」

最初の言葉が、それだった。タケルは顔を上げ、睨みつけた。

「何の用だ。殺すなら、早くしろ」

「聞きたいことがある」

ベルイザナは、牢の格子の前に腰を下ろした。見下ろさない位置だった。

「なぜ和平の席で、刃を抜いた」

「あれは、魔族が先に仕掛けた。王様はそう仰った」

「会談の間で、先に動いたのは人の軍勢だった」

「嘘だ。魔族は話の通じない者たちだ。約束を守らず、人を欺く。だから――」

タケルの言葉は、そこで途切れた。

自分の声が、遠くから聞こえた。喉を通っているのは自分の言葉のはずなのに、どこかで誰かが同じ言葉を繰り返しているような。

ベルイザナは、黙っていた。責めもせず、遮りもせず、ただ聞いていた。

「……魔族は、話の通じない者たちだ」

もう一度、言った。今度は、さっきより声が小さかった。

目の前の男は、話が通じていた。傷を気遣い、座って、目を合わせて問う。食事は、残さず食べろと言われた。看守は無愛想だが、殴ってこない。

(おかしい)

その言葉が浮かんだ瞬間、胸の奥で何かが締まった。頭の奥に、細い痛みが走る。考えるな、と別の声が言った。それは自分の声のようで、そうでなかった。

ベルイザナは、タケルの顔をじっと見た。

「今日はここまでにしよう。また来る」

立ち上がる気配に、タケルは思わず言った。

「おまえ……どこかで」

「何だ」

「いや」

タケルは首を振った。黒髪の男の顔に、なぜか引っかかるものがあった。見たことがある気がする。いつ、どこで。戦場ではない。もっと違う、何かの。

答えは出なかった。男は静かに去り、足音は闇に溶けた。

# **三**

ナキメは、牢の格子の外に椅子を置いて座っていた。

鴉族の長として、数え切れない言霊を扱ってきた。特に、心に触れる術には自信がある。呪文系言霊で魔界随一と言われるのは、伊達ではない。

「痛みはありませんか。少し、中を見せていただきます」

「やめろ」

「やめません。これは、あなたのためでもあります」

ナキメは指先を軽く動かし、**朧**を細く紡いだ。相手の意識の輪郭をぼかす言霊だ。強いものではない。扉を叩く程度の、挨拶のような。

タケルの目が、わずかに揺らいだ。

(入った)

ナキメは息を詰めた。心の表層は、柔らかかった。善良で、真っ直ぐで、不器用な。人を疑うことを知らず、疑われることを恐れる。そういう手触りがある。

その奥に、硬い層があった。

(これか)

王の言霊は、薄い膜のように心を覆っていた。ただ覆っているのではない。膜は根を伸ばし、タケルの善良さそのものに絡みついていた。「正義を信じたい」という願いを足場にして、そこから「魔族は悪だ」という考えを育てている。

**名暴き**を、細く差し入れた。偽りの名を剥がす言霊だ。洗脳の核を見つけて、緩めることができるかもしれない。

その瞬間、強い反発が返ってきた。

タケルの体が跳ねた。喉から、本人のものではない声が漏れる。

「――魔族は、話の通じない者たちだ」

ナキメは、すぐに言霊を引いた。額に汗が滲んでいた。

「……失礼しました。今日はここまでにします」

タケルは息を荒げ、牢の隅へ後ずさった。目に、恐怖が浮かんでいる。ただし、ナキメに向けてではなかった。自分の口が勝手に動いたことへの、恐怖だった。

(自覚はある。解ける余地は、ある)

ナキメは立ち上がり、静かに頭を下げた。

「少しずつやります。あなたを、傷つけたくはない」

タケルは、何も言わなかった。ただ、目だけが、揺れていた。

# **四**

居城の広間は、夜になると冷える。

ナキメは、ベルイザナの前に膝をついていた。膝が、わずかに震えているのが自分で分かる。この王の前に立つと、いつもそうだ。底が見えない。見えないのに、嘘がない。その矛盾が、体を震わせる。

「報告します」

声は、震えなかった。震わせなかった。

「王の言霊は、心の奥深くに根を張っています。無理に剥がせば、本人の心が壊れかねません。この者の善良さを足場にして、成長している。善人ほど、深く染まります」

「解けるのか」

「解けます。ただし、時間がかかります。数か月は見ていただきたい」

ベルイザナは、頷いた。

「急がなくていい。壊すな」

「承知しました」

ナキメは、少し迷ってから、言葉を足した。

「一つだけ。綻びを作ること自体が、王への合図になる危険があります。言霊の根は、遠くの術者に繋がっているように感じました。解こうとするほど、向こうに気づかれるかもしれません」

「気づかれたら、どうなる」

「分かりません。ただ、備えはしておきます」

ベルイザナは、ナキメの顔を見た。長い間、何も言わなかった。

「おまえは、嘘を使わずに報告したな」

「……はい」

「ありがとう。助かる」

ナキメは、深く頭を下げた。顔を上げられなかった。震えは、まだ止まっていない。ただ、それは恐れだけの震えではなかった。

# **五**

黄泉津の宮の露台は、夜風が強い。

ベルイザナは手すりに肘をつき、赤い夜空を眺めていた。耳元に、声が届く。**言伝**の言霊だ。

「ベルイザナ様。人間界へ自ら赴くなど、お考え直しください」

オモイカの声だった。傷が癒えきらず、少し掠れている。

「危険すぎます。人の王は、狡猾です。魔王が一人で乗り込めば、どんな罠が待つか。四天王を連れていく手も――」

「連れていけば、潜入にならない」

「それは、そうですが」

「オモイカ」

ベルイザナは、静かに呼んだ。

「おまえが失った者たちの顔を、私は知らない」

通信の向こうで、息を呑む気配がした。

「おまえは、一人ひとりを覚えていた。家族も、好物も。私は、彼らの顔を知らなかった。名前も、一人も呼べない。王でありながら」

「それは……あなたのせいでは」

「人間の顔も、知らなかった」

ベルイザナは、手すりを握った。指の関節が白くなる。

「戦場で、私は何千人も消した。顔を見なかった。見ようとしなかった。あれが、人だったのかどうか。私は、知らないまま、殺した」

返事はなかった。夜風が、露台の灯を揺らした。

「牢のタケルは、粥を残さず食べる。看守に、礼を言いかけて飲み込む。あれは、魔族が思い描く『人間』と、まるで違う」

「それは、洗脳の――」

「分かっている。だが、洗脳されているのは、あの男だけではない。街にも、軍にも、きっといる。だとしたら、私が滅ぼそうとしているものは、何だ」

沈黙が、長く続いた。

オモイカが、小さく息を吐いた。

「……ベルイザナ様の、お考えは分かりました」

「反対か」

「反対です。今でも」

オモイカの声は、少しだけ笑っていた。

「ですが、あなたは、一度決めたら変わらない方です。ならば私は、最悪の場合を考えます。人間界での名、力の抑え方、通信の取り方。全て詰めましょう」

「ありがとう。おまえには、助けられてばかりだ」

「申し訳ありません、私は――」

「それより」

ベルイザナは、言葉を遮った。穏やかな声だった。

「次の手を、聞かせてくれ」

通信の向こうで、オモイカが、小さく、確かに息を詰めた。それから、静かに答えた。

「……はい。まず、名からです」

# **六**

夜が明ける前に、方針は固まった。

偽りの名を、使う。まことの名を伏せ、「ベル」と名乗る。短く、ありふれた響きだ。まことの名が名付けと支配の力を持つ世界では、偽名にも弱い言霊が宿る。印象を薄め、記憶に残りにくくする。

力は、抑える。人間界で最強と言われるタケルと、同じ程度まで。それでも、並の冒険者よりは遥かに強い。ただ、使うほど気配が漏れる。

四天王には、「下見」と告げる。本当のことは、言わなかった。言えば、止められる。止められないとしても、危険だと言われる。

(本心は、人間を知りたい)

露台の上で、ベルイザナは、その言葉を自分にだけ認めた。

滅ぼすために行くのではない。見に行くのだ。あの牢の男が、どんな世界で育ったのか。畑を踏んで進んだ兵が、どんな家に帰るはずだったのか。

夜明けの光が、赤い空の端を薄く染めていく。黄泉の空は、朝でも赤い。それでも今朝は、少しだけ、澄んで見えた。

遠く、比良坂の方角に、細い光の筋が立っている。大穴の底から、世界の中心から、昇る光だ。

ベルイザナは、その光を、長く見つめた。

(私の名は、ベル。ただの冒険者だ)

声に出さずに言ってみた。まだ、自分のものではない響きだった。

それでも、いつか馴染むだろう。そう思えたことが、昨日までの自分との、小さな違いだった。

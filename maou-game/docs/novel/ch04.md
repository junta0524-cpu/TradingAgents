# **第四章　同じ受付の前で**

# **一**

港町ミナモは、朝から騒がしかった。

ベルは石畳の上に立ち、しばらく動けなかった。比良坂を渡ってから三日、街道を歩き通してようやく着いた交易の町だ。潮の匂いと、焼き魚の煙と、人の声が、いっぺんに押し寄せてくる。

黄泉の市場とは、匂いが違う。魔界の市場は、種族の匂いが混ざる。ここでは、人間の匂いが混ざっていた。汗と、香辛料と、洗濯した布と、焦がした砂糖。

力は、抑えている。黄泉の力を体の奥へ畳み込み、人の青年の姿を保っている。鏡を見たときは、少し驚いた。角も牙もなく、ただの黒髪の若者が映っていた。魔王の面影は、目の奥にわずかに残る程度だ。

「おい、兄さん。そこ、邪魔だよ」

荷車を引いた男が、舌打ちして通り過ぎた。ベルは慌てて脇へ寄った。誰かに邪魔だと言われたのは、いつ以来だろう。

悪い気は、しなかった。

通りには屋台が並んでいた。ベルは、焼き菓子の屋台の前で足を止めた。列ができている。人間の客が三人、その後ろに、獣の耳を持つ女が一人。

店主は、人間の客の注文を先に捌いた。三人目が済んでも、手を止めて、後から来た別の人間の客に声をかけた。

「いらっしゃい、何にします」

「待て、私が先だ」

獣耳の女が、控えめに声を上げた。店主は、ちらりと女を見て、わざとらしく眉を上げた。

「ああ、あんたかい。ちょっと待ちな。順番ってものがある」

順番なら、女が先のはずだった。女は何も言わなかった。目を伏せ、また列の端へ下がった。後から来た人間の客は、それに気づかないふりをして、菓子を受け取った。

ベルは、拳を握りかけて、ゆっくり開いた。

(ここで何かをすれば、目立つ)

分かっている。分かっているが、胸の底に、冷たいものが落ちていた。

魔界で、こんな順番を許した覚えはない。王として、許さなかった。だが、ここは魔界ではない。

通りの奥の掲示板には、紙が何枚も貼られていた。迷い猫の捜索。荷運びの募集。その隅に、ひときわ大きな文字の紙が一枚あった。

『魔族は話の通じぬ者たちである。正義は我らにあり』

見覚えのある言葉だった。タケルが、牢の中で繰り返していた言葉と、同じだ。

ベルは、紙を長く見つめた。誰も、足を止めない。誰も、疑わない。まるで空気のように、街にこの言葉が染みている。

(街に、根を張っている)

ナキメの分析が、頭をよぎった。善人ほど深く染まる。この街の人々は、悪人ではないのだろう。焼き菓子の店主も、荷車の男も、きっと家に帰れば、家族に優しい。

それが、いっそう恐ろしかった。

ベルは、掲示板に背を向けた。冒険者ギルドの看板が、通りの向こうに見えていた。

# **二**

オオナムチは、朝から三度、胸の内で唱えていた。

(初めての依頼。初めての依頼。失敗しない)

ギルドの受付は、木の長い台の向こうにある。朝は混み合う。腕に自信のありそうな冒険者たちが、依頼書を片手に列を作り、ざわめきが天井に反響していた。

オオナムチは、列の後ろに並んだ。継ぎの当たった外套に、使い古した短剣。靴の踵は擦り減っている。登録は昨日済ませたばかりで、冒険者の札は、まだ銅色のいちばん下の等級だった。

「次の方」

受付の女が、顔も上げずに言った。オオナムチの前の男が、台に身を乗り出す。その隣に、もう一人、別の男が並んだ。

オオナムチは、何気なく、その男を見た。

黒い髪の、若い男だった。年は自分より少し上だろうか。背は高く、外套は旅慣れていない様子で、まだ新しい。右の眉の端に、小さな古い傷がある。瞳は、深い灰色だった。

ふと、気づいた。

(見えすぎる)

おかしな感想だった。ただ、その男の顔が、細部までくっきり見えるのだ。眉の傷も、睫毛の長さも、唇の端の癖も。まるで、そこだけ光が当たっているように。

ほかの者たちは、その男に、目も留めなかった。隣の冒険者が肘をぶつけても、男の顔を見ずに謝りもしない。受付の女も、男が台の前に立つと、一瞬だけ視線を向け、すぐ手元に戻した。

「新規の登録ですね。お名前を」

「ベル」

「ベルさん。お住まいは」

「決まっていない」

「根無し草の方ですか。では、後見人は」

「いない」

女は鼻を鳴らし、札を書き始めた。ペンの先が、紙の上を滑る。書き終えて顔を上げたとき、女は、一瞬、ぼんやりした顔をした。

「……ええと、お名前、何でしたっけ」

「ベル」

「ああ、そうでしたね。失礼しました」

女は札を差し出した。男は、礼を言って受け取った。礼を言う冒険者は、珍しい。オオナムチは、思わず、その横顔を見ていた。

(目がいいんだろうな、俺は)

そう思って、すぐに忘れた。今日は、自分の依頼がある。

# **三**

依頼の掲示板は、ギルドの奥の壁にある。

人気の討伐依頼や護衛の仕事は、朝のうちに剥がされる。残るのは、報酬の安い、手間のかかる依頼だけだ。

オオナムチは、掲示板の隅を見ていた。

一枚だけ、何日も残っている紙があった。端が黄ばんで、角が丸まっている。

『ひなた野への届け物。薬と日用品。報酬、銅貨十枚』

誰も受けない理由は、分かっている。行き先が、亜人の多い集落だからだ。往復で一日かかるのに、銅貨は十枚。パン一個と変わらない。

オオナムチは、迷わず紙を剥がした。

受付の女が、紙を見て眉をひそめた。

「それ、受けるんですか。ひなた野でしょう」

「はい」

「報酬、安いですよ。もっと割のいい依頼が、ほら、下水路の掃除なら」

「これでいいです」

「……変わった子ね」

女は、納得のいかない顔で、受注の判を押した。紙を渡す指が、どこか汚いものを扱うように、少し離れていた。

オオナムチは、何も言わなかった。慣れている。生まれ育った土地の名を言うと、人の目つきが変わる。それを、何年も、見てきた。

荷物は、裏口の倉庫に積まれていた。薬草の包みが二つ、塩の袋、布が三反。それから、小さな布の包みが一つ。封をした紙の手紙が、布に挟まれていた。

オオナムチは、その包みを手に取った。宛名の字を見て、息が止まった。

『ハルへ』

見慣れた、少し右に傾く文字だった。

(ユウ)

手紙は、街で働いている幼なじみからだ。何度も、集落に残した弟の話を聞いた。会うたびに、「あいつ、元気かな」と呟いていた。

オオナムチは、手紙を懐の奥にしまった。誰にも言うつもりは、なかった。

# **四**

「その依頼、私も行っていいか」

倉庫の入口に、人影が立っていた。

オオナムチは、はっとして振り返った。受付の隣に並んでいた、あの男だった。ベル、と名乗った黒髪の男。

「え。いや、これは」

「今日、登録したばかりだ。依頼の相場が分からない」

男は、淡々と言った。声は低く、静かで、敵意がない。

「銅貨十枚の依頼を、わざわざ選ぶ人間を、初めて見た。理由を聞きたい」

「理由なんて、ないですよ。誰も受けないから」

「誰も受けないから、受ける」

ベルは、その言葉を、噛みしめるように繰り返した。

「いい理由だ」

「そう、ですか」

オオナムチは、戸惑った。ひなた野に行く冒険者を、初めて見た。同行を申し出る人間など、なおさらだ。

「危ないですよ。途中に、野犬が出ます。俺は、戦いはまだ、全然で」

「私も、似たようなものだ。駆け出しだから」

嘘ではないのか、と、オオナムチは訝った。男の体つきは、引き締まっている。立ち姿に隙がない。ただ、ベルの目には、驚くほど敵意がなかった。誰かを試すでも、侮るでもない。ただ、見ている。

(変な人だ)

そう思った。同時に、悪い人ではない、とも思った。理由は、分からなかった。

「……オオナムチです」

「ベルだ。よろしく頼む」

差し出された手は、少し冷たかった。オオナムチは、その手を握った。力は、驚くほど加減されていた。

# **五**

街を出て二刻ほど歩くと、道は荒れ地に入った。

荷は、オオナムチが背負った。ベルが半分持つと申し出たが、断った。初めての依頼だ。自分の足で運びたかった。

荒れ地の岩陰から、唸り声が聞こえたのは、日が高くなったころだった。

オオナムチの体が、固まった。短剣の柄に手をかける。指が、細かく震えていた。

「出ましたね」

低い声で、ベルが言った。

岩の陰から、野犬が三匹、姿を現した。痩せて毛が荒れているが、牙は鋭く、目が飢えている。一匹が、じりじりと間合いを詰めてくる。

(やるしかない)

オオナムチは、短剣を抜いた。足が、地面に張りついたように重い。呼吸が浅い。頭の中が、白くなる。

その時、不意に、口が動いた。

「――堅め」

自分でも驚いた。教わったことなどない。ただ、集落の年寄りが、子どもの頃に、木の実を取りに行く時に唱えさせてくれた短い言葉だった。身を守る、おまじない。まことの名を呼べば、誰でも基礎の力は引き出せる。

体の周りに、薄い膜のような感触が走った。守りの言霊が、立ち上がった。

野犬が、飛びかかってきた。

オオナムチは、短剣で払った。刃が毛を掠めただけで、犬は怯まない。二匹目が、脇から回り込んでくる。

(だめだ、囲まれる)

視界の端で、ベルが動いた。

ベルは、剣を抜かなかった。ただ、一歩だけ、足を出した。それだけで、三匹目の犬の軌道が、わずかに逸れた。犬は、勢いのまま岩に当たり、悲鳴を上げて転がった。

オオナムチは気づかなかった。目の前の犬に、必死だった。

左腕に、衝撃が走った。牙が食い込み、堅めの膜が軋む。痛みで視界が滲んだ。

「うわっ……!」

「落ち着け。膜は破れていない」

ベルの声が、すぐ後ろから聞こえた。落ち着いた声だった。

「痛みの形を、思い浮かべろ。それを、癒やしてくれと願うんだ」

「癒やし、って、そんな、いきなり」

「できる。君は、もう守りの言霊を出している。同じ力の、反対の側だ」

オオナムチは、歯を食いしばった。腕の痛みを見る。牙の跡。滲む血。それを、元の形に戻してくれと、願った。

「――癒やし」

ふわりと、温かいものが腕を包んだ。傷口は完全には塞がらなかったが、血が止まり、痛みが引いた。

犬が、一匹、怯んだように後ずさった。二匹目も、足を止める。

ベルが、一歩、前に出た。

何をしたのか、オオナムチには分からなかった。ベルは、剣を抜かず、ただ、野犬たちを静かに見ただけだ。三匹の犬が、尾を巻いて、岩場の向こうへ逃げ去った。

荒れ地に、風の音が戻った。

オオナムチは、その場に座り込んだ。足から力が抜けていた。短剣を握る手は、まだ震えている。

「やった……のか、俺が」

「君が、守って、癒やした」

ベルは、静かに言った。

「いい動きだった」

オオナムチは、顔を上げた。嬉しい、と思った。同時に、不思議に思った。最後の一撃を、自分は放っていない。それでも、ベルは、自分の手柄のように言ってくれた。

ベルは、背を向けたまま、息を整えていた。

(危なかった)

力を抑えるのが、これほど難しいとは思わなかった。ほんの一歩、足を出しただけで、野犬は、必要以上に吹き飛びかけた。軌道を逸らすだけにとどめるのに、神経を使い果たした。

それでも、収穫はあった。

オオナムチは、教わらずに堅めを唱えた。誰に導かれたのでもなく、ただ、守りたいという願いが、そのまま言霊になった。癒やしも、一度の助言で形にした。

(才がある)

血統ではない。努力の積み重ねでもない。もっと、素朴な、人を守りたいという性質そのものが、言霊を呼んでいる。

オオナムチの腕の傷を、ベルは見た。左腕に、牙の跡が残っている。

(私がいなければ、致命傷になっていたかもしれない)

守る側に立つというのは、こういうことか、とベルは思った。力を抑えながら、相手が傷つきすぎないように、気づかれない場所で動く。魔界で、民を守る時には、考えもしなかった。力を見せることでしか、守ったことがなかった。

「行こう。日が暮れる」

振り返ったベルは、できるだけ穏やかな声で言った。

# **六**

ひなた野は、丘の陰にある小さな集落だった。

藁葺きの家が十軒ほど、低い石垣に囲まれて並んでいる。畑には、細い野菜が植わっていた。煙突から細く煙が昇っている。畑の脇で遊んでいた子どもたちが、二人の姿を見て、一斉に顔を上げた。

子どもたちの何人かは、耳が尖っていた。尻尾のある子もいる。小さな角を額に持つ子もいた。

「冒険者だ」

「本当に来た」

大人たちが、家から出てきた。老いた女、腰の曲がった男、赤子を抱いた若い母親。誰もが、驚いたように、二人を見つめている。

「ギルドからの、届け物です」

オオナムチが言うと、老婆が、目を丸くした。

「本当に、来てくださったのかい。もう、誰も来ないと思っておったよ」

「遅くなって、すみません」

「遅いものか。ありがたい。薬が、もう切れておって」

老婆は、薬草の包みを抱きしめるように受け取った。皺だらけの手が、小さく震えていた。塩の袋、布の反物と、荷が下ろされるたびに、集落の人々の顔が、ほどけていく。

「ありがとう」

「本当に、ありがとう」

何人もの口から、同じ言葉が出た。ベルは、荷を運びながら、その声を聞いていた。

(感謝されている)

人間界に来て、初めてだった。いや、魔王として、民から感謝された経験は、多かった。それでも、今の言葉は、違った。ベルという名の、ただの冒険者に向けられている。力の裏付けも、地位の重みもない。ただ、荷を運んだことへの、礼だった。

胸の奥が、温かくなった。同時に、少し痛んだ。この温かさを、人間界で味わうことを、自分は許されているのだろうか。

「手紙も、あります」

オオナムチが、懐から、小さな包みを取り出した。

「ハル、という子は」

「あ、おれ」

人垣の後ろから、小さな男の子が、駆け出してきた。八つか九つほどの、痩せた少年だった。目が大きく、髪は寝癖のように跳ねている。耳の先が、わずかに尖っていた。

「兄ちゃんから、ですか」

「そうだよ。街で働いている、ユウさんから」

少年は、両手で手紙を受け取った。包みを、そっと撫でる。封を切る指が、慎重だった。

少年は、地面にしゃがみ込み、紙を広げた。唇を動かしながら、一字ずつ、指で辿っていく。

「は、る、へ。げ、ん、き、に、して、い、る、か」

読み進めるうちに、少年の顔が、ゆっくりとほころんだ。やがて、口元が、大きく緩んだ。

「兄ちゃんの字だ」

少年は、顔を上げて、笑った。

「兄ちゃん、ちゃんと書いてくれた。おれのこと、忘れてなかった」

その笑顔を見た瞬間、ベルは、息をするのを忘れた。

寄り添いの里の、子どもたちの顔が、重なった。耳の聞こえない小さな嵐狼が、泥だらけの手で笑っていた。あの笑顔と、同じ形をしていた。

(人間にも、この顔がある)

分かっていたことだった。頭では、分かっていた。それでも、自分の目で見るまでは、本当には理解していなかった。種族が違っても、笑顔の形は、変わらない。兄からの手紙を、宝物のように読む子どもの顔は、魔界にも人間界にも、同じようにあった。

「ねえ、おじさんたち」

ハルが、紙を握りしめて言った。

「兄ちゃん、元気かな」

オオナムチは、少年の目の高さまで、膝を折った。

「元気だよ」

その声は、柔らかかった。

「手紙の字が、元気だっただろう」

「うん」

ハルは、大きく頷いた。

オオナムチの顔を見ながら、ベルは、ふと、気づいた。彼は、笑っていた。けれどその目の奥に、何か、細い影が差していた。この青年は、手紙の差出人を、知っている。ここに来た理由は、報酬の安い依頼を選んだ優しさだけではない。

ベルは、何も尋ねなかった。ただ、少年の笑顔を、長く見つめた。

# **七**

帰り道は、夕焼けだった。

ひなた野の丘を下りると、西の空が、橙色に染まっていた。ミナモの灯が、遠くで、少しずつ点き始めている。

二人は、並んで歩いた。荷を下ろしたぶん、足取りは軽い。オオナムチの腕の傷は、集落の老婆が、薬草を貼ってくれた。

「報酬、銅貨十枚でしたね」

オオナムチが、懐から小さな布袋を出して、掌で転がした。

「半分、渡します。ほとんど何もしていない、なんて言わせませんよ」

「いらない」

ベルは、首を振った。

「君が選んだ依頼だ。私は、付き添っただけだ。それよりも」

少し間を置いて、ベルは、言った。

「聞いていいか」

「何ですか」

「なぜ、この依頼を選んだ」

オオナムチは、歩みを止めずに、しばらく黙っていた。道の脇で、夕風が草を撫でていく。

「育った場所に、似ていたからです」

やがて、短く答えた。

「ひなた野は、俺の故郷じゃない。でも、似ているんです。薬が足りなくて、誰も来てくれなくて、それでも皆で、少しずつ分け合って暮らしている」

「そうか」

「だから、誰かが行かなきゃって」

それだけだった。オオナムチは、それ以上、語らなかった。

ベルも、それ以上、聞かなかった。聞かなくても、分かった気がした。この青年は、報われない場所に、自分から足を向ける。理由は、損得ではなく、見過ごせないからだ。

(魔界の、寄り添いの里のようだ)

スサノが、群れの掟を破ってまで作った場所を、ベルは思い出した。ついて来られない者を切り捨てない、という、小さな意志。オオナムチの選択は、その意志と、どこか同じ色をしていた。

「ベルさんは、どうして一緒に来てくれたんですか」

今度は、オオナムチが尋ねた。

「誰も受けない依頼を選ぶ人間を、見てみたかった」

ベルは、正直に言った。嘘は、つきたくなかった。

「それだけだ」

「変わった人ですね」

「よく言われる」

実際は、言われたことなどなかった。ただ、そう答えるのが、なぜか自然だった。

オオナムチが、小さく笑った。つられて、ベルも、口の端を上げた。

ミナモの灯が、近づいてくる。橙色の光の中で、青年の横顔が、はっきりと見えた。ベルは、ふと、思った。

(この青年は、いつか私に並ぶ)

根拠は、なかった。ただ、予感があった。

「また、依頼があったら、声をかけてくれ」

「え」

「一人より、二人のほうが、報酬は半分だが、危険も半分になる」

オオナムチは、目を瞬いた。それから、顔をくしゃりとさせて、笑った。

「半分ずつ、ですね」

「そうだ。半分ずつだ」

二人の影が、夕焼けの道に、長く並んで伸びていた。

# 第六章　執筆メモ（ユーザー提供・原文）

約10,200字で、8場面の構成のまま書きました。視点は、オオナムチ(①⑧)、カナメ(②③)、ベル(④)、イシコリドメ(⑤)、コトシロ(⑥⑦)です。

回収用の伏線は次のとおりです。
- 刃の芯に仕込んだ層（10章の脱出で兵が剣を振り上げきれない場面）
- コトシロの「いつか、私の目が役に立つ日」（王都編で再登場）
- 「火は、作り直す力でもある」（ホノカグツチ系の入口、火種の習得）
- 終盤の一瞬のベルの表情（⑧の言伝。タケル脱走の報で、7章へ接続）
- カナメの「腕なら、貸す」（10章の脱出）

ゲーム面は、火種の習得イベントと、コトシロ（商人枠）の鑑定・目利きの体験を織り込みました。

気になる点が1つあります。コトシロは、ベルが細工に気づいていたと察していますが、ベルは正体を隠したままです。その後も「詮索しない恩人」の位置が保たれます。

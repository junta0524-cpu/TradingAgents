# 第七章　執筆メモ（ユーザー提供・原文）

約12,000字で、7場面の構成のまま書きました。視点は、ウズメ(①)、オオナムチ(②⑤⑦前半)、ベル(③⑥⑦後半)、ユウ(④)です。

ハルの所在：4章の「ひなた野」は、入植者の杭と水場の汚染で住めなくなり、ハルたちは「葛の里」(オオナムチの故郷、仮名)へ身を寄せた、としました。名前は仮です。

回収した伏線
- 3章の牢で蒔いたタケルの「どこかで……」を回収しました。阻害の揺らぎを、本文でも描いています。
- 6章終盤のタケル脱走の報は、⑦のオモイカの通信で詳細を補いました。ナキメは猛省し、ベルは「責めるな」と許しています。
- ヒエダの「見破り」による洗脳の「根」の可視化は、10章の阻害破りの伏線になります。
- オオナムチは、ベルが見えない力で命を繋いだことに気づきましたが、問いませんでした。「待つ」決意の積み増しです。

新しく入れた設定
- タケルの視察は、王の探知網を細かくするための「英雄の巡行」でもあった。
- ユウの頭の中の声は、王都の言霊そのもの。「民の一人だ」という言葉は、ミナトと同じ手口。
- ゲーム面：ウズメ(罠・隠し通路)とヒエダ(後衛)の加入、心鎮めの深化、洗脳に綻びを作るイベントを織り込みました。
- ユウの描き方：④で一度だけ内面を開きました。正しい側にいる確信の痛々しさと、頭の中の「温かい声」を前面に出しています。

気になる点
- ハルの年齢を、4章に合わせて「八つか九つ」の少年として扱っています。
- 「葛の里」は仮名です。地名一覧に未登録なので、追加するか別の名にするか決めたいところです。
- ウズメは猫に似た耳と栗色の尻尾、ヒエダは藍色の外套、と外見を固定しました。以後の章で揃えます。

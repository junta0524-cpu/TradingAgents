# 第八章　執筆メモ（ユーザー提供・原文）

約10,000字で、6場面の構成のまま書きました。視点は、ベル(①④⑥)、オオナムチ(②⑤)、コトシロ(③)です。

「念のため」：昼の討論会で、差別の線引きが悪意ではなく善意の言葉から生まれていることを、一語で見せました。ミナモの小さな線引きとの接続です。

伏線の回収・追加
- コトシロが聞いた兵の「握ると考えが澄む」（偽りの納品の効果、10章の脱出）
- やすらぎの院の地下に残る神殿（9章の潜入、オオナムチの名の取り戻し）
- 教師だった夫と娘ヒナの花の種（9章の救出、10章の脱出、エピローグの開花）
- 阻害ゲージが半分を切ったこと（9章でゼロに近づく）
- 凱旋の祝賀が三日後の夜（9章の潜入の好機）

新キャラ：ミオ（妻）とヒナ（娘、五、六歳）。名は日本風の仮名です。夫は名前未設定で、9章で救出される教師にします。

オオナムチの変化：ユウ一人を取り戻す誓いが、この街の消えた人々全体を取り戻す誓いへ広がりました。

ゲーム面：昼と夜の切り替え探索、阻害ゲージの表示、討論会での心鎮めの選択肢を織り込みました。

気になる点
- コトシロは、ベルが炉ヶ岳で細工に気づいていた前提で動いています。ベルの正体までは知らない設定のままです。
- 凱旋の祝賀と、タケルの視察の日程は、7章の翌日から数日後で矛盾しない形にしました。

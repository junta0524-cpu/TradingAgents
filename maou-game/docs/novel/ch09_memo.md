# 第九章　執筆メモ（ユーザー提供・原文）

約11,500字で、7場面の構成のまま書きました。視点は、コトシロ(①)、ベル(②⑥)、オオナムチ(③④⑤)、タケル(⑦)です。

回収した伏線
- コトシロの「写しを持ち出す」覚悟（8章の約束の実行）
- 削られた五柱の紋と、アメノミナカヌシが応えない窪み（クリア後の試練への伏線）
- ヒナの父と花の種の約束（10章の脱出、エピローグの開花）
- 炉番の「火は作り直す力」（怒りを壊す方から作り直す方へ向け直す場面）
- 阻害ゲージが尽き、輪郭が揺らぐ描写（10章の看破へ）
- 魔界の収穫祭前夜の祈りと、オオナムチの祈りが同じ響きであること（共生の伏線）

ゲーム面：潜入（見張りの隙を突く）、入所者の保護、祈りイベント（四柱を選んで呼び、五柱目は灰色）を織り込みました。

修正点が1つあります：祈りのツクヨミの項は、旅で触れた言霊が少ないため、「見破り」（ヒエダの名の出た言霊）を使いました。ストーリー上は最小限の習得という設定どおりです。

気になる点
- ヒナの父の名は、まだ付けていません。10章の脱出か、エピローグで決めたいです。
- 入所者全員は連れ出せていません。10章の脱出の流れで、残りの扱いを決める必要があります。
- 8章で決めた「ベルは魔王の姿に戻りかけ、10章で露見」という流れに、そのまま接続できます。

# 第十章　執筆メモ（ユーザー提供・原文）

約10,500字で、6場面の構成のまま書きました。視点は、タケル(①)、オオナムチ(②④⑤⑥)、ベル(③)です。脱出の群像（④）は、オオナムチ視点で短く重ねました。

回収した伏線
- 3章の牢と、7章の「どこかで……」が、①で確信に変わりました。
- 4章の「顔がはっきり見える」は、②の「ああ、だからか」で回収しました。
- 4章の「手紙の届け物を、一緒に運んだ奴だから」は、③で台詞にしました。
- 6章の偽りの納品は、④で兵の剣を止めました。
- 8章・9章のヒナの父と花の種は、⑤で再会を描きました。
- 2章の「顔を見なかった」蹂躙との対比を、③の「今は、見える」で出しました。
- 1章の「お帰りなさい」の定型を、⑥で使いました。

設計の変更：先にお伝えしたとおり、魔界での修行は11章の冒頭へ移しています。10章は、魔界到着と四天王の出迎えで終えました。

ゲーム面：看破イベント、偽名の剥離（阻害ゲージのゼロ）、脱出イベント（臨時の仲間が順に登場）、魔界の拠点化の導入を織り込みました。

気になる点
- ユウは、ハルの名で一瞬だけ止まりましたが、完全には解けていません。回復は、決戦後です。
- ヒナの父は、まだ名前が決まっていません。エピローグまでに決めたいです。
- タケルの「次は、剣を交える」という台詞が、11章の決戦の導入になります。

# 第十一章　執筆メモ（ユーザー提供・原文）

約12,500字で、7場面の構成のまま書きました。視点は、オオナムチ(①③⑥)、ミカヅチ(②)、オモイカ(④)、ベル(⑤⑦)、タケル(⑥の一部)です。

回収した伏線
- 1章の「人間を収穫祭に招けるか」を、④で半分だけ叶えました。オモイカは随員の名をまだ口にできません。
- ミカヅチの「受けきった」誇りと、2章の手加減の悟りを、②で次の世代へ手渡しました。
- 四すくみの相性と、ナキメの言霊耐性の稽古を、⑥の「洗脳の呼吸を読む」勝ち筋に繋げました。
- 6章の「火は作り直す力」を、⑥の決め手（刃に乗せた火種）で回収しました。
- 4章の「半分ずつ」を、⑤で再び使いました。
- 3章の「どこかで」が、タケルの「俺は……何を……」へ繋がりました。

ゲーム面：魔界拠点の修行イベント（ミカヅチ、スサノ、ナキメ）、名呼びの入口（失敗しても進行可）、タケル戦（規定ターン経過＋HP5割以下で勝利、育成が足りていれば削り切りも可）を織り込みました。

気になる点
- 名呼びは、入口に触れるだけにとどめています。完成は12章の一度きりです。
- ⑥の最後で、ベルが血を出すほど拳を握っていたことを、オオナムチが「見えていた」と言う場面を足しました。構成案にはなかった追加です。
- ヒナの父、ヒナの花、ユウの回復は、12章以降へ持ち越しです。

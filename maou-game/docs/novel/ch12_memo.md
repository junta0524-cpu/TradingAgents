# 第十二章　執筆メモ（ユーザー提供・原文）

約13,800字で、7場面の構成のまま書きました。視点は、クナド(①)、オオナムチ(②⑤⑥)、ベル(③)、タケル(④⑦)です。

対になる構造：王は名を奪い、オオナムチは名を呼ぶ。②の名の剥奪と、⑥の三度の名呼びを、鏡写しに配置しました。

首を刎ねる必然性：兵とタケルの槍と剣が迫り、クナドが身を盾にしている状況を⑤に置き、「他に誰も救えない最後の一手」として描きました。王は最期まで「なぜ私が」と言い、自分の邪悪さを理解しません。

回収した伏線
- 11章でベルが握りしめた拳の血を、③でもう一度使いました。
- スクナの「命を繋ぐ手」を、⑥の名呼びで回収しました。
- 6章の偽りの納品の剣を持つ若い兵が、⑦で最初に武器を置きます。
- オモイカの「あの時も、最後に、この顔をしました」を、①で回収しました。
- 4章の「半分ずつ」を、⑦の最後に置きました。

ゲーム面：王戦は詠唱ゲージを遮りながら核心へ踏み込む形式です。名呼びは、4系統の育成が足りなくても、クナドの補助で届く救済ルートを残せます。

気になる点
- 構成案から、王の言霊の二段目でタケルの名まで削る描写を足しました（④）。⑥で名呼びが必要になる理由づけです。
- 11章の「俺は……何を……」から、⑦の覚醒までが連続して読めるよう、④のタケルの内面に「あの人たちは、俺を殺さなかった」を入れています。
- ユウの回復、ヒナの父の名、花の開花は、エピローグへの持ち越しです。

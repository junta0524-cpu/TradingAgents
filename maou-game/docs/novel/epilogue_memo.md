# エピローグ　執筆メモ（ユーザー提供・原文）

『魔王が仲間になりたそうな顔でこちらを見ている』全12章＋エピローグが、これで完結しました。

約8,800字。七つの断章を、タケル、ハル、ヒナ、オモイカ、ベル、オオナムチ、ベルの視点で重ねました。

回収した伏線
- 2章の兵士の手紙（宛名ミサキ、続きは探し続ける）
- 4章の「元気だよ」の約束（ユウ、ハル）
- 8章・9章・10章の花の種と、ヒナの父の名（カズミ）
- 1章・3章・11章のオモイカの随員の名（ササラ、フミト、ツバメ、残り十一人）
- 1章の「収穫祭に人間を招けるか」と、タイトル回収の盃の台詞
- 「半分ずつ」の最後の使用
- 9章の五つ目の窪み（クリア後の試練への導入）

「十四人」は、三人＋十一人の合計です。会談の随員数は、1章では明示していないので、この数で確定させます。

名前（ササラ、フミト、ツバメ、ミサキ、カズミ）は、確認の上で決めた案を使っています。変えたい場合はお知らせください。

# **第四章（加筆版・試作）　荒れ地の道**

# **五**

街を出て二刻ほど歩くと、道は荒れ地に入った。

石畳は、いつの間にか踏み固めた土に変わり、その土も、少しずつ砂利に削られていった。道の両側に続いていた畑の畝は途切れ、かわりに、背の低い草と、白っぽい岩が、ぽつりぽつりと現れた。港の潮の匂いは、もう届かない。乾いた風が、草の根元を鳴らしていた。

荷は、オオナムチが背負った。ベルが半分持つと申し出たが、断った。初めての依頼だ。自分の足で運びたかった。

背中の荷は、思ったより重かった。薬草の包みは軽いが、塩の袋が肩に食いこむ。布の反物は、歩くたびに、腰のあたりで揺れた。紐の結び目が、外套の継ぎ当てに引っかかる。オオナムチは、歩きながら何度も背負い直した。

ベルは、半歩後ろを、黙って歩いていた。足音が、ほとんどしなかった。

(静かな人だな)

オオナムチは、そう思った。同行を申し出たくせに、道中、ほとんど話しかけてこない。かといって、気詰まりな沈黙ではなかった。風の音と、自分の足音と、時々、荷の紐のきしむ音。そこに、もうひとつの気配が、静かに混じっているだけだった。

太陽が、真上に近づいた。影が、足元に縮まっていく。

道の先に、ひとかたまりの岩場が見えた。大きな岩が、折り重なるように積まれ、その隙間に、濃い影が溜まっている。

ベルの足が、わずかに止まった。

オオナムチは、気づかなかった。ただ、ふと、風の音が、変わった気がした。草が鳴らなくなった。鳥の声も、いつの間にか、途切れている。

荒れ地の岩陰から、唸り声が聞こえたのは、日が高くなったころだった。

低く、喉の奥で擦れるような音だった。ひとつではない。重なって、ゆっくりと、近づいてくる。

オオナムチの体が、固まった。短剣の柄に手をかける。指が、細かく震えていた。革の握りが、掌の汗で滑る。

「出ましたね」

低い声で、ベルが言った。

驚いた様子は、なかった。まるで、天気の話でもするような声だった。

岩の陰から、野犬が三匹、姿を現した。痩せて毛が荒れているが、牙は鋭く、目が飢えている。あばらの形が、毛皮の上から数えられた。一匹が、じりじりと間合いを詰めてくる。残る二匹は、左右に広がり、こちらの退路を、静かに塞いでいった。

(やるしかない)

オオナムチは、短剣を抜いた。足が、地面に張りついたように重い。呼吸が浅い。頭の中が、白くなる。

訓練で習ったことも、集落で見聞きしたことも、すべて、どこかへ飛んでいた。残っているのは、荷を落としてはいけない、という、場違いな考えだけだった。

その時、不意に、口が動いた。

「――堅め」

自分でも驚いた。教わったことなどない。ただ、集落の年寄りが、子どもの頃に、木の実を取りに行く時に唱えさせてくれた短い言葉だった。身を守る、おまじない。まことの名を呼べば、誰でも基礎の力は引き出せる。

体の周りに、薄い膜のような感触が走った。守りの言霊が、立ち上がった。

膜は、薄く、頼りなかった。けれど、肌の外側に、確かに、もうひとつの皮があった。風が、少し、遠くなった。

野犬が、飛びかかってきた。

灰色の塊が、一直線に、迫った。オオナムチは、思わず目を細めた。

オオナムチは、短剣で払った。刃が毛を掠めただけで、犬は怯まない。着地した足が、砂利を蹴り、二匹目が、脇から回り込んでくる。牙の間から、白い息が洩れていた。

(だめだ、囲まれる)

視界の端で、ベルが動いた。

ベルは、剣を抜かなかった。ただ、一歩だけ、足を出した。それだけで、三匹目の犬の軌道が、わずかに逸れた。犬は、勢いのまま岩に当たり、悲鳴を上げて転がった。

乾いた音が、岩場に響いた。

オオナムチは気づかなかった。目の前の犬に、必死だった。

左腕に、衝撃が走った。牙が食い込み、堅めの膜が軋む。痛みで視界が滲んだ。犬の顎の力が、骨まで届く。熱い唾液が、袖を濡らした。

「うわっ……!」

「落ち着け。膜は破れていない」

ベルの声が、すぐ後ろから聞こえた。落ち着いた声だった。あまりに落ち着いていて、オオナムチは、一瞬、痛みを忘れた。

「痛みの形を、思い浮かべろ。それを、癒やしてくれと願うんだ」

「癒やし、って、そんな、いきなり」

「できる。君は、もう守りの言霊を出している。同じ力の、反対の側だ」

オオナムチは、歯を食いしばった。腕の痛みを見る。牙の跡。滲む血。袖の下で、脈が、どくどくと打っているのが分かった。それを、元の形に戻してくれと、願った。

(戻れ。……戻ってくれ)

「――癒やし」

ふわりと、温かいものが腕を包んだ。春先の陽だまりに、手を差し入れたような温度だった。傷口は完全には塞がらなかったが、血が止まり、痛みが引いた。

犬が、一匹、怯んだように後ずさった。二匹目も、足を止める。

ベルが、一歩、前に出た。

何をしたのか、オオナムチには分からなかった。ベルは、剣を抜かず、ただ、野犬たちを静かに見ただけだ。背が高いわけでも、声を荒げたわけでもない。それなのに、三匹の犬は、尾を巻いて、岩場の向こうへ逃げ去った。足音が、遠ざかっていった。

荒れ地に、風の音が戻った。

草が、また、さわさわと鳴った。遠くで、鳥が、一声鳴いた。

オオナムチは、その場に座り込んだ。足から力が抜けていた。短剣を握る手は、まだ震えている。指を開こうとしても、すぐには開かなかった。

「やった……のか、俺が」

「君が、守って、癒やした」

ベルは、静かに言った。

「いい動きだった」

オオナムチは、顔を上げた。嬉しい、と思った。同時に、不思議に思った。最後の一撃を、自分は放っていない。それでも、ベルは、自分の手柄のように言ってくれた。

ベルは、背を向けたまま、息を整えていた。

(危なかった)

力を抑えるのが、これほど難しいとは思わなかった。ほんの一歩、足を出しただけで、野犬は、必要以上に吹き飛びかけた。軌道を逸らすだけにとどめるのに、神経を使い果たした。掌の内側に、嫌な汗が、滲んでいた。

魔界では、力は、示すものだった。示せば、争いは起きずに済んだ。ここでは、逆だ。隠さなければ、守れない。

それでも、収穫はあった。

オオナムチは、教わらずに堅めを唱えた。誰に導かれたのでもなく、ただ、守りたいという願いが、そのまま言霊になった。癒やしも、一度の助言で形にした。

(才がある)

血統ではない。努力の積み重ねでもない。もっと、素朴な、人を守りたいという性質そのものが、言霊を呼んでいる。

オオナムチの腕の傷を、ベルは見た。左腕に、牙の跡が残っている。袖には、血と泥が、まだらに染みていた。

(私がいなければ、致命傷になっていたかもしれない)

守る側に立つというのは、こういうことか、とベルは思った。力を抑えながら、相手が傷つきすぎないように、気づかれない場所で動く。魔界で、民を守る時には、考えもしなかった。力を見せることでしか、守ったことがなかった。

岩場の向こうで、風が、小さく渦を巻いた。さっきの犬たちの足跡が、砂の上に、点々と残っている。それは、すぐに、風に消された。

「行こう。日が暮れる」

振り返ったベルは、できるだけ穏やかな声で言った。

# **前日譚　ベルイザナ　宮の書庫**

夜の書庫は、紙の匂いがした。

若者は、蝋燭を一本だけ灯して、床に座っていた。膝の上に、古い巻物が広げてある。端が、虫に食われて、茶色く縮んでいる。宮の者は、誰も、この書庫に来なかった。ここにあるのは、戦に役立たない昔話ばかりだったから。

黒い髪を、無造作に束ねていた。額の脇の角は、まだ、小さい。背の翼は、窮屈そうに畳まれて、棚の影に、触れていた。

(魔界の、古い昔話)

そう、表紙に書いてあった。

ページを、めくった。

『むかしむかし、白い兎がいた』

字は、掠れていた。蝋燭を、近づけた。

『兎は、波の向こうから渡ってきて、ひとり、岸に打ち上げられた。毛皮は、すっかり剥がれて、赤い肉が、むき出しになっていた』

若者は、息を止めた。

『そこへ、幾人もの神が、通りかかった。兄の神々は、兎に言った。海の塩水を浴びて、風に当たっていなさい。そうすれば、治るだろう。兎は、言われたとおりにした。すると、肉が裂け、痛みは、ひどくなるばかりだった』

(ひどいことを)

若者は、眉を寄せた。

『泣いている兎のところに、最後に、末の弟の神が、やってきた。大きな袋を背負った、いちばん年若い神だった。神は、泣いている兎を見て、足を止めた』

蝋燭の炎が、一度、揺れた。

『神は、尋ねた。どうして、泣いているのか。兎は、事情を話した。神は、静かに頷いて、言った。川の水で、体を洗いなさい。蒲の穂を、敷いて、その上に、寝なさい』

若者は、ページを、そっと、押さえた。

『兎は、言われたとおりにした。すると、毛皮は、ふたたび生えて、もとの白い兎に戻った』

『兎は、神に、尋ねた。あなたは、どなたですか。神は、答えなかった。ただ、傍らに、小さな影が、ひとつ、あった。手のひらに乗るほど小さな神が、袋の口から、顔を出して、笑っていた』

(小さな神)

若者は、その一文を、指でなぞった。

『薬と、まじないを司る、小さな神だった。大きな神が、袋を担いでいる間、小さな神は、傷に薬を塗り、まじないを唱えた。二人は、いつも一緒に、国じゅうを、歩いた』

巻物は、そこで、途切れていた。

若者は、長いあいだ、動かなかった。

(薬を、教えた神)

(名を、呼ばれなかった神)

昔話は、末の弟の神の名を、一度も、書いていなかった。兎を助けた者は、名もなく、ただ、末の弟とだけ、呼ばれていた。

(どうして、名前が、ないのだろう)

そのとき、背後で、扉が、小さく、軋んだ。

「ここにおいででしたか」

細い声がした。振り向くと、一人の若い参謀が、立っていた。灰色の瞳。静かな物腰。まだ、頬に、少年の面影が、残っている。

「オモイカ」

「夜更けです。灯りが、見えたので」

オモイカは、蝋燭の傍まで来て、巻物を覗きこんだ。

「昔話、ですか」

「ああ。白い兎の」

「ああ。あれは、子どもの頃、読み聞かされました」

オモイカは、ふっと、笑った。

「兎は、最後に、どうなるのでしたか」

「元に戻る」

「そうでした」

「だが、助けた神の、名が、ない」

若者は、巻物の端を、指で押さえた。

「どうして、書かれていないんだ」

「さあ」

オモイカは、少し、考えた。

「あるいは、書かなかったのかもしれません」

「書かなかった?」

「はい。助けた者の名は、助けられた者が、胸に持っていればよい。そういう考えが、昔は、あったと聞きます」

「……胸に」

「ですが、胸に持つ者がいなくなれば、名は、消えます。この昔話のように」

若者は、黙った。

蝋燭の炎が、ゆらゆらと、壁に影を作った。二人の影が、書棚の上に、長く、伸びていた。

「オモイカ」

「はい」

「おまえは、宮の者の名を、全員、覚えているのか」

「覚えようとしています」

「どうやって」

「顔と、名と、好きなものを、ひとつずつ。毎晩、帳面に、書き写して」

オモイカは、懐から、小さな帳面を、取り出した。ページの端が、擦り切れていた。

「千人は、おります。まだ、半分も」

「半分か」

「半分です」

若者は、その帳面を、しばらく、見つめた。

「……俺にも、教えてくれ」

「え」

「名を。顔を。好きなものを。俺は、何も、知らない」

オモイカは、目を、丸くした。それから、静かに、微笑んだ。

「承知しました。では、明日の朝から」

「ああ」

若者は、巻物を、巻き直した。蝋燭を、吹き消す前に、もう一度だけ、あの一文を、目で、追った。

『薬と、まじないを司る、小さな神だった』

(名を、呼べば、傷は、塞がるのか)

答えは、まだ、分からなかった。

ただ、胸の奥で、小さな決意が、ひとつ、静かに、灯った。

(俺は、名を、覚える)

誰かの名を、呼べる者になる。

その夜から、若者の隣には、いつも、小さな帳面があった。

のちに、魔王と呼ばれる日が来ても。

その帳面だけは、懐から、手放さなかった。

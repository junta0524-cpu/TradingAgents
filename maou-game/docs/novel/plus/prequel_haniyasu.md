# **前日譚（試作）　ハニヤス　最初の一株**

黄泉の空は、昼でも薄く赤い。その下の谷には、草の一本も生えていなかった。

ハニヤスは、膝をついて、土に両手を埋めていた。

掌に伝わるのは、冷たさだった。冷たいだけではない。土の底から、じわじわと上ってくる、重いものがある。瘴気だ。この谷の土は、何百年も前に、それを吸いこみすぎた。踏めば固く、掘れば黒く、種を蒔いても、芽の形になる前に、腐った。

(それでも)

指先で、土を崩す。粒をひとつ、ひとつ、確かめるように、ほぐしていく。

土蜘蛛族は、土の民だった。地の下の道を知り、地脈の流れを読む。けれど、その力は、争いのために使われてきた。穴を掘り、罠を張り、敵の足元を崩す。ハニヤスの祖父も、父も、そうして死んだ。

(土は、壊すだけのものじゃない)

そう思ったのは、子どもの頃だった。

祖母が、小さな革袋を、枕の下に隠していた。中には、乾いた籾が、数十粒、入っていた。

「これは、遠い昔の、人間の国の稲だよ」

祖母は、そう言った。

「土蜘蛛が、まだ、畑を耕していた頃の。ひと粒でも、芽が出れば、また、増える」

「芽は、出るの」

「出るさ。土を、起こしてやればね」

その祖母も、もういない。

革袋だけが、ハニヤスの懐に、残っていた。

谷の入口のほうで、砂利を踏む足音がした。

ハニヤスは、手を止めなかった。

足音は、ゆっくりだった。ひとり。いや、少し離れて、もうひとり、ふたり。供の者が、いるらしい。

「何を、している」

低い声が、背中に降りた。

ハニヤスは、振り返った。面の奥から、相手を見上げた。

黒い角を二本、額の脇に戴いた男が、立っていた。まだ若い。けれど、その立ち姿には、周りの空気を変えてしまう重さがあった。魔王。噂だけは、聞いていた。

「畑を、作っている」

「畑」

男は、谷を見回した。草一本ない、赤茶けた斜面を。

「ここで?」

「ここで」

「瘴気が、染みているだろう」

「ああ。だから、起こしている」

「起こす」

「土の底の、重いやつを、少しずつ、押し戻す。時間は、かかる」

男は、しばらく黙っていた。それから、ゆっくりと、ハニヤスの横に、並んで、しゃがんだ。

供の者が、慌てたように、一歩、踏み出した。

「王、お召し物が」

「いい」

王は、片手を上げて、制した。それから、土に、指を差し入れた。

「……冷たい」

「そうだ」

「どれほど、かかる」

「十年。ものによっては、もっと」

「十年」

王は、笑った。呆れたようでもあり、楽しそうでもあった。

「十年も、ひとりで、ここを掘るつもりか」

「ひとりでは、やらない」

ハニヤスは、懐の革袋を、取り出した。

「こいつがいる」

王は、袋の中の、小さな粒を、見た。

「それは」

「籾だ。祖母の形見だ。遠い昔の、人間の国の稲」

「芽が、出るのか」

「分からない。出ないかもしれない」

「出なかったら」

「また、土を、起こす」

王は、しばらく、何も言わなかった。

風が、谷を渡った。赤茶けた斜面を、砂塵が、細く舞い上がった。

「俺の民は、」

王が、ぽつりと言った。

「戦うことしか、知らない者が、多い」

「ああ」

「おまえは、違うのか」

「分からない。ただ、壊す土より、育つ土のほうが、いい。それだけだ」

王は、もう一度、笑った。今度は、まっすぐな笑い方だった。

「名は」

「ハニヤス」

「埴の安らぎ、か。いい名だ」

「祖母が、付けた」

「ハニヤス」

王は、確かめるように、その名を呼んだ。

「この谷を、おまえに預けよう。供も、道具も、必要なものは、言え」

「いらない」

「いらない?」

「ひとりで、やる。それが、土への礼儀だ」

王は、目を丸くした。それから、肩を揺らして、笑った。

「頑固者だ」

「それも、祖母に似た」

王は、立ち上がった。裾に付いた土を、払おうとして、やめた。

「また、来る」

「好きにしろ」

「十年たつ前に、来る」

その背中が、谷を出ていくのを、ハニヤスは、見送らなかった。

土に、籾を、ひと粒、置いた。

掌で、そっと、覆った。

季節が、ひとつ、変わった。

谷は、まだ、赤茶けていた。けれど、ある朝、ハニヤスの掘った畝の端に、緑色の、針のようなものが、ひとつ、顔を出していた。

ハニヤスは、息を止めた。

小さい。細い。風に、折れそうなほど。

それでも、それは、確かに、生きていた。

(出た)

声には、出さなかった。ただ、面の奥で、唇が、わずかに、震えた。

そのとき、谷の入口から、足音が、聞こえた。

早い。一年も、たっていないのに。

ハニヤスは、顔を上げた。

王が、供も連れず、ひとりで、立っていた。

「来たぞ」

「早い」

「待ちきれなくてな」

王は、畝のほうへ、歩いてきた。

足が、まっすぐ、芽のほうへ、向かっていた。

「王よ、そこは踏むな」

ハニヤスの声が、飛んだ。

王は、片足を上げたまま、固まった。

地面に、小さな緑が、あった。

王は、ゆっくり、足を下ろした。ひとつ、横の土に。それから、屈みこんで、その芽を、長いこと、見つめていた。

「……生えたのか」

「ああ」

「これが」

「これが、最初の一株だ」

王は、顔を上げた。目が、少しだけ、濡れて見えた。

「ハニヤス」

「何だ」

「この谷を、もう一度、俺に見せてくれ。十年後に」

「ああ」

「そのときは、ここが、全部、緑になっているか」

「なる」

ハニヤスは、はっきり、言った。

「俺が、そうする」

王は、頷いた。

赤い空の下で、小さな緑が、風に揺れていた。

それが、のちに、黄泉の民を飢えから救うことになる、畑のはじまりだった。

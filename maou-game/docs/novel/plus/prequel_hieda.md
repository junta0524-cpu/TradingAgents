# **前日譚　ヒエダ　糸の見える目**

葛の里の夜は、語りから始まる。

ヒエダは、石の広場の真ん中に置かれた、低い腰掛けに座っていた。藍色の外套の裾が、焚き火の光に、ゆらゆらと染まっている。足元には、里の子どもたちが、ぐるりと輪になって座っていた。

「今夜は、どの話がええ」

子どもたちが、口々に叫んだ。

「風の岩溝の龍!」

「迷子の仔狐!」

「ヒエダ爺さまが、若かった頃の話!」

「それは、つまらん話じゃ」

ヒエダは、白い髭を撫でて、笑った。

「ならば、今夜は、目の話をしよう」

「目?」

「そうじゃ。ひとの、目の話じゃ」

子どもたちは、顔を見合わせた。焚き火が、ぱち、と爆ぜた。

「わしの目は、少し、変わっておる。ひとの背中に、糸が見えるんじゃ」

「糸?」

「そうじゃ。細い、細い糸じゃ。ひとが、何かを強く思うとき、その思いが、糸になって、背中から伸びる。優しい思いは、金の糸。怒りは、赤い糸。悲しみは、青い糸」

子どもたちは、息を呑んだ。

「爺さまにも、糸があるの?」

「あるとも。白い糸が、一本、ある」

「白は、何の思い?」

「さあ。何じゃろうなあ」

ヒエダは、遠い目をした。

その夜の語りを終えて、子どもたちを家へ帰したあと、ヒエダは、一人、広場に残った。

焚き火の灰が、ゆっくり、冷えていく。夜風が、里の石垣を、さらさらと撫でていった。

(今日は、少し、変じゃった)

昼間、里の門を通った、旅の商人のことが、頭から離れなかった。

白い礼装の、感じのいい男だった。柔らかい声で、挨拶をして、里の者に、小さな飴を配った。子どもたちは、喜んで、飴を受け取った。

けれど、ヒエダの目には、見えていた。

その男の背中から、細い糸が、無数に、伸びていた。

金でも、赤でも、青でもない。ただ、透き通った、白い、糸。それが、どこか、遠くの空へ、一本の束になって、伸びていた。

(あれは、何じゃ)

長いこと、ひとの糸を見てきた。けれど、あんな糸は、見たことがなかった。誰かの思いではない。誰かに、繋がれた糸。引かれる側の、糸だった。

(操られておる)

男は、それに、気づいていなかった。穏やかな顔で、笑っていた。善意の塊のような、柔らかい目をして。

ヒエダは、その背中を、黙って、見送った。

声をかけなかった。かけたところで、何が言えただろう。あなたの背に、糸がありますよ、などと。

それが、悔やまれた。

その日から、ヒエダは、里を訪れる者の背中を、より注意深く、見るようになった。

旅の商人。入植者。役人。兵。

どの者の背にも、金や赤や青の糸が、揺れていた。けれど、時折、あの白い糸が、混じっていた。

(増えておる)

最初は、一人。やがて、三人。五人。

この世界に、何かが、静かに、広がっている。

ヒエダは、それを、誰にも話さなかった。話しても、誰も、信じないだろう。里の者は、善良で、疑うことを知らない。

だから、ヒエダは、ただ、見ることにした。

里の語り部として、石の腰掛けに座り、子どもたちに、昔話を聞かせながら。

その輪の外側で、静かに、世界の糸を、数え続けた。

ある夜、語りの輪の隅で、小さな少年が、ヒエダに、聞いた。

「爺さまの目は、いつか、誰かを、助けられる?」

「さあ、どうかのう」

ヒエダは、少年の頭を、撫でた。

「だが、見えるということは、助けられる日が、来るかもしれんということじゃ。見えんより、ずっといい」

「そっか」

少年は、安心したように、笑った。

その少年の背中には、柔らかな、金の糸が、ひとつ、揺れていた。

ヒエダは、その糸を、そっと、胸の内で、見守った。

のちに、ひなた野の青年と、黒髪の男が、里を訪れたとき。

青年の背に、白い糸が、絡みつきかけているのを、ヒエダは、見つけた。

そして、その糸を、断ち切るために、この老骨の目を、使う日が来ることも。

この夜は、まだ、知らなかった。

# **前日譚　カナメ　火床の夜明け**

炉の火は、夜明け前に、いちばん赤い。

カナメは、工房の炉の前で、ふいごを踏んでいた。山の朝は、まだ暗い。窓の外では、谷の底から、冷たい霧が、白く立ち上っていた。炉の口から漏れる赤い光が、カナメの短く刈った髪を、橙色に染めていた。

「早いな」

背後から、低い声が、した。

「じいちゃん」

「寝ていていいと言ったはずだが」

イシコリドメは、赤い髭を揺らして、笑った。炉の前に、腰を下ろす。

「眠れなくてな」

「私も」

二人は、しばらく、黙って、炉の火を見ていた。

カナメは、十七歳だった。この里で、いちばん若い鍛冶だった。女の鍛冶は、里に、ほとんどいない。祖父に仕込まれて、十二の年から、槌を握ってきた。腕は、まだ、祖父に及ばない。けれど、刃の肌を見る目だけは、里で、いちばんだと言われていた。

「カナメ」

「何」

「おまえは、なぜ、鍛冶をやる」

唐突な問いだった。

「なぜって」

カナメは、少し、考えた。

「手が、勝手に、動くから」

「それは、答えになっておらん」

「じゃあ、じいちゃんは、なぜ」

「儂か」

イシコリドメは、炉の火を、見つめた。

「若い頃は、強い剣を、打ちたかった。誰にも折られぬ、誰にも負けぬ剣をな。でも、いつからか、変わった」

「何に」

「一本の刃が、誰の手に握られるのか。それを、考えるようになった」

祖父は、傍らの鉄床に、手を置いた。何十年も、同じ場所に、置かれてきた手だった。指の節は、瘤のように、盛り上がっていた。

「鍬は、畑を耕す手に。鎌は、麦を刈る手に。鍋は、飯を炊く手に。刃は、握る者に、似る。儂は、そう思う」

「だから、鍛冶は、道具を打つ、と」

「そうだ」

「戦の剣は、だめなの」

「だめ、とは言わん」

祖父は、静かに首を振った。

「だが、剣が、誰のために振るわれるのか。それを、知らずに打つ剣は、儂は、嫌いだ」

カナメは、炉の火を、見た。赤い炎が、ゆらゆらと、揺れていた。

(誰のために)

その言葉が、胸の奥に、ひとつ、小さな石のように、落ちた。

「カナメ」

「うん」

「おまえが、打つ刃には、おまえが握らせたい手が、ある」

「握らせたい手」

「見つけるといい。いつか」

夜が、少しずつ、明けてきた。窓の外の霧が、薄い金色を、帯び始めた。

工房の戸が、からりと開いた。

「親方、お早うございます」

若い職人が、数人、入ってきた。誰もが、眠そうな顔をしていたが、炉の火を見ると、自然と背筋が伸びた。

「おはよう」

カナメは、立ち上がった。

「今日の分、準備できてる」

「さすが、カナメ」

「当たり前でしょ。私は、この里の、鍛冶なんだから」

声が、少し、誇らしげになった。祖父が、目を細めて、頷いた。

その朝、カナメは、一本の小さな包丁を、打った。

里の、おばあさんのための包丁だった。手が小さく、力も弱い。だから、刃は、薄く、柄は、短く。握る手のことを、考えながら、打った。

(誰のために)

槌を振るたびに、その問いが、胸に、響いた。

包丁が、焼き入れを終えて、水の中で、じゅっと鳴った。

湯気の向こうに、小さな刃が、光っていた。

それが、カナメの、最初の「握らせたい手」だった。

のちに、里に、官吏が来て、百本の剣を求めるとき。

カナメは、この朝の、小さな包丁を、思い出す。

(私の刃は、誰の手に、握られるのか)

その問いが、のちの怒りの、いちばん深い根になった。

# **前日譚　コノハ　半分の耳**

薬草を刻む音は、ひとりの音だ。

コノハは、森の端の小さな家で、まな板に向かっていた。包丁の刃が、青い葉を、規則正しく、刻んでいく。窓の外では、木々が、風に枝を揺らしていた。

(また、あの子たち)

窓の下を、エルフの子どもが三人、通りかかった。声を潜めて、こちらを指さしている。

「見て、半端者の家」

「耳が、短いんだって」

「人間の、血が混じってるから」

聞こえない振りをして、包丁を動かし続けた。葉の青い匂いが、鼻に上ってくる。指先に、緑の汁が、染みた。

(慣れてる)

そう、思った。何年も、同じ言葉を、聞いてきた。

母は、エルフだった。父は、人間だった。二人とも、もういない。残された自分は、尖った耳を持ちながら、寿命も背丈も中途半端な、どちらにもなれない存在になった。

エルフの森では、人間の血を引く者は、遠巻きにされる。人間の町では、尖った耳を持つ者は、石を投げられる。どちらにも、居場所がなかった。

だから、森の端に、家を建てた。集落の中心から、わざと離れた場所に。ここなら、誰にも、干渉されない。

昼下がり、戸を叩く音がした。

「コノハ。いるかい」

しわがれた声だった。戸を開けると、背の曲がった老人が、薬草の籠を、抱えて立っていた。

「スクナ」

「おう。いい葉が採れたでな。おまえさんに、分けてやろうと思って」

老薬師は、籠の中から、一束の葉を取り出した。淡い緑の、細かな葉だった。

「森の奥の、日陰にしか、生えん。熱を下げるのに、よう効く」

「……ありがとう」

コノハは、葉を、受け取った。

「どうした。浮かない顔じゃの」

「別に」

「嘘は、下手じゃな」

老人は、笑った。目尻に、深い皺が、寄った。

「子どもらに、何か言われたか」

「慣れてる」

「慣れるもんじゃない」

スクナは、ゆっくりと、言った。

「痛みに慣れたと言うやつは、痛みを、見ない振りを、覚えただけじゃ。傷は、見ない間にも、ちゃんと、膿んでいく」

コノハは、黙った。

老人は、家の中に、入ってきた。勝手に、椅子に腰を下ろした。

「おまえさんの耳は、半分じゃない」

「何?」

「半分じゃなくて、二つ分じゃ。エルフの耳と、人間の耳。両方で、聞こえる」

「何が、違うの」

「エルフの耳には、聞こえん声が、ある。人間の耳には、聞こえん声も、ある。おまえさんは、両方、聞ける」

コノハは、自分の耳に、そっと触れた。尖った先が、指先に、冷たかった。

「……そんなこと、考えたことなかった」

「考えてみるがいい」

スクナは、にっと笑った。

「おまえさんが、この森と、人間の町を、つなぐ日が、来るかもしれん」

「つなぐ?」

「そうじゃ。耳が、二つ分、あるんじゃからな」

その夜、コノハは、一人で、窓辺に座っていた。

月が、梢の間から、淡く、光を落としていた。

(二つ分)

そんな風に、考えたことは、一度もなかった。

耳を、指で、なぞった。

エルフの森の、風の声が、聞こえた。遠くの人間の町の、鐘の音が、聞こえた気がした。

(どちらも、聞こえる)

それが、重荷ではなく、ひとつの力だとしたら。

コノハは、立ち上がった。壁に掛けた弓を、手に取った。

(私は、半端者じゃない)

その言葉を、心の中で、一度だけ、繰り返した。

その後、森で、スクナが連れてきた二人の人間に、出会うことになる。

継ぎの当たった外套の青年と、黒い髪の、静かな男だった。

コノハは、その二人を見て、初めて、思った。

(この人たちとなら、耳を、二つ分、使えるかもしれない)

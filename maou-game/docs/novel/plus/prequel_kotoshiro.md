# **前日譚　コトシロ　目利きの帳面**

検品局の朝は、刃を見ることから始まる。

コトシロは、机の上に、納められた剣を、一本ずつ、並べていた。窓から差す朝の光が、鋼の表面に、細い線を引いた。袖をまくり、手袋を外す。素手で、刃の腹を、そっと撫でる。

(冷たい)

手のひらに、鉄の温度が、伝わってきた。

検品官になって、二十年になる。刃の良し悪しは、目で見るだけでは、分からない。手で、触れて、光に傾けて、音を聞いて。そうして、一本ずつ、鋼の声を、聞き取る。

「検品官殿、今日の分は、これで全部です」

若い書記が、帳簿を抱えて、入ってきた。

「ありがとう。そこに置いてくれ」

「はい」

書記は、そそくさと、出ていった。コトシロは、帳簿を、開いた。

そこには、剣の本数と、納入者の名が、記されている。炉ヶ岳。ミナモ。葛の里。いくつもの名前が、整った字で、並んでいた。

(皆、顔があるはずなのに)

コトシロは、いつも、そう思う。

刃は、顔を持たない。けれど、一本ごとに、癖がある。炉ヶ岳の剣は、重く、真っ直ぐだ。ミナモの剣は、軽く、しなやかだ。同じ炉ヶ岳の剣でも、鍛冶によって、刃の肌が、違う。

(これは、イシコリドメ殿の)

鋼の波紋を、指でなぞって、そう呟いた。

見れば、分かる。名が書いてなくても。

その夜、コトシロは、帳簿を持って、自分の部屋に戻った。机の引き出しから、もう一冊、古い帳面を、取り出す。

表紙は、すり切れていた。中のページには、日付と、剣の本数と、鍛冶の名前が、びっしりと、書き込まれている。

それは、検品官の仕事とは、別の、コトシロ個人の、帳面だった。

『炉ヶ岳　イシコリドメ　十本　重く、真っ直ぐ。誠実な手』

『炉ヶ岳　カナメ　三本　若い刃。迷いが少ない。伸びる』

『ミナモ　ハルオ　五本　軽い。癖が強い』

二十年、書き溜めてきた。誰に見せるためでもなく。

(名前を、書いておきたい)

そう思ったのが、最初だった。

刃を打つ者の名は、帳簿の、小さな欄に、記されるだけだ。軍に納められた剣は、いつしか、ただの「数」になる。三百本。五百本。誰が、どんな手で、打ったのか。そこまでは、誰も見ない。

でも、自分は、見たかった。

最後のページに、今日の分を、書き足した。

『炉ヶ岳　刃の芯に、わずかな艶の違い。理由は、不明。要観察』

筆が、止まった。

(これは、何だろう)

ここ数か月、納められる剣の、一部に、見慣れない艶があった。鋼の波紋とは、別の、薄い膜のような光だった。

(気のせいだ)

コトシロは、帳面を、閉じた。

引き出しに、しまう手が、わずかに、震えていた。

のちに、その艶の正体が、アマツ王の言霊だと、知ることになる。

そして、この帳面の、「要観察」の一行が、何百という名を救う、最初の手がかりになることも。

その夜、コトシロは、そうとは、少しも知らず、灯りを消した。

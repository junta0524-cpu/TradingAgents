# **前日譚　クナド　足音のない道**

大穴の縁に、風が吹いていた。

クナドは、岩の上に、ひとり、立っていた。背が高く、肩は細い。白い目が、静かに、底のない闇を見下ろしている。足元の石は、乾いて、冷たい。けれど、彼の足は、石の上に、一つの音も、立てなかった。

岐人は、足音を持たない。境に立つ者の定めだった。

「クナド様」

背後から、若い岐人が、駆け寄ってきた。足音は、しない。ただ、衣の裾の擦れる音だけが、風の中に、小さく混じった。

「長老が、お呼びです」

「分かった」

短く答えて、クナドは、岩を降りた。

岐人の集落は、大穴の北の崖に、岩を穿って作られていた。薄暗い洞窟の奥に、白い石の広間がある。そこに、年老いた長老が、座っていた。

「来たか、クナド」

「はい」

「そなたに、次の見届けを、任せたい」

長老は、静かに言った。

「魔界と人間界の、会談じゃ。大穴の縁に、白い建物が建つ。そこで、両陣営が顔を合わせる」

「両陣営の」

「そうじゃ。立会人として、そなたが立つ」

クナドは、黙って、頭を下げた。

「何か、言うことは」

「いえ」

「相変わらず、言葉の少ない子じゃのう」

長老は、苦笑した。

「じゃが、見届け人には、それが、よい。多くを語る者は、多くを、傾ける」

「傾ける」

「どちらかへ、じゃ。見届け人が、傾いてはならん。境の血を引く者は、いつも、真ん中に立つ」

クナドは、頷いた。

その夜、集落の外れの岩場で、クナドは、ひとり、座っていた。

月が、細く出ていた。大穴の闇は、月の光を、飲みこんでしまう。底から、冷たい息が、上がってきていた。

(大穴の底には)

クナドは、そこに何があるかを、知っている。岐人は、境の番人だ。世界の始まりに、神々が、閉じこめたもの。名を喰う影。それが、深い底で、眠っている。

知っているが、語ったことは、一度もない。

語れば、人は、その影を、利用しようとするだろう。魔界の者も、人間の者も。

(だから、黙っている)

それが、岐人の、誓いだった。

「クナド」

細い声が、背後から、した。

振り返ると、幼い岐人の少女が、立っていた。白い目を、大きく見開いて、こちらを見上げている。

「どうして、クナドは、いつも、しゃべらないの」

「……」

「みんな、言ってる。クナドは、石みたいだって」

「そうか」

「石は、冷たいよ」

少女は、じっと、クナドを見た。

クナドは、少し、考えた。それから、ゆっくりと、口を開いた。

「石は、動かない」

「うん」

「動かないものは、倒れない」

「倒れたくないの?」

「倒れたくないのではない。倒れてはいけない」

「どうして」

「石が倒れると、道が、崩れる」

少女は、首を傾げた。

「道って、何の?」

「みなが、通る道だ」

クナドは、大穴の闇を、見た。

「魔界の者も。人間も。名を呼ばれる者も、呼ばれない者も。皆が通る、道だ。その道の、境に、立つ者が、倒れてはいけない」

少女は、しばらく、考えていた。それから、にっと、笑った。

「じゃあ、クナドは、石じゃなくて、橋だね」

「橋」

「うん。橋は、動かないで、みんなを、渡してあげるでしょ」

クナドは、目を、わずかに、見開いた。

(橋)

胸の奥で、何かが、静かに、鳴った。

「……そうか」

「でしょう」

少女は、得意げに、胸を張った。

クナドは、その頭を、ゆっくり、撫でた。

「ありがとう」

それが、少女の聞いた、クナドの、いちばん長い言葉だった。

のちに、会談の間が、血に染まる日。

クナドは、白い建物の隅で、立会人として、ただ、立っていた。

そして、坂上の砦で、勇者を背に負い、王の言霊に、「お断りします」と、静かに答える日が来る。

そのとき、彼の足は、大穴の縁に立った、あの夜と、同じ静けさで、石を踏んでいた。

橋は、倒れなかった。

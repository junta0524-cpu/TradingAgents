# **前日譚（試作）　ミカヅチ　受けきった日**

角ヶ原の風は、乾いていた。

岩肌を削った広い窪地に、鬼族の戦士が、ぐるりと並んでいた。赤銅色の肩が、日に焼けている。誰も口を開かない。腕を組み、足を広げ、ただ、窪地の中央を見ていた。

そこに、二人の男が立っていた。

ミカヅチは、金棒を地面に突き立てた。鬼族の頭領になって、五年になる。力で、そこへ上った。この角ヶ原で、自分より強い者に会ったことはなかった。

向かいに立つ男は、黒い外套を着ていた。額の脇に、黒い角が二本。背には、まだ、翼を畳んでいる。

「おまえが、新しい王か」

「そうだ」

「若いな」

「そう言われる」

男は、笑った。ちっとも腹の立たない笑い方だった。それが、ミカヅチには、かえって気に入らなかった。

「俺たち鬼族は、力に従う。口上は、要らん。拳で、示せ」

「分かった」

男は、外套を脱いだ。それを、傍らの若い鬼に、そっと預けた。若い鬼は、慌てて、両手で受け取った。

「では、先に、おまえの全力を見せてくれ」

「全力、だと」

「ああ。そのあとで、俺が一撃だけ打つ。それを、受けてほしい」

窪地を囲む戦士たちが、ざわめいた。

鬼族の頭領に、全力で打ち込ませる。それを言った者は、過去に二人いた。二人とも、立ち上がれなかった。

(命知らずが)

ミカヅチは、金棒を引き抜いた。

「後悔するぞ」

「しない」

男は、両足を、軽く開いた。それだけで、構えは、終わりだった。

ミカヅチは、息を吸った。腹の底に、力を溜める。鬼族の力は、怒りの力だ。怒りは、いつでも、胸の奥に溜まっていた。仲間を失った日の怒り。力のない者が踏みにじられるのを見た日の怒り。それを、一息に、腕へ流し込む。

「――ぬおおおッ！」

金棒が、唸りを上げた。

岩が割れるほどの一撃だった。窪地の砂が、輪になって、舞い上がった。

男は、受け止めた。素手の両腕で。足が、砂の中に、深くめり込んだ。それでも、後ろへ吹き飛ばなかった。

「……重いな」

口の端から、血が、一筋、流れていた。

「これが、鬼の力か」

ミカヅチは、言葉を失った。それから、もう一度、振りかぶった。三度、四度。全てを、ぶつけた。金棒を握る腕が、痺れて感覚をなくすまで。

男は、膝をつかなかった。

最後の一撃を受けとめたあと、男は、静かに、言った。

「では、俺の番だ」

窪地の空気が、凍った。

男の手が、ゆっくりと、持ち上がった。拳だった。ただの拳が、ミカヅチの胸へ、真っ直ぐに、向かってきた。

衝撃が、体の芯を、貫いた。

視界が、一瞬、白くなった。足が、地面を離れかけた。膝が、折れようとした。

(倒れる)

(倒れるものか)

奥歯を、噛みしめた。鬼族の頭領が、大勢の前で、膝をつく。それだけは、できなかった。誇りにかけて。

足を、踏みしめた。砂が、ざざ、と鳴った。

そして、ミカヅチは、立っていた。

荒い息の中、顔を上げた。男は、拳を下ろしたところだった。

「……見事だ」

静かな声だった。

「俺の拳を、受けきった者は、おまえが、初めてだ」

窪地を囲む戦士たちが、割れんばかりの歓声を上げた。

男は、血に濡れた手を、ゆっくりと、差し出した。

「ミカヅチ。おまえの誇りを、俺に、貸してくれ」

ミカヅチは、その手を、見つめた。

傷だらけだった。それなのに、握られるのを、少しも疑っていない手だった。

(この男は)

(倒れなかった俺を、称えた)

ミカヅチは、金棒を、地に置いた。

そして、その手を、握った。

「俺は、おまえに従う」

声が、思ったより、低く出た。

「力で、負けたわけではない。だが、おまえの前では、俺の力が、安く見える」

「安くはない」

男は、首を振った。

「俺の腕が、折れかけた」

ミカヅチは、思わず、笑った。腹の底から、笑いが、湧いてきた。

笑い声が、窪地に響いた。つられるように、戦士たちが、一人、また一人、笑い始めた。

その夜、角ヶ原では、祭り酒の樽が、いくつも開いた。

新しい王は、鬼族の若い者たちに囲まれ、杯を押しつけられていた。顔を赤くして、必死に断ろうとしていた。誰も、聞き入れなかった。

その様子を、ミカヅチは、少し離れた岩の上から、眺めていた。

(いい王だ)

そう、思った。

自分の強さは、あの王に、認められたのだ。受けきった者に、認められたのだ。そう思うと、胸の奥が、温かくなった。

その温かさが、長いあいだ、ミカヅチの誇りだった。

のちに、根の洲の黒い土の上で、あの日が、まったく違う意味を持つことになるとは、まだ、知らなかった。

あの王が、あの日、拳に込めたのは、受けきれる強さの、ちょうど手前だったのだと。

# **前日譚　ナキメ　底の見えない人**

鴉族は、噂を売って生きてきた。

ナキメは、黄泉の風の中を、翼を広げて、滑っていた。眼下には、赤みを帯びた大地が、静かに広がっている。畑も、川も、焼けた岩場も、すべてが、小さな地図のように、見渡せた。

背に、鴉族の長老から預かった、薄い巻物を負っていた。新しい王への、挨拶の文だった。

(新しい王、ね)

くすり、と笑いが、漏れた。

鴉族は、どの王にも仕えてきた。仕える、と言っても、従うわけではない。噂を運び、耳を貸し、時に、少しだけ、心に触れる。そうやって、どの王にも、「必要な存在」であり続けてきた。

鴉の長は、心の術に長けた者が継ぐ。ナキメは、その術で、魔界随一と言われていた。人の心に、そっと、指先を差し入れる。表面の薄い膜を、さらりと撫でる。それだけで、相手が、何を恐れ、何を隠しているか、およそ、読み取れた。

(王も、同じ)

どんな王にも、恐れがある。どんな力にも、隠したいものがある。

それを知っていれば、鴉族は、王の隣で、生き延びられた。

黄泉津の宮の、広間に通された。

高い天井。磨かれた石の床。窓の光が、白い筋になって落ちている。奥の席に、黒髪の男が、座っていた。

若かった。思っていたよりも、ずっと。

「よく来てくれた。鴉族の長だと聞いた」

男は、席を立って、迎えた。

(席を、立った)

ナキメは、わずかに、目を細めた。長が、使者を、立って迎える。先代の王には、ありえなかった。

「ナキメと申します。お言葉を、頂戴いたしたく」

「楽にしてくれ。堅い挨拶は、苦手でな」

男は、笑った。

(この笑み)

ナキメは、心の中で、そっと、指先を伸ばした。

挨拶のようなものだった。ほんの、表面を撫でるだけ。相手が、緊張しているか、虚勢を張っているか。その、ごく浅い層を。

(……え)

指先が、止まった。

触れる、はずの膜が、なかった。

虚勢も、緊張も、見栄も、ない。ただ、深い、水面のような静けさが、広がっていた。底が、見えなかった。

(深い)

そう思った瞬間、背筋が、ぞくりと、冷えた。

ナキメは、もう少しだけ、指を、沈めた。ほんのわずかな、好奇心だった。

そこで、感じた。

底の見えない水の中に、嘘が、なかった。

誰もが持っている、小さな偽りも。保身も。誰かをよく見せたい気持ちも。それらが、何ひとつ、なかった。ただ、深く、静かで、そして、とても孤独な何かが、そこにあった。

(この人は)

(私に、何も、隠していない)

隠していないのに、底が、見えない。

それは、恐ろしいことだった。隠しごとがあるなら、暴けばいい。けれど、隠しごとがない底の深さには、手の出しようがなかった。

ナキメは、そっと、指を、引いた。

「ナキメ殿？」

男が、少し、首を傾げた。

「……失礼しました」

ナキメは、深く、頭を下げた。膝が、わずかに、震えていた。

「少し、風に当たりすぎたようです」

「そうか。座るといい。茶を、用意させよう」

男は、自ら、椅子を引いた。

その手つきが、あまりに、自然で、ナキメは、顔を上げられなかった。

(この王は)

(私の術に、気づいたかもしれない)

気づいて、そのうえで、何も、言わなかった。

心に触れたことを、咎めもしない。笑って、茶に誘う。

その夜、ナキメは、鴉族の屋敷に戻ると、長老に、短く、告げた。

「あの方に、仕えます」

「ほう。心を、読んだか」

「読めませんでした」

「何」

「読めなかったのです。何も、隠していない人でした」

長老は、しばらく、黙っていた。それから、静かに、笑った。

「それは、一番、仕えがいのある王だ」

「はい」

ナキメは、窓の外の、赤い空を、見上げた。

嘘をつかない王には、嘘で仕えることは、できない。

(私も、嘘は、やめる)

そう、決めた。

鴉族の長として、生きてきて、初めて、自分に課した、決まりだった。

のちに、ベルイザナの前で、膝をつくたび、ナキメは、同じことを思う。

この方の底は、見えない。けれど、嘘が、ない。

その矛盾が、体を、震わせる。それが、ナキメが、この王を、信じる理由だった。

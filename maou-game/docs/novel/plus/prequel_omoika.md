# **前日譚　オモイカ　十四の名**

会談の前の夜、オモイカは、灯りを一つだけ点けて、机に向かっていた。

机の上には、白い紙が、一枚。細く削った筆が、その横に置いてある。随員の名簿だった。

(十四人)

和平の席に連れていく数としては、多い。人間側からは、「十人まで」と、内々に知らされていた。それを、四人、押し通した。

「多すぎます。向こうに、警戒されます」

そう言ったのは、ミカヅチだった。

「少なすぎれば、もっと警戒される。魔界の者が、人間を恐れている、と思われる」

「だが、数が多ければ、人間は、軍勢だと思う」

「だから、荷物と楽器を、持たせる」

オモイカは、淡々と答えた。

「武器を持った者は、数えない。私の随員は、旅の一座だ」

ミカヅチは、鼻を鳴らした。それから、頷いた。反対ではなかった。心配なだけだった。それが、分かった。

筆を、取った。

最初の名を、書こうとして、手が、止まった。

(ササラ)

嵐狼の若者だった。笛吹きだ。腕は、お世辞にも、上手くない。音が外れる。拍がずれる。

けれど、道中、あの笛があると、誰かが、必ず、笑った。笑えば、肩の力が、抜ける。肩の力が抜けた者は、疲れにくい。

(外せない)

そう、思った。

筆を、動かした。

『ササラ』

次に、浮かんだのは、老いた鬼の顔だった。

(フミト)

巻物を、いつも、胸に抱えて歩く書記だ。腰が曲がっているのに、足だけは、速い。口が、少し悪い。

「参謀殿、顔が怖いですぞ」

何度、言われただろう。言われるたび、頬が緩んだ。

『フミト』

三人目を、書いた。

『ツバメ』

鴉族の、若い娘だった。荷を担ぐのが、好きなのだと言う。担げる限り、いつも、一番多く担ぐ。

「故郷の畑に、いつか、帰るんです」

誰かに、そう話していたのを、聞いたことがある。小さな畑だと言っていた。大きくは、ならなくていい、と。

(帰してやる)

その一行を、オモイカは、紙に、書かなかった。ただ、胸の中で、そっと、確かめた。

名を、一つずつ、書いていった。

トウゴ。セナ。アオイ。シノ。

鬼の荷車引きがいた。笛の弟子の少年がいた。土蜘蛛の料理番がいた。鴉の伝令見習いがいた。皆、顔が、鮮明に、浮かんだ。

好きな食べ物も、知っていた。故郷の畑の広さも、家族の数も、癖も。

(全員、覚えている)

それが、参謀の仕事だ、と、先代の頃から、思ってきた。力で押さえつける統治は、いつか折れる。折れないためには、一人ひとりを、知っていなければならない。

十四の名が、紙の上に、並んだ。

筆を、置いた。

窓の外で、風が、鳴った。遠くから、笛の音が、ひとつ、聞こえた。外れていた。

(……ササラだ)

小さく、笑いが、漏れた。

窓を、少しだけ、開けた。夜気が、頬を撫でた。庭の隅で、随員たちが、車座になって、荷の確認をしているのが、見えた。誰かが、冗談を言って、誰かが、笑った。

その輪の中に、ササラが、いた。笛を、膝の上で、くるくると、回していた。

「ほら、もう一回、合わせるぞ」

「やめろ。耳が、腐る」

「ひでえな」

笑い声が、夜に、広がった。

オモイカは、その様子を、じっと、見ていた。

胸の奥で、小さな棘が、疼いた。人間の王から届いた書簡の、整いすぎた文面。誠実すぎる言葉の順序。

(嘘を知っている者の、書いた文だ)

その確信は、消えていなかった。

けれど、もう、決めたことだった。王が、望んだ和平だ。

(もし、何かが起きるなら)

その時は、自分が、盾になる。

この十四人を、無事に、連れて帰る。笛が外れていても、荷が重くても、巻物が曲がっていても。全員を、必ず。

紙を、手に取った。

十四の名を、もう一度、目でなぞった。それから、折りたたんで、懐の奥に、しまった。

灯りを、消した。

闇の中で、遠くの笛が、また、外れた。

オモイカは、目を閉じて、その音を、胸に刻んだ。

あれが、十四人の名を、記した、最後の夜になった。

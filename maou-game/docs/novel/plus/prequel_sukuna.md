# **前日譚　スクナ　袋の口**

聖の森の入口には、小さな薬草畑がある。

スクナは、その畑の端に、しゃがみこんでいた。淡い緑の髪を、後ろでひとつに束ねている。背の籠には、朝のうちに摘んだ草が、いっぱいに詰まっていた。杖は、傍らの木に立てかけてある。先に付けた青い石が、朝の光を受けて、ちらちらと光った。

「今日は、よう効く朝じゃ」

土を指で崩しながら、誰に言うでもなく呟いた。

薬草は、人と同じで、朝に聞けば機嫌がよい。夕方に聞けば、疲れている。それが、スクナの、長年の見立てだった。

畑の草を、ひとつずつ、確かめていく。熱を下げる葉。傷を閉じる根。眠れぬ夜の花。どれも、スクナが、種から育てたものだ。

(この草を、教えてくれた者が、おったな)

不意に、そんな考えが、浮かんだ。

もう、ずいぶん昔のことだ。顔も、声も、細かいところは、思い出せない。ただ、大きな袋を担いだ、背の高い人だったことだけは、覚えている。袋の口から、いつも、薬草の匂いがした。

「おまえは、手が器用じゃ。草の名を覚えるのも早い」

そう言われて、嬉しかった。その人は、どんな草にも、名前があることを、教えてくれた。

(名前を、呼んでから、摘むのじゃ)

それが、その人の、口癖だった。

名は、思い出せない。

不思議なことに、その人の名だけが、頭の奥の、どうしても届かない場所に、仕舞われていた。何度、思い出そうとしても、霧の向こうで、輪郭が、ぼやける。

(年を取ったからじゃろう)

そう、思うことにしていた。

畑の端の道を、誰かが、歩いてくる気配がした。

振り返ると、森の若者が、籠を抱えて、立っていた。

「スクナ爺さま。熱を出した子がいるんです。いい薬草を、分けてください」

「ええとも。どれ」

スクナは、籠の中から、細い葉を取り出した。

「これを、煎じて、飲ませなさい。三度に分けて」

「ありがとうございます」

「それから」

スクナは、若者の顔を、まっすぐ、見た。

「子どもの名を、呼んでやりなさい。熱で苦しむ子には、名を呼ぶ声が、いちばんの薬になる」

「名を」

「そうじゃ。薬は、体を助ける。名は、心を助ける」

若者は、少し、驚いた顔をした。それから、深く、頭を下げた。

「はい。そうします」

その背中を、スクナは、静かに、見送った。

昼を過ぎて、森の道のほうが、少し、騒がしくなった。

白い礼装の使者が、森の入口に、立っていた。

「老薬師殿。この森の長に、お目通りを願いたい」

柔らかな声だった。穏やかな顔。人好きのする、微笑み。

スクナは、杖に手を置いた。

(見ない顔じゃ)

笑みの奥に、何かが、足りなかった。人の顔には、必ず、その人だけの温度がある。この男の顔には、それが、薄かった。

「ご案内しよう」

スクナは、静かに答えた。

「長は、森の奥におられる。足元に、気をつけなされ」

「ありがとうございます」

使者は、にこやかに頭を下げた。

道中、スクナは、何度も、背後の足音に、耳を澄ませた。

使者の足音は、整っていた。一歩ごとに、同じ間隔、同じ強さ。まるで、誰かに、数えられているような歩き方だった。

(ああ)

スクナは、胸の奥で、小さく息を吐いた。

(こういう歩き方を、昔、どこかで、見たことがある)

思い出そうとして、また、霧の向こうに、輪郭が、消えた。

その夜、畑の端の小屋に戻って、スクナは、一人、茶を淹れた。

囲炉裏の火が、小さく、揺れていた。

窓の外の、森の闇に、遠く、梟が鳴いた。

(わしは、何を、忘れておる)

茶碗を、両手で包んだ。熱が、手のひらに、染みた。

(いつか、思い出す日が、来るじゃろう)

そんな気がした。理由は、分からない。けれど、胸の奥の、深いところで、何かが、静かに、待っている。

その日が、来たら。

(今度は、わしが、薬草を、教える番じゃ)

それが、スクナの、ささやかな、願いだった。

数日後、森の入口に、継ぎの当たった外套の青年が、現れた。

背の籠に、薬草を詰めた老薬師は、青年の顔を見て、少し、目を細めた。

懐かしい、と思った。

理由は、分からなかった。

# **前日譚　スサノ　手の形**

嵐ヶ峰の夜明けは、風の音で始まる。

スサノは、岩の上に、半身を預けていた。灰色の毛並みが、冷たい風に逆立っている。眼下の斜面では、群れの若い狼たちが、朝の駆けくらべの支度を始めていた。

「スサノ」

背後で、年老いた雌の声がした。群れの母だった。

「おまえに、頼みがある」

「何だ」

「あの子を、どうにかしてやってくれ」

母の視線の先、岩陰の隅に、小さな影が、うずくまっていた。

生まれて二つほどの子狼だった。灰色の毛はまだ綿のようで、耳だけが、大きく立っている。けれど、その耳は、風の向きを探らなかった。誰かが近づいても、ぴくりとも動かなかった。

「聞こえんのだ」

母が、低く言った。

「呼んでも、振り向かん。吠えても、気づかん。狩りには、連れて行けん。群れの掟は、知っておろう」

「知っている」

スサノは、牙の間から、息を吐いた。

嵐狼の掟は、単純だった。走れぬ者、聞けぬ者、群れの足を引く者は、群れに置かない。それが、冬を越えるための、古い知恵だった。冷たい理屈だが、間違ってはいない。

(間違ってはいない)

そう思いながら、スサノの足は、岩陰へ向かっていた。

子狼は、近づく影に、びくりと身を縮めた。耳が聞こえない代わりに、目と鼻が、鋭いのだった。大きな琥珀色の目が、スサノを見上げた。怯えていた。それでも、逃げなかった。

「おい」

スサノは、声をかけた。当然、通じない。子狼は、首を傾げただけだった。

スサノは、しばらく、困った。

それから、地面に、腰を下ろした。前足を、そっと、持ち上げた。拳のように握って、また、開いた。手招きの形だった。

子狼は、目を丸くした。

それから、ためらいがちに、近づいてきた。小さな鼻が、スサノの前足に触れた。

「そうだ。それでいい」

声は、聞こえない。けれど、子狼の尻尾が、ほんの少し、揺れた。

その日から、スサノは、毎朝、岩陰に通った。

形を、作った。腹が減ったときは、指を口に当てる。眠いときは、頬に掌を当てる。水は、指先で、波を描く。子狼は、驚くほど、早く覚えた。覚えて、自分でも、形を作り返した。

(ありがとう)

小さな掌が、胸の前で、そっと、重ねられた。

その形を、初めて見たとき、スサノは、不覚にも、鼻の奥が、熱くなった。

数か月が過ぎた。

群れの母は、何も言わなかった。ただ、ある朝、スサノの前に、乾いた肉を一切れ、置いた。

「あの子の分だ」

「ああ」

「群れの者には、黙っておく。だが、冬が来る前に、決めなければならん」

スサノは、頷いた。

決める、とは、何を決めるのか。群れに残すのか、置いていくのか。群れから出ていくのは、あの子か、それとも自分か。

答えは、まだ、出ていなかった。

そんな頃だった。嵐ヶ峰に、客が来たのは。

尾根の道を、一人の男が、登ってきた。黒髪に、額の脇に黒い角。背に、まだ翼を畳んでいる。供もつけず、荷も持たず、ただ、歩いてきた。

「何者だ」

見張りの若い狼が、牙を剥いた。男は、立ち止まった。手を、ゆっくりと、胸の前に上げた。敵意がない、と示す形だった。

「新しい王だ、と言えば、通してもらえるか」

「王だと」

「ああ。嵐狼の群れを、見に来た」

スサノは、岩の上から、その男を、見下ろしていた。

(王、か)

どうせ、また、新しい支配者だ。鬼族の頭領が替わった話は、風の噂で聞いていた。力で従わせる王か。それとも、飾り物か。

男は、岩の下まで来て、足を止めた。上を見上げて、笑った。

「おまえが、スサノか」

「そうだ」

「群れの長ではないと聞いた。だが、一番、慕われていると」

「余計な噂だ」

「そうか」

男は、辺りを見回した。斜面を駆ける若い狼たち。岩に刻まれた爪の跡。そして、岩陰で、こちらをうかがっている、小さな子狼。

男の目が、子狼に、とまった。

子狼が、恐る恐る、手を持ち上げた。拳を握って、開く。手招きの形だった。

男は、一瞬、目を丸くした。それから、同じ形で、手を、返した。

(こんにちは)

子狼の尻尾が、ぱっと、揺れた。

スサノは、息を、止めた。

「……知っているのか、その形を」

「いや」

男は、振り返った。照れたように、頭を掻いた。

「見よう見まねだ。嵐狼の子は、よく、手で話すと聞いた」

「話さない。この子だけだ」

スサノは、岩から下りた。男の前に、立った。背丈は、ほとんど同じだった。

「群れは、この子を、置いておけない」

自分でも、驚くほど、素直に、言葉が出た。

「冬が来る前に、群れを出る。この子と」

「そうか」

男は、頷いた。驚いた顔はしなかった。

「では、そのための場所が、要るな」

「何」

「群れに置けない者の集まる場所が。聞けぬ者、走れぬ者、群れから、はぐれた者。そういう者が、冬を越せる場所だ」

スサノは、息を呑んだ。

「そんな場所を、作れるのか」

「作れる。ただし、一人では、無理だ」

男は、手を、差し出した。

「手を、貸してくれ。この嵐ヶ峰の北の谷に、作ろう」

スサノは、その手を、見つめた。

握りしめれば、折れそうな、人の形の手だった。それなのに、断られるとは、少しも思っていない手だった。

(この男は)

スサノは、牙を、少しだけ、見せた。笑ったつもりだった。

「約束しろ」

「何を」

「あの子が、手の形で、話せる限り、この谷では、誰もあの子を、追い出さん。それが、条件だ」

「約束する」

即答だった。

その日のうちに、スサノは、群れの長に、別れを告げた。群れの母は、岩の上から、静かに見送った。

北の谷へ向かう道すがら、子狼は、スサノの肩の上で、小さな手を、風に向かって、振っていた。

(ありがとう)

その形を、誰に向けたのかは、分からなかった。

それが、嵐狼の新しい集落の、最初の朝だった。

のちに、そこで暮らす子らは、皆、手の形で話すことを、覚えた。

# **前日譚　ウズメ　杭を抜く朝**

獣ノ原の朝は、風の音で、目が覚める。

ウズメは、岩の上で、伸びをした。尻尾の先が、ぱしんと、岩を叩く。猫に似た耳が、風の向きを探って、ぴくりと動いた。栗色の毛並みは、朝露で、少し湿っていた。

(今日も、杭が、増えてる)

視線の先に、細い木の杭が、一本、地面に打たれていた。赤い布が、風に、ひらひらと揺れている。昨日までは、なかったものだ。

人族の入植者が、境を決めるために、打つ杭だった。

「また、一本」

ウズメは、岩から、ひょいと飛び降りた。四つ足で着地して、そのまま駆け寄る。杭の根元を、前足で、がしがしと掘った。

「そんなもの、抜いちゃえ」

土が、飛び散った。杭は、少し傾いた。

「お嬢さん、また、やってるのかい」

背後から、のんびりした声がした。里の見張り番の老人が、岩の上から、こちらを見下ろしていた。

「だって、おじいさん。昨日も、一昨日も」

「いたちごっこじゃよ」

「でも、杭が増えるたびに、獣ノ原が、狭くなる」

「それは、そうじゃが」

老人は、静かに、笑った。

「抜いても、また、打たれる。それなら、話をつけたほうが、早い」

「話が通じる相手、なの?」

「通じる者も、おる。通じん者も、おる。人間も、獣も、同じじゃ」

ウズメは、むっとして、尻尾を、ぴしりと振った。

(おじいさんは、いつも、大人だ)

それが、少し、悔しかった。

昼過ぎ、境の向こうから、人影が近づいてきた。

背の高い、若い男だった。麻の服に、布の帽子。腰に、小さな斧を、提げている。人間の、入植者だった。

ウズメは、岩の上から、じっと見ていた。男は、杭の前で、足を止めた。傾いた杭を、見つめている。

「……誰だ」

低い声で、呟いた。

「誰が、抜いた」

ウズメは、岩から降りた。ゆっくり、男の前に立った。

「あたしだよ」

男は、驚いた顔をした。猫の耳と、尻尾を、まじまじと見た。

「獣人の、娘か」

「そう。足が速くて、口が早くて、あとは……まあ、いい女」

自分で言って、少し、照れた。男は、目を、丸くした。それから、ぷっと、吹き出した。

「いい女、ね」

「何か、おかしい?」

「いや。初めて会った相手に、それを言う奴は、初めて見た」

男は、頭を掻いた。

「俺は、ガクだ。この先の、野原に、畑を作ろうと思って来た」

「畑?」

「ああ。麦と、豆と。女房と、子どもを、食わせないといけない」

ウズメは、少し、黙った。

(女房と、子ども)

杭の向こうに、立っているのは、敵ではない。同じように、食べ物を、探している、ただの人だった。

「でも、そこは、あたしたちの、狩り場だよ」

「そうか」

ガクは、しばらく、考えた。

「どこまでなら、使っていい」

「え」

「俺は、畑が欲しいだけだ。獣ノ原を、奪うつもりは、ない」

ウズメは、目を丸くした。

「……話が、通じるの」

「通じない奴も、いるだろうが」

ガクは、苦笑した。

「少なくとも、俺は、通じるつもりだ」

その言葉が、おかしくて、ウズメは、ふっと、笑った。

その日の夕方、ウズメは、里の見張り番の老人に、言った。

「話の通じる、人間が、いた」

「そうか」

「でも、杭は、増える。ほかの入植者は、どうだか、分からない」

「そうじゃな」

「だから、あたしが、見張る。誰が、どんな人間か、全員、見て回る」

老人は、目を細めた。

「それが、斥候の、仕事じゃな」

「うん。斥候になる」

ウズメは、尻尾を、ぶんと、振った。

その夜から、ウズメは、獣ノ原の境を、駆け回るようになった。

杭を、抜くのではなく、杭の向こうに立つ、人の顔を、見るために。

のちに、ミナモから来た、継ぎ当ての外套の青年と、黒髪の男に会ったとき。

ウズメは、心の中で、笑った。

(話の通じる、人間が、また、来た)

# イラスト生成プロンプト（Gemini「Nano Banana」用・ドット絵）

ゲームに差し込むドット絵を、Gemini の画像生成（Nano Banana）で作るためのプロンプト集。
**第1弾は主要な人物・ボス・主な背景だけ**（ユーザー決定）。絵柄がうまくいけば、残り（町の人・ふつうの敵・残りの背景）も作る。
見た目は小説（docs/novel/）の記述から取り、書かれていない所は今のゲームのドット絵の色（js/data/sprites.js）で補った。

---

## 1. 作る絵の種類と大きさ

| 種類 | ゲームでの使い道 | できあがりの大きさ | Geminiで作る大きさ |
|---|---|---|---|
| 顔グラ（バストアップ） | 会話の窓の左に出す顔 | 64×64ドット | 正方形（1:1） |
| 敵・ボス | 戦いの画面の敵・見聞録の絵 | 64×64（ボスもこの絵を大きめの枠に描く） | 正方形（1:1） |
| 背景 | 物語の場面の背景・戦いの背景 | 240×160ドット（ゲームで2倍に拡大して480×320） | 横長（3:2） |

- マップを歩く小さな人物（16×16）は小さすぎて生成に向かないので、**今のドット絵のまま**にする。
- Geminiの絵は細かすぎるので、できた絵は**こちら（Claude）で縮小・色数の整理・背景の透明化**をしてからゲームに入れる。絵をそのままチャットに貼ってもらえればよい。

## 2. うまく作るための手順（大事）

1. **最初に「絵柄の基準」を1枚作る。** オオナムチの顔グラ（下の C-02）を先に作り、気に入るまで作り直す。
2. **2枚目からは、基準の絵を一緒に添付して**、プロンプトの頭に次の1行を足す。絵柄がそろう。
   > `Match the exact pixel art style, palette softness, outline thickness and shading of the attached reference image.`
3. 顔グラと敵は**背景をマゼンタ一色（#FF00FF）**にしている（あとで透明にするため）。違う色が混ざったら「背景をマゼンタ一色にして」と追加で頼む。
4. 気に入らない所は、同じ会話で「髪をもっと黒く」「角を2本に」のように**言葉で直してもらう**（Nano Banana は手直しが得意）。
5. 文字が入ってしまったら「文字や記号を消して」と頼む。

## 3. 共通の絵柄（全部のプロンプトの頭に付ける）

**顔グラ・敵用**
```
16-bit era Japanese RPG pixel art, crisp hard-edged pixels, no anti-aliasing, no blur, limited palette of about 24 colors, clean dark outline, soft cel shading with 2-3 tones per color. Japanese-mythology (Kojiki) inspired fantasy. Solid flat magenta (#FF00FF) background, no text, no border, no watermark.
```

**背景用**
```
16-bit era Japanese RPG pixel art background, crisp hard-edged pixels, no anti-aliasing, limited palette of about 32 colors, painterly dithering, Japanese-mythology (Kojiki) inspired fantasy world, wide 3:2 landscape, no characters, no text, no watermark.
```

**世界の色の決まり**（仕様書 11章）
- 人間界は白〜青の調子。王都・天津京は白く整った色。王の側（王・官吏・兵の腕章）は白でそろえる。
- 魔界（黄泉）と過去の回想は赤みがかった色。黄泉の空は昼でも薄く赤い。魔界の者は黒・赤に、角・翼・甲殻・獣の耳。

## 8. できた絵の渡し方と、このあと

- できた絵は、ファイル名を付けてチャットに貼る（何枚かまとめてでもよい）。
- こちらで ①縮小（64×64・96×96・240×160）②色の整理 ③マゼンタの背景を透明に して、`assets/` のフォルダに入れ、ゲームで使えるようにする。
  - 顔グラ：会話の窓の左に顔を出す（名前のある人のセリフのとき）。
  - 敵：戦いの画面と見聞録の敵の絵を差し替える。
  - 背景：物語の場面の背景・戦いの背景を差し替える。
- 絵がない人や場面は、今の絵のまま動く（少しずつ差し替えられる）。
- 第1弾の絵柄がよければ、第2弾（町の人の種類・ふつうの敵 約50種・残りの背景）のプロンプトを作る。

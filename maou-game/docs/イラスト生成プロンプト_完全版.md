## 2. 失敗しないコツ

1. 背景は、マゼンタ（#FF00FF）一色にする。光・オーラ・糸・線・影を背景に描かせない（切り抜きが汚くなり、絵が小さくなる）。
2. 顔は1:1。頭のてっぺんの上に少し余白、肩まで入れる。体の大きい人は上半身で止める。
3. 全身の戦闘絵は1:1。足先まで全部入れ、まわりに余白をとる。
4. できている絵を1枚添付して貼ると、絵柄がそろう（顔には顔、背景には背景の絵を添える）。各プロンプトの最後の「Match the exact pixel art style…」の1行が、その合図。1枚目で基準が無いときは、その行を消してよい。
5. 文字・枠・署名が入ったら、「文字や記号を消して」と頼む。背景がマゼンタでなかったら「背景をマゼンタ一色にして」と頼む。
6. 手直しは同じ会話で言葉で頼む（「髪をもっと黒く」「角を2本に」など）。
7. できた絵は、ファイル名を添えてチャットに貼る。縮小・色の整理・背景の透明化・ゲームへの取り込みは、こちらでやる。

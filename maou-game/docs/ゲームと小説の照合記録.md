# ゲームと小説の照合記録

ユーザー依頼：ゲームと小説に違いがないか全部調べ、どちらかに合わせる判断をして直す（どちらを取り入れてもよい）。

## 調べた方法（機械で全部照らした）
- 本編13編のセリフ（「」）と、ゲームの場面データ（js/data）の文字列を、記号・空白を除いて一行ずつ照合（双方向）。
- 寄り道の章16編のセリフと、寄り道クエスト（js/data/sidequests）を照合。
- 地の文の（　）でない1行、固有名詞（カタカナ語）、言霊の名前（「――〇〇」と太字）、章の題を照合。
- 人物の見た目（髪・耳・角・髭）を、小説の描写と顔グラの絵の両方と照合。

## 見つかった違いと、決めたこと
1. **ベルのセリフ（約60か所）**：ゲームは、ユーザー提供の「ベルの台詞 差し替え表」（bell_lines_revision.md）どおりに直してあったが、小説の本文は元のままだった。→ **ゲームに合わせた**。表の全行を、小説（第2〜12章・エピローグ）に反映した（「殺さぬ」「感謝する」「そなた」「戻った」など）。加筆版（plus/）にも同じ直しを当てた。
2. **第九章**「己が良いことをしていると信じている」：ゲームは「自分が、良いことをしていると、信じている」。→ ゲームに合わせた。
3. **第十二章**「手は、出さない」：ゲームは「手は出さぬ」（第十一章と同じ言い回し）。→ ゲームに合わせた。
4. **エピローグ**「顔を、知りませんでした」：直後のセリフと重なっていて、ゲームは後者だけ。→ ゲームに合わせ、小説から重なりを外した。
5. **エピローグ**のベルの詫び「…今、知っています」→ 表どおり「…今は知っている」。
6. **ユウの見た目**：顔グラ（猫耳のある白い礼装）と、小説・ゲームの場面に耳の描写がなかった。→ **絵に合わせて、小説とゲームの両方に**「栗色の髪の間から、猫に似た小さな耳が覗いている」を足した（第七章）。

## 問題がなかったもの
- 本編のセリフ：ゲームにないセリフは、前の見直しで足してあり、いまは「一行を二つに分けて出した」だけの違いが残る（意味は同じ）。
- 寄り道の章16編のセリフ：欠けなし。
- 固有名詞：小説にあってゲームにない名前はなし。
- 言霊の名前：小説の「――〇〇」はすべてゲームの名前と一致。習得の順序（堅め・癒やし＝4章、心鎮め＝5章、火種＝6章、見破り＝9章）も一致。
- 章の題：本編12章とも一致。

## 残していること（違いではない）
- ゲームの地の文は、小説より短い（道のり・戦いの描写は、歩く・戦うで置き換えたため）。ゲームに出さない心の中の（　）の一行も、小説にだけある。
- ハル・イサナ・ユズリハなどは顔グラがまだなく、絵と文の照合は絵が届いてから行う。

## 二回目の点検（加筆・前日譚・名の欠片の短編を足したあと）
- 本編のセリフ：ゲームとの欠けは0（前日譚・加筆を足したあとも変わらず）。
- 名前の重なり：新しく作った名前（ガク・ヤスケ・ハルオ・ゲンタ・ハナ・ハギ・サクヤなど）は、本編・寄り道の章の人物と重ならない。
- 設定の食い違い（見つけて直した分）：
  - ハニヤス・ミカヅチの前日譚：ミカヅチが「王の一撃を受けきった」形に直した（第十一章に合わせる）。
  - タケルの前日譚：ヤツカが「正義は我らにあり」を戒める形を、「王の使者のあとで言うようになる」形に直した（番外編二に合わせる）。
  - オモイカの前日譚の随員の名：本編の名（ササラ・フミト・ツバメ・トウゴ・セナ・アオイ・シノ）に合わせた。
  - アマツ王の前日譚：老女の息子の名が番外編四の「ゴロウ」と重なったので「ヤスケ」に変えた。
  - 名の欠片の短編：追加した場面が、名を呼ばれなくなったあとの出来事と矛盾しないよう、位置を直した。
- 文字の点検：加筆版・前日譚・短編の27ファイルで、「」と（）の数の不一致、句読点の重なり、混入した英字は0。
- 残していること：前日譚は「作者が決める設定」（先代と魔王の関わり、スクナと昔話の小さな神の関係など）に踏み込まない。

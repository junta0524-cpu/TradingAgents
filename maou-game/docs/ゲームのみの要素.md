# ゲームにだけある要素（小説にないもの）の洗い出し

小説（docs/novel/ ch01〜ch12・epilogue）と、いまのゲームを見比べて、**ゲームにだけあるもの**を並べた一覧。
小説へ落とし込む（番外編・四天王編・4.5章などを書く）ときの材料にする。

- 出どころ：〔仕様〕＝ユーザーの仕様書・地図のデザイン、〔資料〕＝ゲーム版の資料、〔追加〕＝ゲームを作るときに足したもの
- 「小説での扱い」：小説に名前だけある／まったくない、など

---

## 1. 物語の流れで、ゲームが足したり形を変えたりしたところ

| 章 | ゲームにあること | 小説での扱い | 出どころ |
|---|---|---|---|
| 4〜9章 | 章の始まりが毎回ミナモのギルドの受付。行き先へは人間界の地図を歩いて行く | 5・6・7章は「ギルドで受けた依頼」の一文だけ。8・9章はギルドの話がない | 〔追加〕ユーザー決定 |
| 8・9章 | 受付で「次の方」のあと、行き先の案内だけ（依頼の中身がない） | 王都へ行く理由・祝賀の夜に向かう理由のつなぎがない | 〔追加〕 |
| 5章 | 使者の言葉に「頷く／たどり直す」を選ぶ（頷いた回数を数える） | 心を保つ場面はあるが、選ぶ形ではない | 〔追加〕 |
| 6章 | コトシロ・カナメが戦いの仲間として同行 | 二人とも出てくるが、一緒に戦う描写はない | 〔仕様〕 |
| 7章 | ウズメが岩陰の抜け道を見つける。夜の井戸で腕章の兵2人と戦う（ベルは見守る） | 抜け道はない。井戸の場面はあるが戦いの形は違う | 〔追加〕 |
| 9章 | やすらぎの院に見張りがいて、見つからないように進む（見つかると入口へ戻される） | 見張りの描写は少し。忍び込む遊びはない | 〔追加〕 |
| 10章 | 蹂躙戦闘で「5つの隊を止める」。追手と3回戦う | 兵の一隊が突っ込んでくる描写はあるが、5隊を順に止める形ではない | 〔仕様〕〔追加〕 |
| 10章 | 場面の絵にカズミの姿が出る | カズミは小説ではエピローグにだけ出る | 〔追加〕 |
| 11章 | ミカヅチ・スサノ・ナキメとの手合わせが、それぞれ戦い。そこで「堅め連」「先読み」を覚える | 手合わせはあるが、新しい言霊は覚えない | 〔追加〕 |
| 12章 | 王の詠唱がゲージで溜まり、守りの言霊で遅らせる戦い | 詠唱はあるが、遅らせる駆け引きはない | 〔追加〕 |
| 12章 | オオナムチのレベルが低いと、名呼びの三度目にクナドが手を貸す | ない（ゲームだけの助け舟） | 〔追加〕 |
| 2章 | 魔王ベルイザナの攻撃は敵全体に2回 | 圧倒的な強さの描写はある | 〔追加〕ユーザー決定 |

## 2. クリア後（13章）— まるごとゲームだけ

小説はエピローグで終わる。そのあとの話は、すべてゲームだけ。

- **師との手合わせ**：ハニヤス（守）・ミカヅチ（攻）・ナキメ（再生と知）・ベルとの特訓で、四つの系統の言霊を教わる
- **ツクヨミの社**：暗い社と燭台、灯籠を「西→真ん中→東」の順に灯す謎、裏の修行、祭壇で言霊を授かる
- **クナドの導き**：四つの系統がそろうと、クナドが大穴の最深部へ連れて行く
- **試練の扉と天の声**：6つの問いに答えると「調和の光」（アメノミナカヌシ）を授かる
- **ベルとの最終手合わせ**：勝つと「まことの名」
- **ミカヅチからの大軍戦**（好きなときに挑める蹂躙戦闘）
- **オモイカの出迎え**、**大穴で両方の世界を行き来**できる〔資料〕
- **レベル99まで**、レベルに応じて強い敵が出る
- **残党軍**〔追加〕ユーザー決定：王が倒れても洗脳の解けない旧王軍の生き残り。歩兵・弓兵・術師・騎兵・旗持ち・薬師が隊を組んでさまよい、仲間を呼ぶ。率いるのは、ひどく強い「残党の将」。みな目を覚まさせられる
- **黄泉の深淵**〔追加〕ユーザー決定：大穴の最深部のさらに下。上の淵の番人「黄泉の大蛇」、底の番人「名喰いの王」（奪われた名の文字を吸い込む、黒い鎧の亡霊。クリア後でいちばん強い）

## 6. 小説に文がないので、案内の文で埋めているところ

- 8・9章の受付の依頼の中身
- 12章の、クナドが名呼びに手を貸すところ
- 目覚めさせたときの文「（〇〇は、武器を下ろした）」
- 名の欠片を返したときの文
- 寄り道の依頼の文、言の葉の石碑の手がかり
- 町の部屋の住人のひと言

### 書くときの決まり（いままでどおり）
- 小説の文体（docs/novel の各章）に合わせる。セリフは小説の人物の言い方をなぞる。
- 書いた章は docs/novel に新しいファイルで置く（いまの章は書き換えない）。
- ゲームのほうの文（案内の（　）など）は、書いた章ができてから、合わせるかどうかを決める。

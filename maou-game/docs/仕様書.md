## 0. やらなくてはいけないこと（最優先・必ず守る）

1. **ファイルを開くだけで遊べること**：`index.html` をダブルクリックして、Chrome / Edge / Safari で動くこと。サーバー不要。`<script type="module">` と `fetch()` によるJSON読み込みは禁止（データはJSファイルに書く）。
2. **外部ライブラリは使わない**：HTML / CSS / 素のJavaScriptだけ。画像と音は、Canvasの図形・自作ドット絵・Web Audioで作る。
3. **著作権への配慮**：既存の有名RPGの固有名詞・画像・音楽・セリフは使わない。使ってよいのは「遊びの仕組み」だけ。呪文名・地名・人名は、この文書のものを使う（古事記由来の神名と、オリジナルの和風名）。
4. **データと処理を分ける**：言霊・敵・キャラ・アイテム・マップ・会話・イベントは `js/data/` のJSオブジェクトに書く。数値バランスは `js/data/balance.js` に集める。
5. **1フェーズずつ作る**：フェーズが終わるたびに止まり、「できたこと」「確認の手順」「次の予定」を、専門用語を使わず報告する。ユーザーが「OK」と言うまで次へ進まない。
6. **ユーザーはプログラミングの専門家ではない（リフォーム業界の職人）**：説明は短く具体的に。確認は「〇〇キーを押して△△になればOK」の形で書く。
7. **物語の核を守る**：次の3つはどのフェーズでも崩さない。
    - ベルは仲間を死なせない「守り手」。ゲームオーバー条件は **ベル以外のキャラの死亡**（直前のセーブへ戻る）。ベル自身は死なない。
    - 敵を単純な悪人にしない。洗脳された善人として描く。
    - 「奪う力（名の剥奪）」に対し、「呼ぶ力（名呼び）」で救う、という対比。
8. **デバッグ機能を必ず入れる**：F1キーで開く。内容は第13章。
9. **将来の拡張を見越す**：章・敵・言霊の追加は「データファイルを足すだけ」で済む作りにする。

## 3. 世界観

- **二つの世界**：人間界「葦原」と魔界「黄泉」。世界の中心の大穴「比良坂」だけでつながる。
- **比良坂**：両岸に拠点（人間側「坂上の砦」、魔界側「坂下の関」、会談の間「和合殿」）。管理は完全中立の番人一族「岐人」（境の神の血を引く）。岐人だけが大穴を自由に行き来でき、最深部に入れる。異変は両陣営へ報告する義務がある。
- **魔界**：和風ダークファンタジー。四天王が四種族を統治する封建制。相性（四すくみ）：鬼族→嵐狼族→土蜘蛛族→鴉族→鬼族（左が右に強い）。傾向であり、個人や状況で覆る。
- **人間界**：人族（魔族を絶対悪とする）、ドワーフ（人族寄り）、エルフ（意志ある中立）、亜人（魔族寄りと見られ、地域で差別が強い）。政体は表向き議会制、実質はアマツ王が言霊で操る「見せかけの民主制」。
- **同じ神々**：人間も魔族も同じ原初の五柱を信仰している（共生の伏線）。
- **力の体系＝言霊**：全存在は「まことの名」を持つ。正しく唱えれば誰でも基礎の力を引き出せる。意志を言葉に乗せられるのは才ある者だけ（才は血統でも後天でも開花しうる）。

## 6. 戦闘仕様（`systems/battle.js`・数値は `balance.js`）

- **形式**：ターン制コマンド。全員の行動を決め、素早さ順に実行。最大4人、ベルとオオナムチが基本。
- **行動順**：値＝素早さ×乱数(0.5〜1.0)。大きい順。同値は味方先。ターン開始時に決まる。
- **物理ダメージ**：基本＝(攻撃力−守備力/2)/2。乱数幅＝基本/16+1。基本が2未満なら0〜1。
- **会心**：1/64。守備力を無視して攻撃力相当。特技・グループ攻撃では出ない。
- **言霊ダメージ**：言霊ごとの固定幅（威力は術者のステータスに多少補正をかけて終盤の物理優位を避ける）。耐性倍率：0（無効）/0.5/1.0/1.5。
- **ぼうぎょ**：被ダメ半減。**逃走**：1回目1/2、2回目1/2、3回目3/4、以降7/8。ボス戦・イベント戦は不可。
- **狙われ率**（生存4人）：前列から 40%/30%/20%/10%。
- **状態異常**：ねむり（2〜5T、打撃で味方1/2・敵1/4で解除）／こんらん（6〜9T）／口封じ（7〜10T）／縛り（4〜7T）／毒（フィールドで歩数ダメージ）／猛毒（毎ターン最大HP1/8）／朧（命中低下）。耐性で確率が変わる。
- **作戦（AI）**：「どんどん攻めて」「うまくやって」「回復まかせた」「MP節約で」「いのち優先」「ぜんぶ指示する」。AIはアイテムを使わない。初期実装は「うまくやって」と「ぜんぶ指示する」。
- **戦闘終了**：経験値・ゴールド分配。ドロップは最後に倒した敵1体だけが判定（確率ランクS/A/B/C…）。
- **エンカウント**：歩数制（町・神殿は0）。設定で「少なめ」を選べる。
- **ゲームオーバー**：ベル以外のキャラが倒れると、直前のセーブへ戻る。
- **成長**：レベル上限99（試作は20まで先に）。ステータスは オオナムチ=低め、ベル=カンスト。主人公の成長はなだらかにし、守りを覚える序盤の死にやすさを調整（`balance.js`）。

## 7. ベル専用システム

### 7-1. 阻害ゲージ

- 偽名「ベル」の言霊による認識阻害。ゲージ満タンから始まる。
- **減る条件**：力・言霊の使用（大きく減る）、探知網の濃い場所（天津京など）にいる時間。
- **探知網**：4〜6章は薄い、7章でタケルの視察、8〜9章は濃い。
- **ゼロで**：正体露見イベント（10章）。
- 表示：画面端の小さなゲージ。強い場面では輪郭が揺れる演出。
- **オオナムチだけは影響を受けにくい**：ベルの顔が常にはっきり描かれる（他者は印象が薄れる演出）。

### 7-2. ベルの守り手ルール

- 4〜9章のベルは力を抑えて戦う（タケル同等以上だが、手加減）。パーティを死なせない「かばう」「致命傷を止める」が自動で働く強みを持つ。
- ベルが手を出さない場面（9章祈り、11・12章の約束）では、ベルは操作・戦闘から外れ、見守り演出になる。

### 7-3. 蹂躙戦闘（ベル単独）

- **置き場所**：2章（侵攻軍の壊滅）、10章（王都脱出で兵を傷つけず止める）、クリア後（任意の大軍戦）。
- **ルール**：ベル一人を操作。敵は万の軍勢。ベルのHPは減らず、**ゲームオーバーなし**。プレイヤーが選ぶのは「どの隊列から、どの順で消す（止める）か」程度。
- **演出**：詠唱も派手な光もなし。足音と風だけ。血の描写は抑える。
- **2章**：「消す」。戦闘後、兵が懐に持っていた書きかけの手紙（「娘に――」）が拾える。
- **10章**：同じ操作で「止める」。兵を傷つけると脱出の助けが弱まり、止めるだけなら周囲の迷いが増えて助けが強まる。
- **クリア後**：全言霊が使える。あえて使わず止める縛りも遊べる。

### 重要なイベント仕様の補足

- **9章 祈りイベント**：学んだ言霊の数が少ないほど紋の戻りが弱くなる。五柱目（アメノミナカヌシ）は選べない。
- **10章 脱出**：コトシロ（偽の通達）、ウズメ（近道）、コノハ・スクナ（霧）、カナメの武具を持つ兵が剣を振り上げられない、が一斉に働く。各章の選択（誰を助けたか）が助けの強さに影響。救えなかった縁がある場合は難易度が上がる（やり直し可）。
- **12章 王戦**：王は武力が低い。護衛兵は殺さず無力化。ゲージが満ちる直前に核心へ踏み込むと決着。
- **ゲームオーバー**：兵やタケルが仲間を倒す、または名の剥奪が完了、で直前セーブへ。

## 10. クリア後（やり込み）

1. 四系統（守・攻・再生・知）を規定の段階まで育てる＝入場条件。
2. 岐人クナドが、大穴最深部の「試練の扉」へ案内する。
3. 扉の前で**天の声**が選択式で問う。出題は固定で、各章のテーマ（森・鍛冶・差別・洗脳・正体・共生）から1問ずつ。正解は「どちらが強いか」ではなく「どちらが誠実か」。何度でも挑戦でき、不正解時は答えを言わず該当章を思い出させる一言だけ。
4. 突破するとアメノミナカヌシが**調和の光**を授ける。演出は無音に近く荘厳（四つの言霊が光となって巡り、まことの名が刻まれる）。
5. 解放後、**ベルとの最終手合わせ**が別枠で遊べる。
6. 任意の**蹂躙戦闘**（大軍戦）。
7. ツクヨミ系の深い言霊を3ルートで習得（ナキメの裏修行／ツクヨミの社／ベルとの特訓）。

## 11. UI仕様

- ウィンドウ：黒い半透明背景、白い2pxの枠、角は少し丸く。カーソルは点滅する▶。
- メッセージ：1文字30msで表示。決定キーで一気に表示、もう一度で次へ。▼が点滅。Shiftで早送り。速さは設定で3段階。
- 戦闘画面：上に敵、下にコマンド、右上に味方のHP/MP。HP25%未満はオレンジ、倒れたら赤。
- 時代の見た目：過去回想や魔界は赤みがかった色調、人間界は白〜青系。天津京は白く整った色調。
- スマホ：縦画面は上半分がゲーム、下半分が十字ボタンとA・Bボタン。ダブルタップで拡大しない。
- 設定：文字速度、エンカウント率（ふつう／少なめ）、音のON/OFF。

## 12. 口調の指針（会話データを書くとき）

- ベル：一人称「私」。短く言い切る（〜だ／〜ぬ／〜か）。礼節は保つ。4〜9章は冒険者として武士調を薄め、ぶっきらぼうだが丁寧に。二人称は4〜7章「そなた」、8章以降「おまえ」。山場だけ素の言葉（「……ありがとう」「半分ずつ、だったな」）。
- オモイカ：丁寧語。ベルが「感謝する」「次の手を聞かせてくれ」と返す定型。
- ミカヅチ：重く短い。スサノ：荒い。ナキメ：涼しく慇懃。ハニヤス：寡黙。
- ヒエダ：「いけませんぞ」と小言を言う老賢者。

**フェーズ0**

## 15. Claude Codeへの進め方

1. 最初にこのファイル全体を読み、今のフェーズの作業計画を5行以内で示してから始める。
2. 1フェーズごとに止まり、①できたこと ②ユーザーの確認手順 ③気になった点、を報告する。
3. 小さく作って動かす。大きな変更を一度にしない。
4. フェーズが終わるたびに、gitで記録する（使えなければ `backup_phase1` のようにフォルダごとコピー）。
5. 各ファイルの先頭に、日本語で「このファイルの役目」を2〜3行書く。
6. 数字（遭遇率、成長、値段）は `balance.js` にまとめ、ユーザーが自分で試せるようにする。
7. 既存作品の固有名詞が混ざっていないか、フェーズの終わりに確認する。
8. 仕様があいまいな点は、勝手に大きく決めず、案を2つ出してユーザーに選ばせる。小さなことは「遊びやすさ優先」で決めてよい。
9. シナリオ本文（セリフ）は、ユーザーが別に執筆した小説（全12章＋エピローグ）を元にする。**セリフはユーザーが提供したテキストを優先して使い、勝手に書き換えない。**

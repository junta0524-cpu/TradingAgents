## ① 4.5章「名を呼ばれない港」　（4章と5章のあいだ・ミナモ）

**視点**：ベル・オオナムチ　**時**：ひなた野の届け物から、聖の森の依頼まで。二人で小さな依頼を重ねる日々（5章の「報酬が前回より増えた」につなぐ）。

1. **ベル**：朝のギルドで、掲示板の「正義は我らにあり」の紙の前に立ち、ベルが黙って拳を握る。後ろで、オオナムチがそれを見ている（10章の「見ていた」を回収）。二人で、荷運びや野犬払いの小さな依頼を続ける。
2. **オオナムチ**：港の荷運び。荷運びのトマリ、年寄りの漁師イサナ。イサナは、誰からも「おい、爺さん」としか呼ばれない。網元の娘アサギだけが名を呼ぶ。宿の入口で、亜人の子どもたちが断られるのを見て、自分の子どものころを思い出す（8章の回想を回収）。
3. **ベル**：野原の依頼で、皮をはがれて泣いている白い兎を見つける。オオナムチは「真水で洗って、蒲の穂に寝かせる」と手当てし、癒やしを重ねる（古事記の、大穴牟遅と因幡の白兎）。ベルは、魔界の古い昔話を思い出す。
4. **オオナムチ**：夜の宿。ベルとの、堅めの稽古の始まり。オオナムチは、イサナの顔だけが日ごとに薄く見えることに気づく。翌朝、桟橋でイサナの名を呼ぶと、老人の顔が少しだけはっきりした（名呼びの、いちばん小さな芽）。
5. **ベル**：夕暮れの港で、アサギが父の網を繕いながら、イサナの名を何度も呼ぶ。掲示板に「聖の森、薬草の護衛」の紙が貼られる（5章へ）。

**回収**：10章の「掲示板の前で拳を握るベルを見ていた」、8章の「宿の入口で断られる子どもたち」、5章の「報酬が増えた」。
**ゲーム**：ミナモの港・野原の白兎・ギルドの掲示板。

## ② 5.5章「森の底の石」　（5章のあと・聖の森からミナモへ）

**視点**：オオナムチ・コノハ・ハニヤス・ベル　**時**：5章の翌朝から、ミナモに戻るまで。

1. **オオナムチ**：森を出る前に、スクナから頼まれる。洞窟の避難民が通った地下道を、苔の大蜘蛛がふさいだ。コノハが、文句を言いながらついて来る。
2. **コノハ**：苔むした地下道の奥で、古い石碑を見つける。文字は「かため」。エルフの言葉でも人間の言葉でもない、もっと古い祈りの言葉だった。後から来たスクナが言う。「民は、種族を超えて、同じ祈りを持つ」（9章でオオナムチが思い出す言葉を回収）。苔の大蜘蛛は、卵を守っていただけだった。倒さずに、巣を移させる。森の弓手シイと語り部ユズリハが、森で「いないもの」にされていることに、コノハが気づく。
3. **ハニヤス**（魔界・埴の里）：クナドに導かれて、洞窟の避難民が着く。若い鴉族の女は、まだ家族を探している。ハニヤスは、黙って鍬を一本渡す。
4. **ベル**：帰り道、森の村ククノチで一泊。耳を当てると声が聞こえる大樹の話。ベルは、オオナムチに初めて名の話をする。「まことの名が、存在の輪郭を作る」（9章の「聖の森で、ベルが言っていた」を回収）。薬草摘みのツユクサの顔が、オオナムチにはひどく薄く見えた。
5. **オオナムチ**：宿場町ヤチマタを通ってミナモへ。宿場では、炉ヶ岳へ鉄を運ぶ荷車の噂が流れていた（6章へ）。

**回収**：9章の「聖の森の老薬師が言っていた」「聖の森で、ベルが言っていた」、5章の避難民のその後。
**ゲーム**：苔むした地下道（苔の大蜘蛛）・言の葉の石碑・ククノチ・ヤチマタ。

## ③ 6.5章「納めの鉄」　（6章のあと・炉ヶ岳の麓）

**視点**：オオナムチ・坑夫の母・ベル　**時**：6章の霧の朝から数日。ベルはタケル脱走の知らせを受けたばかりで、表に出さずに張りつめている。

1. **オオナムチ**：山道を下る朝、ベルの沈黙が重い。オオナムチは気づいても、聞かない。麓の鉱夫村マガネでは、王都に納める鉄が倍になり、坑夫たちが夜も掘っている。
2. **坑夫の母**：ヤチマタの大宿で働く息子へ、字の書ける人に頼んで書いてもらった手紙がある。母は、それを冒険者に託す。
3. **ベル**：子どもが古い竪坑に迷い込み、奥で岩喰らいが目を覚ます。ベルは力を使えない（阻害）。覚えたばかりの火種で、オオナムチが道を開く。「火は、作り直す力でもある」。鍛冶のハガネ、炭焼きのスミ、炉番の弟子タタラ。三人は、坑夫の名簿から名前が消されていた。
4. **オオナムチ**：ヤチマタで、息子に手紙を届ける。息子は、指で一字ずつたどって読む（4章の、ハルとユウの手紙と重なる）。オオナムチは、ユウのことを思う。
5. **ベル**：夜、言伝でオモイカに尋ねる。「経緯は、まだ調べております」。ベルは「急がずともよい。責めるな」と返す。翌朝、二人はミナモへ戻り、獣ノ原への依頼を受ける（7章へ）。

**回収**：6章の終わりのベルの一瞬の顔、6章の「倍の発注」の重さ、7章の「責めるな」の前ぶれ。
**ゲーム**：マガネ（母の手紙の頼みごと）・古い坑道（岩喰らい）・ヤチマタ。

## ④ 7.5章「風の岩溝」　（7章のあと・獣ノ原からミナモへ）

**視点**：ウズメ・オオナムチ・ベル　**時**：7章の翌朝から数日。王の網を避けて、ミナモへ戻る道。

1. **ウズメ**：網に見つからない抜け道へ、ウズメが二人を案内する。風の岩溝へ。ひなた野から移ってきた機織りのノギクと子どものフキ、畑の老人タネ。井戸番のナズナは、井戸に泥を投げ込まれた日から、名を呼ばれなくなっていた。
2. **オオナムチ**：岩溝の上で、風の大鷲が巣を守っている。倒さずに、堅めで風を受け流して通る。ベルの輪郭が、また一拍ゆらぐ。オオナムチは、見なかったことにする。
3. **ベル**：イワクラ城の城下。衛士は年寄りばかりで、若い者は王都の兵に取られ、白い腕章をつけて帰ってくる。老いた衛士が、前の王の頃の話をする。
4. **オオナムチ**：城下の宿。オオナムチが「王都へ行きたい」と言う。ユウのいる軍務局、腕章の根がある場所。ベルは止めかけて、受け入れる。この夜から、ベルの呼び方が「そなた」から「おまえ」に変わる。
5. **ベル**：ミナモに戻る。オモイカの言伝が来る。二人は、王都へ向かう（8章へ）。

**回収**：本編にない「王都へ行くと決めた経緯」、8章からのベルの呼び方の変化、ヒエダが語り継ぐ「前の王の頃」。
**ゲーム**：風の岩溝（風の大鷲）・イワクラ城。

## ⑤ 8.5章「削られた丘」　（8章と9章のあいだの三日・王都の外）

**視点**：ベル・オオナムチ・コトシロ　**時**：祝賀までの三日。ベルは阻害が半分を切っていて、宿の屋根裏から動けない。オオナムチだけが外へ出る。

1. **ベル**：屋根裏。指先が震える。「平気だ」と言い張るベルが、オオナムチに外を見てくるよう頼む。ミオの夫カズミは教師で、王都から半日のタカマの丘へ、よく子どもたちを連れて行っていたという。
2. **オオナムチ**：関所の町ウキハシ。関で、亜人だけが書付を求められる。断られる子ども。「念のため」。名を失いかけた旅の歌い手のウタが、橋のたもとで歌っている。誰も足を止めない。
3. **コトシロ**：軍務局の書庫。写しを取る、二度目。名簿の端に、書記シロエの名が線で消されている。シロエは、写しを取ろうとして院へ送られた前任者だった。
4. **オオナムチ**：タカマの丘。社の紋は、五つとも削られていた。巡回の兵が来る。オオナムチは心鎮めを唱える。兵の槍が下がり、兵は自分の名を小さくつぶやいてから、去っていく（衛士ミカゲ。完全には戻らない）。
5. **ベル**：夜、戻ったオオナムチの話を聞く。ヒナは、丘の花の種を鉢にまく。明日の夜が、祝賀だ（9章へ）。

**回収**：9章の五つの削られた紋の前ぶれ、8章の「三日」、コトシロの「三度に分けて」写しを取ること。
**ゲーム**：巡回の兵を目覚めさせる・ウキハシの関所・タカマの丘の削られた紋。
**本編との合わせ**：9章でオオナムチが院を「初めて見上げる」ので、院には近づかない。戦いもしない。

## ⑥ 四天王編「土と角と牙と羽」　（11章のあいだ・魔界）

**視点**：ハニヤス・スサノ・ナキメ・ミカヅチ・オモイカ　**時**：11章の修行の日々。本編の日数を増やさず、同じ日々を四天王の目から描く。

1. **ハニヤス**：朝、土に挨拶する人間の若者を見ながら、1章で畦の芽を踏みかけたベルを思い出す。畑番のアカネは、根の洲が焼けた日から、名を呼ばれなくなっていた。
2. **スサノ**：嵐ヶ峰の寄り添いの里。群れの掟を破って、ついて来られない者を切り捨てない里を作った理由。耳の聞こえない嵐狼の子が、オオナムチに手話で名前を教える。
3. **ナキメ**：タケル脱走の夜を、まだ自分で責めている。言霊にかかりにくくする稽古で、オオナムチの心の静けさを知る。伝令のクロハは、脱走の夜に見張りをしていて、それから誰にも名を呼ばれていない。
4. **ミカヅチ**：夜、ベルとオオナムチの夜の特訓を、遠くから見る。ベルの最後の教え「守るとは、倒すことではない」（11章の「夜の特訓の最後」を回収）。オハバリ城の鍛冶ヤマブキの打った刃。昔、ミカヅチがベルと一騎討ちをした日の話。
5. **オモイカ**：夜明け前、ヒラサカの関。随員十四人のための、名のない石の前に立つ。まだ名を言えない。坂上の砦へ向かうオオナムチを見送る（11章の決戦へ）。

**回収**：11章の「夜の特訓の最後」、作者メモの「ナキメの言霊耐性の稽古」、1章の畦の芽、2章・11章の一騎討ち。
**ゲーム**：魔界の拠点（オハバリ城・ヒラサカの関など）、四すくみ。

## ⑦ 番外編①「五つ目の窪み」　（エピローグのあと）

**視点**：クナド・オオナムチ・タカマの社守・ベル　**時**：エピローグの比良坂の縁から。

1. **クナド**：オオナムチが「五つ目の窪みへ行きたい」と言う（エピローグの最後から）。クナドは「四つの柱の声を、もっと深く聞いてから」と答える。
2. **オオナムチ**：師たちを巡る。ハニヤスに守り、ミカヅチに攻め、ナキメに再生、オモイカとベルに知を教わる。
3. **オオナムチ**：ツクヨミの社。暗い社の灯籠を「西、真ん中、東」の順に灯す謎。祭壇に、細い月の印がある。
4. **オオナムチ**：大穴の最深部の、試練の扉。天の声の六つの問い（森・鍛冶・差別・洗脳・正体・共生）。どれも、旅で出会った顔を思い出せば答えられる問いだった。五つ目の窪みに、調和の光が灯る。大穴の番人だったウツホの名も、ここで戻る。
5. **タカマの社守**：五つ目の紋を、自分の手で彫り直す（8.5章のタカマの丘につなぐ）。
6. **ベル**：宮での、最後の手合わせ。ベルは手を抜かない。終わったあと、ベルがオオナムチの「まことの名」を呼ぶ。12章で王が奪おうとした名を、今度はベルが呼ぶ（12章の「おまえの、まことの名を、呼ぶ」と対になる）。

**回収**：9章・エピローグの五つ目の窪み、8.5章の削られた紋。
**ゲーム**：クリア後の師の手合わせ・ツクヨミの社・試練の扉と天の声・タカマの社守・ベルとの最終手合わせ（今のゲームの場面の文を、小説の文に替える）。

## ⑧ 番外編②「旗を降ろさぬ者たち」　（エピローグのあと）

**視点**：タケル・オオナムチ・残党の弓兵・ベル　**時**：エピローグから少しあと。

**本編との合わせ**：12章で「洗脳は王の死で解けた」。そのため、残党が解けない理由を決める。案：9章で「中継の黒い石は一つではない」とあった。北の古い砦に残った中継の石が、死んだ王の最後の命令「三度は、言わぬぞ」を、こだまのように繰り返している。

1. **タケル**：根の洲で耕すタケルに知らせが来る。北の砦の兵が、旗を掲げたまま戻らない。率いるのは、タケルに剣を教えた老将（名前は仮。あとで決める）。
2. **オオナムチ**：コトシロの写しから、中継の石の場所が分かる。ベルは魔王の姿のままでは行けない（王の言葉を、本当にしてしまうから）。オオナムチとタケルの二人で行く。
3. **残党の弓兵**：砦の中。頭の中の温かい声。けれど、声は日ごとに同じ言葉しか言わなくなっていた。
4. **オオナムチ**：歩兵・弓兵・術師・騎兵・旗持ち・薬師の隊と向き合う。誰も殺さない。心鎮めと名呼びで、一人ずつ目を覚まさせる。
5. **タケル**：老将との一騎討ち。斬らない。オオナムチが老将の名を呼ぶ。タケルは、中継の石を自分の手で砕く（12章の「俺の手で、直す」）。
6. **ベル**：戻った兵たちを、比良坂で迎える。

**回収**：9章の「中継点は一つではない」、12章のタケルの償い、エピローグのミサキの手紙を探す旅。
**ゲーム**：クリア後の残党軍（残党の6種類と残党の将）。

## ⑨ 番外編③「名を喰う底」　（エピローグのあと・いちばん最後）

**視点**：カズミ・オオナムチ・ベル・アサギ　**時**：番外編①②のあと。

**本編との合わせ**：12章で「王が死んでも削られた名は戻らない。名呼びで取り戻す」。10章で「院には、まだ多くの人が残っている」。この二つを締めくくる。

1. **カズミ**：院から戻れなかった人たちに、文字を教え直している。まだ名を思い出せない人が、何十人もいる。
2. **オオナムチ**：クナドが、大穴のさらに下に深い淵があると明かす。削られた名は、輪郭を失って、そこへ沈んでいく。
3. **ベル**：上の淵の番人、黄泉の大蛇。須佐之男が大蛇を酔わせた八塩折の甕の話。ベルとオオナムチが、二人で並んで戦う（本編で一度もなかった）。
4. **オオナムチ**：淵の底の名喰いの王。沈んだ名の文字を吸い込んで形になった、黒い鎧の影。王の残した仕組みの、最後の姿。オオナムチは、旅で出会った24人の名を、一人ずつ呼ぶ。イサナ、アサギ、トマリ……。
5. **アサギ**：港で、イサナが自分の名を名乗る。24人の、その後の短い断章。ヒナの花が咲く。

**回収**：10章の院に残った人たち、12章の名呼び、各章の名の欠片の24人、ヒナの花の開花。
**ゲーム**：黄泉の深淵（黄泉の大蛇・名喰いの王）、名の欠片を全部返したときの「名告りの勾玉」。

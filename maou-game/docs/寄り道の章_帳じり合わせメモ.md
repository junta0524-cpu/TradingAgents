# 寄り道の章　帳じり合わせメモ（あとでまとめて直す）

ユーザー決定：章どうしの食い違いの見直しは、あとでまとめてやる。書いた担当が「気になる点」に挙げたものと、読んで気づいたものを、ここに貯めておく。

## すでに直したもの

- 6.5章：オオナムチが「ひなた野の人が葛の里へ移った」と前から知っていた一文を消した（本編7章で着いてから驚くため）。
- 番外編二：兵の名「カイ」を「マサゴ」に（6.5章の坑夫の息子カイと重なるため）。
- 8.5章：書記シロエを男に（番外編三の「9章の院の、指の曲がった男」に合わせた）。
- 5.5章：まだ出会っていないツユクサの名が先に出ていた一文を直した。

## これから確かめるもの

### 時の流れ
- 収穫祭の日：1章「三日後」、1.5章では「2章の戦いの日が祭りの日」、11章で開かれ、エピローグでも開かれる。本編もはっきりしない。
- 番外編の時期：①約三か月後、②四か月、③半年、④収穫のころ（柿・麦）、⑥約一年後の秋。④の「根の洲の土はもう黒くない」とエピローグ・⑥の季節の書き方。
- 5.5章のユズリハの訪問を、番外編六は「去年の秋」と書いている。

### 人と名前
- 十四人の随員：1.5章「十四人。私を入れて十五人」、2.5章「十四人」、番外編五で十一人の名（アオイ・カガリ・シノ・ハヤテ・ミズキ・ツムギ・イブキ・コハル・トウゴ・ユラ・セナ）。番外編六は名を出していないので、⑤の名に合わせて足すか。
- 鬼の名：番外編五の護衛「カガリ」と、番外編六の鬼の若者「カグラ」が似ている。
- 2.5章の鬼の看守「ヒサメ」、参謀見習い「イオリ」（21）。番外編二の砦の兵（セキ・ナギ・トキワ・マサゴ）、12.5章の若い兵「テツ」（マガネの鉱夫の三男）と重ならないか。
- 3.5章の亜人の行商人の親子（名なし）が、4章のひなた野の場面に出てくるかどうか。
- 番外編四の母「ヨネ」、ゴロウの身の上（字が右に傾く・柿むきがうまい）。番外編二のゴロウの書き方と合うか。
- ミカゲ：8.5章「城の衛士」、番外編三「タカマの社の石段を掃く」。
- ウツホ：番外編一で鬼の老人（クナドの前の番人）。3.5章のクナドの「名を思い出せない先任」と同じ人か。

### しくみ・品
- 中継の石：番外編二「人間界に七つ」。9章「一つではない」。
- 八塩折の甕：番外編三で持ち帰ったあと誰が持っているか。
- 五つの紋：イワクラの井戸（7.5章）・タカマの社（8.5章・番外編一）・院の地下（9章）。多すぎないか。
- 「まことの名」：番外編一（ベルがオオナムチの名を呼ぶ）、番外編三（「おまえの名は、私が覚えている」）、番外編六（ベルが「ベルイザナが、まことの名だ」と名乗る）。重なり方。
- 夜の特訓の「最後の夜」の場所（四天王編はぼかした）。
- ベルの外套：3.5章「王の外套を仕立て直した」。4章「上等な縫い取りだが新しい」と合うか。
- クナドの「顔を見ない・名を聞かない」掟（3.5章）と、5章・10章のクナドの出方。

### 本編との細かい合わせ
- 6章の終わり「三人は霧の山道を」（同行は二人）。6.5章は二人として書いた。
- 2章で兵の持ち物はみな消えるのに、手紙だけ残る理由（2.5章：丘の根に引っかかっていた）。
- 番外編四でタケルが魔王に頭を下げるのを「二度目」と書いた（一度目＝12章の土下座）。

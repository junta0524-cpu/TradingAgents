## B　章と章のあいだ（4章）

### B-1　1.5章「避難の夜」　（1章の終わりから2章の終わりまでの、魔界の側）
**視点**：ハニヤス・スサノ・ナキメ・オモイカ　**時**：ベルイザナが一人で大穴へ歩き出した夕方から、ミカヅチが「避難は終えました」と報告するまで（2章と同じ時間を、魔界の側から）。
1. **ハニヤス**：収穫祭の卓が空いたままの畑。王に託された民の避難を始める。畦の芽を、皆で踏まないように歩く。
2. **スサノ**：寄り添いの里の、足の弱い者・耳の聞こえない子を、置いていかずに運ぶ。群れの掟より、遅い者に歩幅を合わせる。
3. **ナキメ**：宮で、腹に傷を負ったオモイカの手当て。オモイカは、随員の顔を一人ずつ数え、言伝で王へ報告を送る。
4. **オモイカ**：熱の中で、会談の間を思い出す。誰かに押されて回廊へ逃れたこと。押した手が誰のものか、分からない（1章の「誰の手だったか、分からない」）。
5. **ミカヅチ**：鬼の若い衆を連れて、根の洲へ走る。途中で、焼け野の向こうの静けさに気づく（2章の終わりにつなぐ）。
6. **ハニヤス**：夜明け。避難した民で埋まった段々田。空いたままの収穫祭の卓に、誰かが、黙って一つずつ、椀を置いていく。

### B-2　2.5章「牢の粥」　（2章のあと、3章の前）
**視点**：鬼の看守・ベルイザナ・ナキメ　**時**：根の洲から、タケルたち六人が牢に入れられる日まで。
1. **鬼の看守**：生かされた六人を、牢へ運ぶ。ベルの命令「傷つけるな。飢えさせるな」。人間の飯の作り方を知らない鬼たちが、粥を炊く（3章でタケルが完食する粥）。
2. **ベルイザナ**：宮の露台の夜。外套の陰で震えていた右手（2章でミカヅチが見た）。顔を見ずに消した兵たちのことを、初めて考える。
3. **ナキメ**：牢の六人を、遠くから朧で見る。タケルの中に、自分のものではない声の根がある（3章の分析の前ぶれ）。
4. **鬼の看守**：参謀格の五人は、粥に手をつけない。タケルだけは、眠ったまま。看守は、粥を温め直し続ける。
5. **ベルイザナ**：書きかけの手紙（2章の兵の）を拾っていた鬼が、ベルに届ける。宛名は「ミサキへ」。ベルは、読まずに、ミカヅチに預ける（エピローグで根の洲から掘り出される手紙とは別の、もう一通。またはその写し。※帳じり合わせで決める）。
6. **ベルイザナ**：二日目の夜、牢へ下りていく（3章の場面につなぐ）。

### B-3　3.5章「比良坂を渡る」　（3章のあと、4章の前の三日）
**視点**：オモイカ・クナド・ベル　**時**：偽名「ベル」が決まった夜明けから、ミナモに着くまでの三日。
1. **オモイカ**：宮の露台で、旅支度のベルを見送る。黒い外套、角と翼を畳む練習。「次の手を聞かせてくれ」。
2. **クナド**：比良坂の大穴を、ベルを連れて渡る。光の筋の道。岐人だけが知る、境の掟。
3. **ベル**：人間界の最初の夜。街道沿いの野宿。火の熾し方が分からない。通りかかった亜人の行商人の親子に助けられる。
4. **ベル**：二日目、街道の宿場。初めて銅貨を使う。値段が分からず、払いすぎる。宿で断られる亜人の行商人を見て、何もできない（4章の屋台の場面の前ぶれ）。
5. **クナド**（短い場面）：境の岩の上で、人間界へ消えていった王の背中を思う。
6. **ベル**：三日目の夕方、ミナモの灯が見える丘。「私の名は、ベル。ただの冒険者だ」を、もう一度、声に出してみる（4章の冒頭へ）。

### B-4　12.5章「三か月」　（12章の決戦から、エピローグまで）
**視点**：オオナムチ・ユウ・タケル・ベル・ヒエダ　**時**：決戦の翌日から、三か月。
1. **オオナムチ**：決戦の翌朝。王の喉を断った手の震えが止まらない。眠れない夜、ベルが隣に座る。何も言わずに、手を重ねる。
2. **ユウ**：腕章を外したあとの、頭の中の静けさ。温かい声が消えて、怖い。葛の里へ帰る道で、何度も引き返しかける（エピローグの「元気だよ」へ）。
3. **タケル**：魔界の裁きの場。裁きを求めるタケルに、ベルが「直せ」と言った（12章）その後。根の洲の鍬を、初めて握る日。ミカヅチが監督を申し出る。
4. **ヒエダ**：葛の里。傷の癒えた語り部が、子どもたちに、前の王の頃の話をもう一度語る。今度は、新しい話も一つ足す。
5. **ベル**：同盟の儀の支度。人族の老議員との最初の文のやりとり。オモイカが、杯を十四並べたいと言う。
6. **オオナムチ**：三か月目の朝。手の震えが、ようやく止まる。比良坂の縁で、五つ目の窪みのことを思う（エピローグの最後へ）。

## A　番外編三のあと（3章）

### A-1　番外編四「ミサキへ」
**視点**：タケル・ミサキ・オオナムチ　**時**：番外編三のあと。
番外編二で分かった、手紙の書き手ゴロウの村へ。タケルが、焼け残った手紙と、自分の言葉で書いた続きを持って行く。娘ミサキは、十二歳くらい。父を殺した軍の、いちばん前にいた勇者を、どう迎えるか。オオナムチが同行するが、口は挟まない。最後に、ミサキが手紙の「続き」を自分で書く。

### A-2　番外編五「十一人の名」
**視点**：オモイカ・ナキメ・ベル　**時**：番外編四のあと。
オモイカが、残りの随員十一人の名を、ようやく語る。一人ずつ、その人の好物、家族、最後に交わした言葉。ナキメが記録を書く。ヒラサカの関の名のない石（四天王編）に、十四の名が刻まれる。ベルが、一人ずつ名を呼ぶ。

### A-3　番外編六「名を呼び合う祭り」（いちばん最後の章）
**視点**：ユズリハ・ハル・コノハ・ベル・オオナムチ　**時**：番外編五のあと、次の秋。
5.5章でユズリハが語った、昔の「名を呼び合う祭り」を、魔界の収穫祭と一緒に、もう一度ひらく。人間・エルフ・ドワーフ・亜人・魔族が、同じ畦に並ぶ。知らない者に名を聞いて、呼ぶ。寄り道の章に出た人たちが、みんな集まる。スクナがベルを見て目を細めた理由（5章）に、少しだけ触れる。最後は、ベルとオオナムチの「半分ずつ」。

# 寄り道クエスト　設計図の一覧

ユーザー決定：寄り道の章16章を、読み物ではなく、本編とは別の「寄り道クエスト」として遊べるようにする。
遊び方は「歩く＋話す＋戦う」、文章は「セリフは小説のまま全部、地の文は要所」、魔界の人が主役の章は「その人を操って遊ぶ」。
1章ずつの設計図は同じフォルダの `<章>.md`（受け方・操作する人・流れ・新しく要るもの・ごほうび・気になる点）。

## 作るもの（あらまし）

- しくみ：クエストの始まりと終わり（いまの仲間・場所・章・道具袋を預けて、終わりに戻す）、操る人の入れ替え（見た目と名前）、クエストのあいだだけ出る人と調べる所、進み具合の目的の1行、「耐えきれば勝ち」「心鎮めで勝つ」戦い。
- 新しいマップ（約9）：根の洲、宮の台所（看守の部屋）、大穴の光の道、街道と宿場、ユズリハのうろの家、天津京の書庫、北の砦、北の山村、大穴の名の部屋。
- 新しい敵：ベルの稽古、オオナムチの手合わせ（11章）、残党の将ヤツカ。
- 新しい品：各クエストのごほうび（16個ほど）と、話に出る大事なもの。
- いまの「読みますか？」は無くし、クエストを終えると思い出の帳の「寄り道の章」に入る（読み物としても見返せる）。

## 決めてほしいこと（設計図の「気になる点」から）

1. 町の頼みごととの重なり：マガネの「母の手紙」、イワクラの「井戸の鈴」は、六・五と七・五と同じ話を別のセリフで描いている。
2. 名の欠片との重なり：クエストの中で名を呼ぶ人（アカネ・ウツホなど）が、名の欠片の持ち主でもある。
3. 書きかけの手紙：ゲームの2章ではベルが手紙を拾って持っているが、小説（2.5章）では鬼が焼け野に戻し、エピローグでタケルが掘り出す。
4. 番外編三の24人の名：名の欠片を全部返していなくても呼べるか。

## 決まったこと（ユーザー決定。すべておすすめの案）

1. マガネの「母の手紙」、イワクラの「井戸の鈴」の頼みごとは消して、六・五章・七・五章のクエストに置き換える。
2. 名の欠片とクエストは別々に数える（クエストで名を呼んでも、欠片を返したことにはしない）。
3. 書きかけの手紙は小説に合わせる：2章でベルが拾った手紙は、二・五章のクエストの中で鬼が焼け野に戻す（持ち物から消える）。エピローグ・番外編四とつながる。
4. 番外編三の24人の名は、名の欠片を全部返していなくても呼べる。

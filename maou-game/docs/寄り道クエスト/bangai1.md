## 気になる点
- ウツホは名の欠片の24人の一人（`js/data/names.js` の `utsuho`。欠片は大穴の上層）。10で名が戻るとき、案A＝欠片を拾っていなくても「返した」ことにする。案B＝クエストの場面は流すが、名の欠片の数は欠片を返したときだけ数える。
- 今の石碑の文（「細い月は西の空に。満ちた月は天の真ん中に〜」）と小説の文がちがう。案A＝小説の文に替える（謎としては少しむずかしくなる）。案B＝両方を刻む。
- クリア後の本筋をすでに先に進めた記録（師と戦い済み・扉を越え済み）では、その段の小説の場面を、クナドに話したときにまとめて流すか、思い出の帳の読み物で読むだけにするか。
- 七の演武場の絵がない。`palace` を夜の色で使うか、戦いの背景 `throne` に合わせた新しい背景を一枚作るか。
- 六の社守の場面は、今の `talkWhen`（調和のあと、五つ目の紋の話をする）と同じ出来事。場面を流したあとも、そのひと言は残してよい。

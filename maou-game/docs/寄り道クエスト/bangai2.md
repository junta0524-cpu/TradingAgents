# 番外編二　旗を降ろさぬ者たち

元の小説：`docs/novel/bangai2.md`（一〜七）。いまの読み物：`side_bangai2`（offer は iwakura・13章・番外編一を読んだあと）。
残党の将ヤツカ（タケルに剣を教えた老将）と、北の古い砦の中継の石。

## 受け方
- いつ：13章、番外編一のクエストを終えたあと（`side_read_side_bangai1`）。
- どこ・だれ：`yomi_hani` の西の焼けた畦で鍬をふるう、新しい人 タケル（13章だけ。`takeru13`）。話すと一の場面が始まる。
  （根の洲のマップはないので、畑の西の端を根の洲の続きに見立てる。案）

## 操作する人
- 二のあと〜四：オオナムチとタケル（タケルは臨時の仲間 `join`。ベルは `split: 'away'`＝宮で待つ）。
- 五（ヤツカとの一騎討ち）：タケル一人を操作（オオナムチは `split: 'watch'` のように見守る形）。
- 六（中継の石）：タケルを操作して石室へ歩く。
- 三（弓兵セキ）・七（比良坂のベル）：短い場面だけ。
- 七のあと：タケルが別れ（`leave`）、ベルとオオナムチの二人に戻る。

## 流れ
1. 場所 `yomi_hani`（タケル）／場面 一 全部（「手が止まっているぞ」〜コトシロの読み上げ『旗を降ろすな。〜』、タケルが言葉を知っていた段まで）。短い場面（タケルの目から）。背景 `scorched_after`、人はタケル・ミカヅチ・コトシロ。
2. 場面 二 全部（露台。「王が死んで、洗脳は、解けたはずです」〜「……覚えよう」）。短い場面。背景 `balcony`、人はベル・オモイカ・コトシロ・タケル・ミカヅチ・オオナムチ。
   終わりに：タケルが加わる（`join`）、`split: 'away'`、大事なもの「北の砦の名簿」を手に入れる。目的「大穴から人間界へ。イワクラ城の北の、古い砦へ」。
3. 場所 `oana_jou` → `world_ningen` →（イワクラ城の北の山へ歩く）／戦い：道すがらのクリア後の組（`encounter.byChapter[13]` の byLevel。残党の隊も出る）。
4. 場所：新しいマップ `kita_toride`（北の古い砦の麓と雪原）に入ったとき（`onEnter`、一度だけ）／場面 三 全部（物見台のセキとナギ。「セキ」「麦湯だ。薄いけどな」〜胸の底の棘、雪の風）。短い場面。背景 `fortress`（夜の色）、人はセキ（`soldier`）・ナギ（`clerk`）。
5. 場所 `kita_toride` の麓の林／場面 四の頭（「門の上に、弓兵が二人」〜「行きます」）。林を出て雪原の `triggers` を踏むと、矢の場面（「止まれ！」〜「――堅め」、門が開いて歩兵がなだれ出る）。
6. 戦い①：雪原。`zantou_hohei`×4＋`zantou_kusushi`×1。新しい戦い方「目覚めさせるだけの戦い」（全員の体力が1から下がらない。目覚めさせると消える）。
   hook：はじめのラウンドの終わりに「――心鎮め」〜「マサゴ」「南の、浜辺の村の、マサゴさん。年は、十九」「なんで、俺の、名を」「お母さんが、議会に、手紙を出していました。〜」。
7. 戦い②：騎兵が厩から。`zantou_kihei`×2＋`zantou_hohei`×2（同じく目覚めさせるだけ）。hook：騎兵が一人目覚めたとき、タケルの「怪我は、ないか」と騎兵の「……勇者、さま」。
8. 戦い③：門の内と城壁の上。`zantou_jutsu`×1＋`zantou_hata`×1（トキワ）＋`zantou_yumi`×1（セキ）。hook の順：
   - 2ラウンド目の終わり：術師の甘い声（地の文の『惑わされるな。それは、魔族の手口だ』）、「トキワさん」「トキワさん！　山の炭焼きの村の、トキワさん！」（旗持ちはまだ止まらない）。
   - 3ラウンド目の終わり：弓兵の矢が逸れる段。「セキ、やめろ！　あいつ、俺たちの名前を、呼んでるんだぞ！」（名前「薬師」）、「セキさん！」「ナギさんが、隣にいるでしょう。〜」→ セキが目覚める（`st` で弓兵を目覚めさせる）。
   - 残りを目覚めさせると勝ち。勝ったあと「雪原に、槍が、一本、また一本と、置かれていった。」
9. 場所 `kita_toride` の中庭（門の内）／操作：タケル一人／場面 五の前半（「ヤツカ様」〜「ならば、教え直してやる。旗を降ろすな。〜」）。
   戦い④：新しい敵 `zantou_yatsuka`（ヤツカ）とタケルの一騎討ち。耐える戦い（今の `hold` と同じ形。ラウンド数は balance.js）。タケルからは打っても体力は1から下がらない（斬らない）。
   hook：ラウンドの終わりに「甘い。それで、勇者か」「勇者では、ありません」。耐えきったら場面 五の後半（タケルの告白「ヤツカ様。俺は、魔界の会談の席で〜」〜「黙れ！」、オオナムチの「ヤツカさん。北の山村の、ヤツカさん。〜」〜「……ハツ」）。
10. 場所 `kita_toride` の物見台の下の石室（新しい部屋 `kita_ishimuro`）／操作：タケル一人／すること：黒い石を調べる／場面 六 全部（「タケルさん」「俺が、やりましょうか」〜「降ろすぞ」「……ああ」、白い旗が降りる）。
    石の声（『旗を降ろすな』など）は名前なしの声として出す。拳を振り下ろすたびに決定キーで進める（新しい命令は要らない。セリフを区切るだけ）。
11. 場面 七 全部（比良坂の縁。兵の列、ヤツカとベル「あなたが、魔王か」〜、セキとタケル「娘の名は」「ミサキ、だったと思います」〜、夜の名簿「マサゴさん。〜」〜「一人ずつ、覚える。何年かかっても」）。短い場面（ベルの目から）。背景 `hirasaka`（夜の段は暗くする）。
    終わりに：タケル `leave`、`split: null`、`base_hirasaka`（ヒラサカの関）に立つ。ごほうびを渡して記録。

## 新しく要るもの
- マップ：`kita_toride`（灰色の岩山の肩。南に麓の林、まん中に雪原、北に石の門と城壁、門の内に中庭、東に厩、北の隅に物見台）。`kita_toride` の中から入る小部屋 `kita_ishimuro`（12×9の型、まん中に黒い石の台）。敵の出ない所。
- 人間界の地図の出入口：イワクラ城の北の山のとなりに `kita_toride` への入口（`requires: { chapter: 13, if: 'sq_bangai2_go' }`、クエストを受けるまでは「岩山の上に、古い砦が見える」）。クエストのあとは、戻った兵たちの暮らしの声を置いてもよい（案）。
- 人：`yomi_hani` の13章のタケル（受ける人）。砦の中で目覚めた兵（戦いのあと、雪原や中庭に立たせる。セリフは足さない）。
- 敵：`zantou_yatsuka`（`js/data/enemies_post.js`）。今の残党の将 `zantou` を元に、名前「ヤツカ」、`unique`、`big`、`awaken`、`wis` を書く。絵は今の残党の将の絵を使う。
- 臨時の仲間：`TEMP_PARTY.takeru`（balance.js）。クリア後のレベルに合う強さ（案：オオナムチのレベルに合わせて決める式、または Lv60 ほどの決まった数字）。
- 大事なもの：「北の砦の名簿」（`read` で名簿の説明。小説に出る名＝マサゴ・トキワ・セキ・ナギ・ヤツカ）。
- しくみ：
  - 目覚めさせるだけの戦い：`battle` に `spare: 'all'`（ch08_5.md の心鎮めの戦いと同じ広げ方）。
  - 主役の入れ替え（ch08_5.md と共通）：`lead: 'takeru'`。戦いもタケル一人で戦う。
  - hook から敵を一人目覚めさせる（8のセキ）：今の `G.battle.tryAwaken` を hook から呼べるようにする。
  - クエストの進み具合（`G.state.vars.sq_bangai2`）と目的の行。目覚めた人数（`G.state.awakened`）・ギルドの残党の依頼には、この戦いの分も数える。
- 背景：あれば「雪の砦の物見台」の絵（なければ `fortress` の色替え）。
- 数字（balance.js）：ヤツカの強さ、耐えるラウンド数、タケルの強さ、ごほうびの品。

## 気になる点
- 北の古い砦のマップが今のゲームにない（今の offer の `iwakura`＝イワクラ城は人の住む城下町なので、閉ざされた砦には向かない）。案A＝新しいマップ（上の案）。案B＝イワクラ城の「古い書庫」などの手直しで済ませ、砦の場面は短い場面にする（歩いて戦う所が減る）。
- 五の一騎討ち：タケル一人で残党の将と戦うと、強さの合わせ方がむずかしい。案A＝耐える戦い（上の案。負けたらその前からやり直し）。案B＝オオナムチも並んで戦い、タケルが倒れても続く形。
- 小説では、薬師ナギは城の上で味方につく人。戦い①に薬師（`zantou_kusushi`）を入れたが、ナギ本人とは別の兵にした。
- 一の舞台（根の洲）にマップがない。`yomi_hani` の西の端で受ける形にしたが、魔界の地図に「根の洲」の入口を足す案もある。
- 二の露台は小説では昼だが、今の背景 `balcony` は夜。色替えで昼にするか、夜のままにするか。
- 番外編二の砦の兵は42人（「四十二人」）。戦いで目覚めさせる数は、隊の数の合計で十数人にしかならない。残りは「戻った兵」として七の列に含まれる、と考える。

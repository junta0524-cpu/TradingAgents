# 番外編三　名を喰う底

- 受け方：クリア後（`chapter: 13`）で、番外編二のクエストを終えていて（`sq_bangai2_done`）、黄泉の深淵の二つの番人を倒していること（`gm:yomi_fuchi1:nushi`・`gm:yomi_fuchi2:nushi`）。土蜘蛛族の畑 `yomi_hani` の (9,11) に立つクナド（`kunado13`）に話すと始まる（この条件のあいだは `post_kunado` より先にクエストの場面）。いまの「ミナモに入ったら読みますか」の offer は外し、終わりの場面（六）をミナモで流す。
- 操作する人：ふだんはベル＋オオナムチ（クリア後のまま）。一だけカズミ一人（臨時）。終わると元の二人に戻る。
  - オオナムチの「並んで戦ったの、初めてですね」は、ゲームではクリア後に何度も並んでいるので少しずれる（気になる点）。

## 流れ

1. **カズミの授業**　場所：`yasuragi_ward`（場面の goto で入る。ふだんは来られない）
   - すること：カズミを操作。老人（p1）に話す →「あ」の場面。指の曲がった男（新しい人）に話す →「思い出せないのでは……」。最後に窓辺の鉢を調べると夜になり、ミオが来る。

2. **比良坂の縁で**　場所：`yomi_hani` のクナドの前（背景 `hirasaka` の場面）
   - すること：場面だけ。手紙は `letter`（『名が、下へ、落ちていく気がする』）。
   - 場面：二 全部（クナドの説明、ベル「行くぞ」「今度は、私も行く」〜クナド「甕で、八つ」）。
3. **八つの甕**　場所：`yomi_hani`

4. **螺旋の石段**　場所：`oana_soko` 南西の石段 → `yomi_fuchi1`

5. **上の淵の番人**　場所：`yomi_fuchi1` 中ほどの広間（(12,8)を踏むと）

   - 勝ったあと：オオナムチ「並んで戦ったの、初めてですね」〜ベル「悪くない」、クナド「持っておゆきください。番人が、通した証でございます」→ 大事なもの「八塩折の残り酒」。

## 気になる点

- 名の欠片（`G.state.names`）を返していなくても、場面では24人全員を呼ぶ（小説どおり）。欠片のしくみには触れない案（A）と、欠片を全部返していることを受ける条件にする案（B）。おすすめはA。
- 番人は倒し済みなので、同じ敵との「物語の戦い」をもう一度する。番人の印（倒すと消える）とぶつからないよう、クエストの場面はマスを踏んで流す。
- 「並んで戦ったの、初めて」はゲームとずれるが、セリフは変えない。
- 黄泉の深淵の暗闇（燭台）がクエスト中も暗いまま。灯した燭台を覚えていないなら、クナドの火で明るくする（`dark` をクエスト中だけ外す）案。

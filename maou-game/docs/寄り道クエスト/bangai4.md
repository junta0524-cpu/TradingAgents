# 番外編四　ミサキへ

- 受け方：クリア後、番外編三を終えたあと（`sq_bangai3_done`）。角ヶ原の演武場 `tsunogahara` のミカヅチ（`mika13`）に話すと始まる（この条件のあいだは `post_mika` より先）。いまの「マガネに入ったら読みますか」の offer は外す。
- 操作する人：一のあと、タケル（臨時・先頭）＋オオナムチ。ベルは来ない（小説「だから、行かぬ」）。`party { ids: ['takeru','oonamuchi'] }`、終わりに `['bell','oonamuchi']` へ戻す。五だけオオナムチ一人（`split: 'away'` でタケルを外す）。
  - タケルのセリフの顔は `takeru_free`（face_states.js の12章から）。

## 流れ

1. **根の洲の小屋**　背景 `scorched_after`（小屋の絵がないので焼け野の夜。`lodging` でもよい）
   - 場面：一の前半。書き損じの『ミサキ殿』、焼け残りの文は `letter`（『戦が終われば、英雄の凱旋で街が祝うそうだ。おまえにも土産を』）。ミカヅチ「まだ、起きていたのか」〜「どこかで、聞いた言い方だ」。操作はしない（小屋の中で手紙を前に座るだけ）。
2. **比良坂の縁**　背景 `hirasaka`
   - 場面：一の後半。ベル「北へ、行くそうだな」〜「名を、聞いてきてくれ。それだけでよい」、タケル「……分かった」。終わるとタケルが加わり、人間界の地図の大穴のとなり `world_ningen` (66,43) へ。
3. **北への道**　場所：`world_ningen`（大穴 → 北の山の村まで）
   - すること：タケルを先頭に歩く（オオナムチが半歩うしろ＝いつもの後ろの並び）。
   - 戦い：ふつうの出会い（クリア後の `byLevel`。残党は番外編二で鎮まったあとなので、出す敵からは外すのを推す）。
   - 村の手前の山すそ（新しい spot）を踏むと **三日目の夜**：背景 `forest_night`。タケル「オオナムチ」「おまえは、王を斬ったとき、何を考えた」〜「顔を、見に行く」。オオナムチの内心（言わないと決めていた／ベルが自分にしてくれたのと同じ）は語りで3〜4行。
4. **梅の木の上（ミサキ）**　場所：北の山の村に入ったとき
   - 場面：三。視点がミサキで、木の上で街道を見ているだけなので短い場面（操作しない）。セリフはヨネ「いいの。字の形を、見てるだけで」のみ、ほかは語りを縮める。終わりに二人の人影が村の入口に立つ。
5. **ゴロウの家**　場所：北の山の村
   - すること：タケルを操作。入口のセキに話す →「タケル殿」〜「あとは、タケル殿の口から」。梅の木の下の家の戸を調べる → 家の中へ。
   - 場面：四 全部（「……どうぞ」、タケル「タケルだ」〜ミサキが飛び出す、ヨネ「立ってください」〜「誰も、あの人の名を、言わなくなっていたから」）。ミサキが読む文は `say`（一字ずつ区切った読み方のまま）。
6. **梅の木の下**　場所：北の山の村（外）
   - すること：オオナムチ一人を操作（タケルは土間に膝をついたまま＝家の中の人として置く）。梅の木の根もとを調べる → 場面。
   - 場面：五（ミサキ「おまえも、英雄？」〜オオナムチ「ミサキさんが、自分の目で見て、決めることだと思います」）。ミサキの内心は語りで縮める。
7. **ヤツカの家の夜**　場所：北の山の村（ヤツカの家の中）
   - すること：タケルを操作。夜になった村で、ヤツカの家の戸へ。
   - 場面：六 全部（ヤツカ「おまえは、昔から、先に謝る子だったな」〜ミサキ「続き。わたしが、書く」）。書き損じを燃やす所は語り。
8. **続きを書く朝**　場所：ゴロウの家の中 → 外
   - 場面：七。ミサキの視点で、文机の前の短い場面（操作しない。書くのは手紙の窓で見せる）。ミサキ「父ちゃんは、何を書いたと思う？」、ヨネ「さあね。……」「きっと、また、土産の話よ」。二枚の手紙は `letter` で原文どおり。外でミサキ「勇者さま、とは、呼ばないから」〜タケル「ゴロウ殿は、どんな人だった」。
   - 大事なもの：「ミサキの手紙」を受け取る（タケルが持つ）。
9. **根の洲〜比良坂の縁**　背景 `scorched_after` → `hirasaka`
   - すること：村を出ると、場面で根の洲へ（もう一度、人間界の地図を歩かせない）。
   - 場面：八 全部（ミカヅチ「届けたか」〜「分かっている者の手は、止まらん」、タケルの内心は語り。比良坂でベル「戻ったか」〜オオナムチ「半分ずつ、ですよ」）。
   - タケルが抜けて、ベル＋オオナムチに戻る。ごほうび。`sq_bangai4_done`。

## 気になる点

- 小説に戦いがない。道中のふつうの出会いだけにする案（A・おすすめ）と、山道に獣の群れの決まった戦いを1つ足す案（B）。
- いまの offer はマガネ。マガネを「北の山の村」と見なして人を足す案もあるが、マガネは坑夫の村でドワーフが多く、小説（梅の木・ヤツカの村）と合わないので新しい村を推す。
- 2章で、ベルは道具「書きかけの手紙」（`kakikake_tegami`）を持っている。小説ではタケルが土から掘り出した一通。クエストの始めにこの品を消す（タケルに渡った扱い）か、そのまま残すか。
- 七は春の梅なのに、五の語りに「秋の風」とある（小説の食い違い。帳じり合わせメモへ）。

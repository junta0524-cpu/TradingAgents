# 番外編六　名を呼び合う祭り（いちばん最後）

- 受け方：クリア後、番外編五を終えたあと（`sq_bangai5_done`。大事なもの「稲穂の封の文」を持っている）。聖の森の集落 `hijiri_village` で、うろの家の前に座るユズリハ（クエスト用の人）に話すと始まる。いまの「土蜘蛛族の畑に入ったら読みますか」の offer は外す。
- 操作する人：場面ごとに替わる（別行動と同じく、終われば戻る）。一＝オオナムチ一人、二＝ハル、三＝コノハ、四＝ベル一人、五・七＝オオナムチ一人、八＝ハニヤス。最後にベル＋オオナムチに戻る。一以外はすべて `yomi_hani`（敵が出ない）なので、戦わない臨時の操作役でよい。

## 流れ

1. **うろの家**　場所：`hijiri_village`
   - すること：オオナムチ一人で（`split: 'away'`）集落へ行き、ユズリハに話す。
   - 場面：一 全部（オオナムチ「ユズリハさん」〜コノハの伝言「別に、背負いたいわけじゃないけど、って」）。視点はユズリハだが、来る人はオオナムチなので、操作はオオナムチ。封の文を渡すと「稲穂の封の文」が消える。
   - 終わると目的「土蜘蛛族の畑へ」。人間界の地図→大穴→魔界の畑 `yomi_hani` へは、ふつうに歩く（ベルも戻る。戦い：ふつうの出会い）。
2. **大穴を渡る（ハル）**　場所：`yomi_hani`（畑に入ると）
   - 渡る所は短い場面（背景 `hirasaka`。クナドの後ろを列で歩く。操作しても一本道なので）：ユウ「ハル。足元、気をつけろ」〜「九つだろ」「もうすぐ十なの」、空が赤い所の語り。
   - すること：ハルを操作。段々田の上で手を振る嵐狼の子（`wolfkid`）に話す →`choice`「（手を、真似する）」→ ユウ「耳が、聞こえないんだ」〜「あの子の名前を、おまえが、真似したんだ」。ナズナ婆さまに話す →「ええ水が、流れとる」「井戸番の目で見りゃ、分かる。ここの者は、水を、大事にしとる」。
3. **祭りの前の日（コノハ）**　場所：`yomi_hani`（昼）
   - すること：コノハを操作。畦の端でユズリハを下ろす場面（「重かったわ」「すまんのう」「別に。謝ってほしいわけじゃないけど」）。畦を歩き回るスクナ（`wander`）に追いついて話す →「あなた、ここ、来たことあるの」〜「なんでじゃろうな」→ ハニヤスが来る「爺さん」〜「……土は、忘れはせん」。
   - コノハの内心 (まあ、いいわ) で終わり。
4. **祭りの夜（ベル）**　場所：`yomi_hani`（夜の色。卓 `L` のまわりに人を並べる）
   - すること：ベル一人を操作。荷車の親子に話す → ナツメ「今度、会ったら、教えるって、言ったでしょ」〜「だから、返さなくていいって」。卓の外れのタケル・ヤツカ・ミサキ母子を見る（調べると語り「それでも、二人は、同じ畑に、立っていた。」と (それで、よい)）。
   - 卓のいちばん奥の十四の杯（オモイカ）に話すと、大事なもの「八塩折の残り酒」が消えて杯に注がれる（語り「注いだのは、ハニヤスだと聞いた。」は残す）→ ベル「名を、聞け」〜鬼「ソウタ。飲め」。
   - そのあとイサナが来る →「あんたが、魔王様か」〜「残りの半分を、あの子がやった。それで、ええ」。ベルの内心は語り。
5. **名を聞く（オオナムチ）**　場所：`yomi_hani`（夜）
   - すること：オオナムチ一人を操作。話しかけられる（自動）「真の勇者殿の、お名前は」〜「殿も、いりません」。アカネ・クロハに話す（「アカネさん」「オオナムチ」）。卓の端の鬼の若者に話す →「あの」〜トドロキ「今年こそ、飲め。オオナムチ」。三人と話すと、ハルと嵐狼の子・ユウの所で (元気だよ) の語り。
6. **歌の最後の一行**　場所：`yomi_hani`（場面。操作しない＝座って歌を聞く場面なので）
   - 場面：六 全部。ユズリハ「昔、昔。……」〜スクナ『名を呼ばれた者は、もう、ひとりではない』、ユズリハ「……あんたか」〜スクナ「さあのう。爺さんなど、どこにでもおる」。ベルの内心（小さな神のこと・(呼ばれたくないなら、呼ばぬ)）は語り。歌は曲を `festival` 系に替えて流す（新しい曲を足すなら sound.js）。
7. **半分ずつ**　場所：`yomi_hani`（夜更け）
   - すること：オオナムチを操作して、畑の端の畦（新しい spot）まで歩く → 場面。
   - 場面：七 全部（「ベルさん」「ああ」〜「名を探すのも、半分ずつだ」「半分ずつ、ですね」「ああ。半分ずつだ」）。
8. **夜明けの畦（ハニヤス）**　場所：`yomi_hani`（明け方の色）
   - すること：ハニヤスを操作。畦の芽を3か所調べる（語り「芽は、一つも、踏まれていなかった。」ほか）。卓の奥の十四の杯を調べる（空になっている）。
   - するとウツホが来る「おう」「手伝うぞ。来年の、祭りの分じゃろう」→ ハニヤス「土は、黙っているが、忘れはせん」「人も、もう、忘れまい」。
   - ごほうび。`sq_bangai6_done`。最後の見出し（「完」ではなく「寄り道の章　おわり」）を出して、ベル＋オオナムチで畑に戻る。

## 新しく要るもの

- マップの手直し：`yomi_hani` に「祭りの前の日（昼）」「祭りの夜」「明け方」の三つの人の並びと色（`tint` をクエストのフラグで切り替え）。祭りの夜は卓に料理と灯り、奥に十四の杯（調べる所）。終わったら元に戻す。
- 人（祭りの間だけ）：ユズリハ（`elf2`。聖の森と畑）、ハル・ユウ・嵐狼の子・ナズナ・ススキ・クズハ・ノギク・フキ・タネ、シイ・ツユクサ、スクナ、荷車の男・ナツメ（`merchant`・`child`）、イサナ・アサギ・トマリ、イシコリドメ・カナメ・ハガネ・スミ・タタラ・ヤマブキ、コトシロ・ミオ・カズミ（ヒナ）、ミカゲ・シロエ・ウタ、クナド・ヨミジ・ホムラ・ウツホ、タケル・ヤツカ・ミサキ・ヨネ、オモイカ、鬼の若者トドロキ・イバラ、人間ソウタ。話しかけて小説にない人は一言の暮らしの声（新しい文は（　）の案内だけにし、セリフを作らない）。名の欠片の持ち主はこの間、元の場所から消す。
- 臨時の操作役：`hal`・`haniyasu`（戦わない）。コノハは既存の `konoha` を一人で。
- 大事なもの：「稲穂の封の文」（番外編五でもらう）を一で消す。「八塩折の残り酒」（番外編三）を四で消す。
- 装備：名呼びの盃（装身具。祭りの杯。仮の名。全部の能力が少し上がる）。

## ごほうび

- 名呼びの盃（装身具）。十六の寄り道クエストを全部終えた印として、思い出の帳の「寄り道の章」に花の印をつける案。

## 気になる点

- 小説に戦いがない（祭りの章）。戦いを入れない案（A・おすすめ）と、一のあと聖の森の道で決まった戦いを1つ置く案（B）。
- 二の「ユウの手紙の字が右に傾く」はミサキの父の字と重なる書き方。小説のままにする。
- 番外編三の「八塩折の残り酒」をとっていない（番外編三を読んだだけで遊んでいない）場合の扱い。クエストを順にしか受けられないので起きない想定。
- 人が多い。全員を畑に立たせると狭いので、名前が出る人だけ立たせ、ほかは背景 `festival` の場面の actors にする案。

# 一・五　避難の夜

- 受け方：11章（修行の間）とクリア後（`chapter: [11, 13]`）。土蜘蛛族の畑 `yomi_hani` の、収穫祭の卓（`L` のマス、x15〜21・y12/14）を調べる → （収穫祭の卓だ。――寄り道「一・五　避難の夜」を遊びますか？）の（　）の案内で「遊ぶ／読む／やめる」。
  - 1.5〜3.5章は「11章とクリア後に、魔界で、その章ゆかりの場所や人から始める」に決めた。理由：①思い出の帳は記録の外（見返しは仲間・道具・戦いを変えない）なので、戦いもごほうびも入らない。②章の変わり目に差し込むと、1.5章の 七（王が軍勢を消す）が2章の山場より先に出てしまう。③魔界を歩けるのは11章とクリア後だけで、11章はオオナムチが四天王に会う章なので、その人たちの「あの夜」を遊ぶのに合う。
  - 始まりに章の見出し「一・五　避難の夜」と（一章の終わりから二章の終わりまで。魔界の側）の案内。
- 操作する人：場面ごとに入れ替わる（いまの仲間・名前・場所・章の状態・道具袋は、始めに預けて、終わりに戻す）。
  - 一・九：ハニヤス一人（NEW `sq_haniyasu`）。三：スサノ一人（NEW `sq_susano`）。五・八：ミカヅチ一人（NEW `sq_mikazuchi`）。
  - 二・四・六・七（ナキメ・オモイカの場面）は歩かない。背景の絵と人だけで流す。
  - 九のあと、ごほうびを渡して元の仲間・場所に戻る。

## 流れ
1. 場所 `yomi_hani`（夕方の色＝1章の `ch1_evening` と同じ）／すること：始まると場面。終わったら若衆に話す。
   場面：一 の「王の背中が、赤い空の下に」から「ハニヤスは、鍬を、肩に担ぎ直した。」まで（語りは最初の2段落と「(民は、直せん)」だけ）→ 若衆に話すと「集まれ」から「王が、踏まずに行った」まで。話し手：ハニヤス・若衆。
2. 場所 `yomi_hani`／すること：畦の上の婆・荷車引きの鬼・嵐狼の子に話す（3人。話すと畦を歩いて南の端から消える）。
   場面：「老人たちが、孫に手を引かれて」から「誰も、畦を外れなかった。」を3人に分けて出す。
3. 場所 `yomi_hani`／すること：卓（3か所の spot）を調べて布をかける → 南の端へ歩く。
   場面：「ハニヤスは、最後まで、畑に残った。」から一 の最後「背後で、稲穂が、風に鳴っていた。」まで（卓を調べるたびに「卓に布をかけた。一つずつ。」など）。
4. 背景 `corridor`（人：ナキメ・オモイカ）。
   場面：二 全部（「大穴の縁の回廊の出口で」から「それきり、何も言わなかった。」まで）。セリフは全部。語りは血の跡・傷を見る所・「名だ、と、ナキメは気づいた。」の段落だけ。
5. 場所 `world_makai`（夜の色。嵐ヶ峰 (102,38) の南西の峰の道に置く）／すること：北東の嵐ヶ峰へ歩く。
   場面：三 の「嵐ヶ峰の北の斜面を」から「止めはせん」まで（歩き始めに）→ 道の半ばの見えない印で、子の手話「(王様は？)」から「(王様、強い)」と「(あいつは、一人で、何を背負いに行った)」まで。
   戦い：道の途中で決まった戦い1回 `arano_ookami` ×2（遅れた群れを狙う荒野の狼。逃げられない）。ふだんの出会いは下の出会い表。

   場面：三 の「夜半、群れは」から三 の最後「それでよかった。」まで（吹雪の峰の思い出の段落も、短くせず語りで出す。この章の大事な所）。
7. 背景 `palace`（暗くした宮の一室。人：オモイカ。あとからナキメ）。

## 気になる点
- 11章で遊んで畑へ戻ると、修行を三つ終えていれば収穫祭（`ch11_fest`）がすぐ始まる。戻った直後の1回は onEnter を止めるか、そのまま流すか。
- 一の「誰の座る席も、空いたままだった。」は九でも同じ文が出る。どちらも入れる（小説どおり）案。
- 三の子の手話は ( ) の書き方（本編1章と同じ）で、話し手は「嵐狼の子」。スサノの手話も ( ) で、話し手「スサノ」。
- 二・四・六・七はナキメとオモイカが歩かないので、遊べるのはハニヤス・スサノ・ミカヅチだけ。ナキメも歩かせたいなら、七を塔の階段を上る短い歩き（新しいマップ）にする案。
- 五の戦いは小説にない（夜の峰は静か）。入れずに出会いだけにする案もある。

  - 1.5〜3.5章を11章とクリア後に魔界で始める理由は ch01_5.md と同じ。この章は露台の旅立ちから始まるので、露台の扉を入口にする（人を増やさずにすむ。広間のオモイカはクリア後の師の場面があるので重ねない）。
  - 始まりに見出し「三・五　比良坂を渡る」と（三章のあと、四章の前の三日）の案内。

## 流れ

   場面：一 全部（「オモイカは、露台の手すりに」から「オモイカは、それを、長く見送った。」まで）。角と翼が沈む所で、先頭の見た目を `bell_true` → `bell` に替える（`rename` の look）。手鏡の段落は語りで残す。外套・剣・銅貨の受け渡しのセリフは全部。話し手：オモイカ・ベルイザナ。

## 気になる点
- 宿場の名：小説は「家は、二十軒ほど」の名のない小さな宿場。拠点の宿場町ヤチマタ（八つの道の大きな宿場）を使うと5.5章・6.5章の書き方と合わないので、新しいマップにした。ヤチマタで代えるなら、二十軒の文と合わない点を帳じり合わせメモへ。
- 女の子は名を「ないしょ」と言う。のちの章（ひなた野など）の誰かに当てるかは小説で決まっていない。見た目を `kid_ear` にすると、ひなた野の子と同じ型になる。
- 岐人の話し手名は小説どおり「岐人」（名乗らない）。11章からの「クナド」と同じ人だと顔で分かる。
- 戦いは小説にない（三日間、戦いはない）。3の野犬1回だけにして、出会いもなくす案もある。
- クリア後に遊ぶと、ベルの記録の強さは魔王（カンスト）。このクエストの間だけ4章の冒険者ベルの強さにする。

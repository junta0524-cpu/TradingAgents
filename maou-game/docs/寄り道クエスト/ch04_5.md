# 四・五　名を呼ばれない港

- 受け方：5〜9章とクリア後（いまの sidestories.js の offer と同じ `chapterFrom: 5, chapterTo: 9, chapterAlso: 13`）。ミナモのギルド `minamo_guild` に入ったとき、「寄り道（四・五）を遊びますか？」と聞く（いまの「読みますか？」を「遊ぶ／読む／あとで」に替える）。「あとで」のときは、ギルドの奥の掲示板 (12,1) を調べると、もう一度聞く。
  - はじめに章の見出し「四・五　名を呼ばれない港」と、（四章と五章のあいだ。ひなた野の届け物から七日）の（　）の案内を出す。思い出の中を遊ぶ扱い。
- 操作する人：ベル＋オオナムチ（臨時の仲間はいったん外す。終わったら戻す）。途中で入れ替わる：
  - 六：オオナムチ一人（`split: 'away'`。ベルは宿に残る）。
  - 七：トマリ（なりかわり。下の「新しく要るもの」）。

  - 八の後半から元に戻り、ごほうびのあとに臨時の仲間も戻す。

## 新しく要るもの
- しくみ：sidestories.js の offer を「遊ぶ／読む／あとで」に。進み具合はフラグ `sq_ch04_5_1`〜`_11`、いまの目的（objectives.js）に各手順の1行。
- しくみ：なりかわり（新しい場面の命令 `standin { name, look }`／`standin { off: true }`）。仲間の記録はそのまま、歩くマップの先頭の見た目と名前だけ替え、後ろの仲間を描かず、敵を出さず、メニューは閉じる。ベル一人のときも同じ命令（look は `bell`）で、薄く揺らぐ描き方は今のまま効くようにする。

- 場面だけの人（npcs に `if`/`unless` で出す）：トマリ・イサナ（小舟）・アサギ・水夫2・帳場の男・宿の主人・行商人・亜人の子3（kid_ear／kid_tail＋角の子）・パン屋・若い冒険者4（`soldier` 以外の見た目）・白い兎。

## 気になる点
- 名の欠片：イサナ・アサギ・トマリは今「欠片を拾って返す」しくみの持ち主（names.js）。このクエストで名を呼ぶので、①終えたら3人の名を自動で返したことにする ②欠片は別に残す、のどちらか。
- 白兎：めったに出ない敵 `shirousagi`（因幡の白兎）が野原にいる。助ける兎と戦う兎が同じ野原に出るので、クエスト中は出さないか、敵の名前を変えるか。
- 話し手の名：名乗る前のイサナは「漁師」、宿の主人などは役名。名が出た場面からは名前にする案。
- 八の最後は5章の「聖の森」の依頼を受ける場面。5章より後に遊ぶので、思い出として流すだけ（依頼は増やさない）。
- 戦いが手合わせ1回だけ。野原の見回りで、野犬（`dog`）の決まった戦いを1回足すか（小説は「野犬は出なかった」）。

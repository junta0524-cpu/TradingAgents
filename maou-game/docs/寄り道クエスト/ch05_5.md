# 五・五　森の底の石

- 受け方：6〜9章とクリア後。聖の森の道 `hijiri_path` に南の端（地図から）入ったとき、「寄り道（五・五）を遊びますか？」と聞く（いまの offer は `kukunochi`。小説の始まりが森の出口なので、聖の森の道に移す案。ククノチは途中で通る）。「あとで」なら、入るたびに聞く。
  - 章の見出しと（五章の翌朝。森の出口から一刻ほど）の案内。思い出の中を遊ぶ扱い。
- 操作する人：ベル＋オオナムチ＋コノハ（臨時 `join`。手順1から手順8まで）。スクナは手順5で臨時 `join`、手順8で `leave`。
  - 二・七のコノハ視点の所は、`party` 命令で並べ替えてコノハを先頭にする（3人とも仲間にいるので記録は消えない）。終わったら元の順。
  - 六：ハニヤス（なりかわり `standin`。魔界の埴の里 `yomi_hani` へ場面の `goto` で行き、終わったら戻る）。
  - 手順8でコノハとスクナが別れ、そのあとはベル＋オオナムチ。終わりで臨時の仲間を元に戻す。

## 流れ
1. 場所 `hijiri_path`（南の端）／すること：入ると、後ろからコノハが駆けてくる。
   場面：小説の 一 全部（「森の出口から、一刻ほど歩いたころだった。」から「そのために、走ってきたんだから」まで）。最後に `join konoha`。背景 `forest_day`。
2. 場所 `hijiri_path`（東の岩陰の洞窟の口 (28,6) のそば。岩の上にシイ）／すること：シイに話す（コノハが先頭）。
   場面：二 全部（「地下道の入口は、苔に覆われた岩の割れ目だった。」から「黙って、ついてきた。」まで）。話し手：シイ、コノハ、オオナムチ。
3. 場所 `hijiri_cave` → `hijiri_deep`／すること：洞窟の奥の石段から地下道へ。並びを元に戻す。苔の広間を歩く（いつもの出会い：森蜘蛛・迷い火・絡み蔦・苔玉など、`hijiri_deep` の `encounter`）。下の長い通路の東で、白い糸と大蜘蛛を見ると場面。
   場面：三 の前半「地下道は、思っていたよりも、広かった。」から「前脚を振り上げた。」まで。
   戦い：`koke_ookumo`（耐える戦い。hook：オオナムチが堅めを唱えたら「――堅め」〜「破れなかった」の語りを差し込み、balance.js `SIDEQUEST.ch05_5.HOLD_ROUNDS`（3）ラウンドで `st.forceWin`。倒さない）。
   場面：三 の「下がりなさい」から「まるで、何か、大きなものの前で、身を縮めるように。」まで。
4. 場所 `hijiri_deep`／すること：卵の袋を調べる（堅めを覚えていること＝`knows: 'katame'`）→ 袋を持ったまま、西の枝分かれの細い通路（x=6 の縦の道）の奥を調べて置く。
   場面：三 の「その隙に、コノハが、糸を切った。」から最後「昨日と、同じ言葉だった。」まで（「――堅め」は袋を調べたとき）。
5. 場所 `hijiri_deep`（いちばん奥＝左上の小部屋 (2,1)。光の差す石碑）／すること：石碑を調べる。
   場面：四 全部（「地下道の、いちばん奥だった。」から「わしの声は、もう、遠くまで届かん」まで）。スクナが入口から現れ、`join sukuna`。
6. 場所 `hijiri_cave`（壁の根の穴から NEW `hijiri_uro` うろの家）／すること：うろの家に入り、奥のユズリハに話す。
   場面：五 全部（「うろの家は、森の奥の、倒れかけた古木の根もとにあった。」から「照れたように目を伏せた。」まで）。話し手：スクナ、ユズリハ（名を呼ばれる前は「老いたエルフ」）、オオナムチ。
7. 場所 `yomi_hani`（ハニヤスになりかわる。朝霧の色）／すること：うろの家を出ると場面が切り替わる。畦から坂を下り、クナドと避難民の列へ行く → 鴉族の女に話す → 鍬を渡す（調べる）。
   場面：六 全部（「埴の里の段々田に、朝の霧がかかっていた。」から「霧の雫を、受けていた。」まで）。話し手：ハニヤス、鴉族の女。終わったら `goto` で `hijiri_cave` へ戻り、なりかわりを解く。
8. 場所 `hijiri_path`（洞窟の口。シイはまだ岩の上）／すること：洞窟を出ると、コノハを先頭にしてシイに話す。
   場面：七 の前半「地下道を出たのは、昼を過ぎてからだった。」から「コノハは、聞こえないふりをした。」まで。終わったら `leave konoha`・`leave sukuna`（知らせは出さない）。
9. 場所 `kukunochi`（夜の色）／すること：地図を歩いてククノチへ。村の真ん中の大樹 (8,11) を調べる → 道の端の薬草摘みの娘に話す。
   場面：七 の後半「その夜、二人は、森の外れの村、ククノチに泊まった。」から最後「濃くなった気がした。」まで。話し手：オオナムチ、ツユクサ（名乗るまで「娘」）。
10. 場所 `yachimata` → `yachimata_inn`（大宿の二階の窓）／すること：地図を歩いてヤチマタへ。宿の窓を調べる。
    場面：八 全部（「宿場町ヤチマタは、昼も夜も」から最後「ゆっくりと飲み干した。」まで）。話し手：荷車の男（3つ）、オオナムチ、ベル。→ ごほうび。`side_read_side_ch05_5` も立てる。

## 気になる点
- 苔の大蜘蛛：`hijiri_deep` にはすでに番人の大蜘蛛（倒すと `gm:hijiri_deep:nushi`）がいる。クエストの大蜘蛛は「出口のあたりの別の蜘蛛」として下の通路に出す案（番人を先に倒していてもおかしくない）。番人を倒していないときだけ遊べる、にする案もある。
- 名の欠片：シイ・ユズリハ・ツユクサは欠片の持ち主で、立つ所が聖の森の集落（ツユクサも）。小説ではツユクサはククノチ。持ち主の場所を小説に合わせるか、このクエストで名を返したことにするか。
- ククノチの大樹は、頼みごと `kukunochi_ki`（大樹の声）の調べる所と同じ。クエストの間は場面を先にする。
- 受け方を聖の森の道へ移すか、いまのククノチのままにするか（ククノチだと、始まりの森の出口まで戻ることになる）。
- 六（ハニヤス）は魔界。6〜9章は魔界を歩けないので、場面の中だけで `goto`（地図の出入口は開かない）。

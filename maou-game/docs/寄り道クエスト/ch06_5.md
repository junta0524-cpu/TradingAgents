# 六・五　納めの鉄

- 受け方：7〜9章とクリア後（いまの offer と同じ `magane`）。鉱夫村マガネ `magane` に入ったとき、「寄り道（六・五）を遊びますか？」。「あとで」なら入るたびに聞く。
  - 章の見出しと（六章の霧の朝。炉ヶ岳の里を出て山道を下る）の案内。思い出の中を遊ぶ扱い。
- 操作する人：ベル＋オオナムチ（臨時の仲間は外す。終わったら戻す）。
  - 二：フジ（坑夫の母。なりかわり `standin`）。
  - 三の前半：ベル一人（なりかわり。オオナムチは寝ている人として部屋に置く）。
  - 四の坑道：二人のまま。ハガネ・スミは仲間に入れず、場面の人として先に立つ。岩喰らいとの戦いだけ、ベルは見守る（`split: 'watch'`。小説の「使えない」）。
  - 七の前半：ベル一人（なりかわり）。八で元に戻る。

## 流れ
1. 場所 `magane`（入口）／すること：入ると場面。
   場面：小説の 一 の「霧は、山道を下るほどに、濃くなった。」から「村に入ると、昼間なのに、人の姿が少なかった。」まで（背景 `road`→歩くマップ）。そのあと坑道の口の前の座り込んだ坑夫に話す。
   場面：一 の「坑道の口から、男たちが」から最後「その果てが、見えなかった。」まで。話し手：オオナムチ、坑夫。
2. 場所 `magane`（井戸。フジになりかわる）／すること：井戸端から、通りを歩く二人（場面だけの人）のところへ行って話す。
   場面：二 全部（「フジは、井戸端で、芋を洗う手を止めた。」から「フジは、それ以上、何も言えなかった。」まで）。話し手：フジ、オオナムチ（地の文の「細い子」）、カイの回想の一言は「カイ」。手紙は今ある大事なもの `magane_tegami` を `item` で渡す。
3. 場所 `magane_inn`（夜。ベル一人）／すること：窓を調べる → 寝ているオオナムチに話す。
   場面：三 の「その夜、ベルは、村はずれの宿の窓から」から「青年は、すぐに目を開けた。眠りの浅い子だ。」まで → 「子どもが一人、古い竪坑へ入っていった」「オオナムチは、跳ね起きた。」。言伝の声『タケルたちが、牢を破りました』はオモイカの名で出す。
4. 場所 `magane`（夜の色。竪坑の口 (11,2)。元の二人）／すること：宿を出て竪坑の口へ。男と女に話す。
   場面：三 の「外へ出ると、坑道の口の前に」から最後「案内しろ。行くぞ」まで。話し手は名乗るまで「男」「女」、名乗ってからハガネ・スミ。
   そのあと：竪坑の口がクエストの間だけ開き、古い坑道 `ro_mine` へ入る（下の「新しく要るもの」）。
5. 場所 `ro_mine`（暗い坑道）／すること：入ると「――火種」の場面（四 の「竪坑の中は、冷たかった。」から「つるはしの跡が、無数に刻まれていた。」まで）。手前の広間を北へ歩く（いつもの出会い：岩蜥蜴・火鼠など、`ro_mine` の `encounter`）。広間の奥のタタラに話す。
   場面：四 の「ハガネが先に立ち」から「岩喰らいだった。」まで（「タタラ」「タタラ！」はスミ）。
6. 場所 `ro_mine`／戦い：`iwakurai`（耐える戦い。ベルは見守る `split: 'watch'`）。戦いの前に `save`。
   場面（戦いの前）：四 の「下がれ」から「何かを、こらえるように。」まで。
   hook：オオナムチが堅めを唱えたら「膜が、広がった。」〜「(半分ずつ、包め)」の語りを差し込む。balance.js `SIDEQUEST.ch06_5.HOLD_ROUNDS`（3）ラウンドで `st.forceWin`。
   場面（戦いのあと）：四 の「岩喰らいが、一歩、前に出た。」から「(焼くんじゃない)…作り直す力でもある。」まで。
7. 場所 `ro_mine`（広間）／すること：広間の壁の古い燭台3つを火種で灯す（今ある `torch` のしかけ。クエスト用の燭台）。3つ灯すと場面。
   場面：四 の「坑道が、明るくなった。」から最後「その声も、少し、震えていた気がした。」まで。終わったら `split: null`。
8. 場所 `magane`（夜明けの色。竪坑の口）／すること：坑道を出ると人だかりの場面。
   場面：五 全部（「夜明けの村に、四人が戻ると」から「ほんの少しだけ、ほどけたように見えた。」まで）。話し手：頭、オオナムチ、坑夫（3人。名前なし）、ハガネ、スミ、タタラ、ベル。
9. 場所 `yachimata`（大宿の裏庭）／すること：地図を歩いてヤチマタへ。大宿の裏で薪を割るカイに話す（手紙を渡すと `magane_tegami` が消える）。
   場面：六 全部（「宿場町ヤチマタは、街道が八方へ分かれる辻に」から「薪を割る音が、また、聞こえはじめていた。」まで）。手紙の文はカイが読む声として出す（`letter` の窓は使わない）。
10. 場所 `yachimata`（夜。安宿の裏庭の井戸。ベル一人）／すること：井戸のそばで空に手をかざす（調べる）。
    場面：七 全部（「その夜、ヤチマタの安宿の裏庭で」から「温かさが下りていった。」まで）。オモイカは言伝の声。途中「背後で、足音がした。」から元の二人に戻し、オオナムチが湯呑みを持って来る。
11. 場所 `minamo_guild`／すること：ミナモへ歩いて戻り、ギルドの掲示板を調べる。
    場面：八 全部（「ミナモに戻ったのは、それから三日後の朝だった。」から最後「二人を待っていた。」まで）。受付の女の「次の方」「獣ノ原ですか。物好きね」。→ ごほうび。`side_read_side_ch06_5` も立てる。

## 気になる点
- 頼みごと `magane_fumi`（母の手紙）と中身が重なる。頼みのセリフ（「冬には帰る」など）は小説と違い、ヤチマタの若者 `yachimata_inn_youth` は「三年」（小説は二年）。①このクエストに置き換えて頼みを消す ②頼みは残し、クエストを終えたら済んだことにする。
- 岩喰らい：`ro_mine` には番人の岩喰らい（倒すと牙）がいる。クエストの岩喰らいは広間の「岩の山」で、奥へ帰るだけ。番人とは別の獣として扱う案。
- 竪坑の場所：小説はマガネの村はずれ、ゲームの古い坑道は炉ヶ岳の山道の脇。マガネから同じ坑道へつなぐ案にした（新しいマップを作らない）。新しく小さな竪坑のマップを作る案もある。
- 名の欠片：ハガネ・スミ・タタラの持ち主は今、炉ヶ岳の里に立つ。小説ではマガネの人。
- 八は7章の始まり（獣ノ原の依頼）と同じ場面。思い出として流すだけ。
- フジの場面はなりかわりにしたが、短いので場面だけにする案もある。

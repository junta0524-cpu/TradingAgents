   場面：小説の 一 の「夜明け前の葛の里は」から「ずっと、そう思っていた。」まで（ノギク・タネ爺・フキのセリフは、それぞれに話したときに出してもよい）。品：ノギクの布・タネ爺の豆を `item` で受け取る。
   すること：井戸のナズナ・見張り台のススキ・織り場の窓（クズハ）の前を通って門へ。門の外へ出ようとすると場面。
   場面：一 の「ナズナさん」から最後「日が昇る前に、溝の入口まで」まで。「来るよ、フキ」はオオナムチ（気になる点）。
2. 場所 `kuzu_village`（井戸。ナズナになりかわる）／すること：三人が出たあと場面が切り替わる。井戸の桶を調べて下ろし、引き上げた水をのぞく。
   場面：二 の「ナズナは、井戸の縁に、座ったままでいた。」から「桶を、井戸に下ろした。」まで → 調べる → 「縄が、するすると」から最後「互いの顔を、見ていた。」まで。終わったら並びを元に（オオナムチが先頭）、なりかわりを解く。

   すること：風に流される床を進む（今のしかけのまま。歩くことが下りの描写の代わり）。溝の半ば（東の縦の風の下 (20〜22, 10)）へ着くと場面。
   場面：三 の「溝の半ばまで来たときだった。」から「(半分ずつ、包む)」まで。

- 頼みごと `iwakura_ido`（古井戸の底）が、鈴を井戸から拾う話で重なる（頼みは庭番の祖父の鈴、小説は衛士の祖父の形見で孫が落とした鈴）。①このクエストに置き換えて頼みを消す ②頼みの話を小説に合わせて直す。
- 「来るよ、フキ」の話し手が書かれていない。前後からオオナムチと見たが、ウズメの可能性もある。
- 名の欠片の見た目が小説と違う：ナズナの持ち主が子ども（`kid_tail`。小説は老婆）、ススキが `beastwoman`（小説は若い男）、クズハが `beastwoman`（小説は人間の里から嫁いだ女）。クズハの欠片は `kemono_ravine` (1,9) に落ちている。

- 鈴を拾う所は小説では語られるだけ。遊ぶ手順にするか、場面だけで済ませるか。

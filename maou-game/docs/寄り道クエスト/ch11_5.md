- 受け方：クリア後（`chapter: 13`）。土蜘蛛族の畑 `yomi_hani` に入ったとき「寄り道（四天王編）を遊びますか？」と聞く（いまの sidestories.js の offer と同じ場所・条件。「遊ぶ／読む／あとで」に替える）。「あとで」のときは、畑のいちばん上の段の畝 (5,2) を調べるともう一度聞く。
  - 11章の中では遊ばせない（同じ日々を四天王の目から描く章なので、11章の修行・収穫祭と二重になる。12章へ進むと魔界に戻れない）。
  - 始まりに見出し「四天王編　土と角と牙と羽」と（十一章の修行の日々。四天王の目から）の案内。
- 操作する人：場面ごとに四天王とオモイカに替わる（いまの仲間・名前・場所・道具袋は始めに預け、終わりに戻す）。
  - 一・二：ハニヤス一人（`sq_haniyasu`、1.5章と共通）。三：スサノ一人（`sq_susano`）。四：ナキメ一人（NEW `sq_nakime`）。五・六：ミカヅチ一人（`sq_mikazuchi`）。七：オモイカ一人（NEW `sq_omoika`。戦いなし）。

## 流れ
1. 場所 `yomi_hani`（夜明け前の靄の色）／すること：ハニヤスで畦を上り、いちばん上の段の畑番の娘（NEW の人、look `tsuchi`）を調べる（話しても答えない）。
   場面：一 の「ハニヤスは、夜明けより先に、畑へ出た。」から「ハニヤスは、しばらく、それを見ていた。」まで（入ったときと、娘を調べたときに分ける。名を呼ばれなくなったいきさつの段落は語りで残す）。
2. 場所 `yomi_hani`（畑の下の客の小屋の戸＝spot）／すること：坂を下りて小屋の戸を調べる。
   場面：一 の「それから、坂を下りた。」から一 の最後「起きたか、客人」まで。このあとの土への挨拶は本編11章の 一（流さない。二の頭の「土への挨拶は、済ませた。」で受ける）。
3. 場所 `yomi_hani`（日の高い色。畝の端にオオナムチ）／すること：畦の上の印に立つと、オオナムチが娘の隣へ行く場面（背景 `fields`、人：オオナムチ・娘・ハニヤス）。
   場面：二 の「日が高くなるころ」から「人は、呼ばれなければ、忘れられていく。」まで。名が出るまでの話し手は「畑番の娘」、「……アカネ」から「アカネ」。
   すること：ハニヤスで娘に話す → 「アカネ」から「少しだけ、くっきりと見えた。」まで（ハニヤスが自分で名を呼ぶ所を、遊ぶ人の手で）→ 握り飯の場面「朝のうちに、畦に並んで」から二 の最後「少しだけ、高く見えた。」まで。
4. 場所 `arashigamine`（演武場の岩。岩の下に耳の聞こえない嵐狼の子）／すること：スサノで岩を降り、子に話す。
   場面：三 の「嵐ヶ峰の風は、冷たかった。」から「演武場の入口を、じっと見張りはじめた。」まで（手話は ( ) で、話し手「嵐狼の子」「スサノ」）→ 岩へ戻ると「スサノは、その小さな背中を」から「それを、見てみたかった。」まで（妹と掟の段落は語りで残す。この人の大事な所）。
5. 場所 `yomi_sanctum` → `yomi_palace` → `yomi_market` → `arashigamine` の入口の坂（ナキメに替わる。後ろに11章のオオナムチの見た目）／すること：聖域から嵐ヶ峰まで歩く。坂の途中の岩の伝令の娘（NEW の人、look `crow`）の前を通ると場面。
   場面：四 の「聖域から嵐ヶ峰へ向かう道を」から「入口に触れた者は、皆、そう言います」まで（聖域を出るとき）→ 坂で「峰へ上る坂の途中で」から「言霊への、耐えです」〜「合格です」「ええ。洗脳の言葉には、呼吸があります。…」まで → 三歩進んだ印で「ナキメは、歩き出した。三歩、進んで、止まった。」から四 の最後「翼の付け根が、熱かった。」まで。名が出るまでの話し手は「伝令」、ナキメの心の中だけ「(クロハ)」。

## 気になる点
- 名の欠片：アカネ・クロハ・ヤマブキは names.js の欠片の持ち主（11章から）。このクエストで名を呼ばれるのはアカネだけ（クロハ・ヤマブキは、まだ呼べない、で終わる）。①アカネだけ欠片を返したことにする ②三人とも欠片はそのまま、のどちらか。
- 六の手合わせの相手はオオナムチ本人。遊ぶ人がオオナムチを打つことになるので、ハニヤス・スサノの「見る」気持ちに合うよう、負けない・倒しきれない手合わせにした。
- 一・二の「客人」と、本編11章の始まり（土への挨拶）が同じ朝。二は挨拶のあとから始めるので、挨拶の場面は流さない。
- 七の鬼の女の話し手名（「鬼の女」のまま）でよいか。六ではミカヅチが王に「ヤマブキに、研がせました」と名を言う（小説どおり）。
- 遊ぶ順を「三の前半→四→三の後半」に変えた。小説の順のまま（三全部→四）にする案もある。

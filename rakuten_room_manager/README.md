# 楽天ROOM運用管理ツール

楽天ROOMの運用を効率化するためのローカルWebアプリケーション（Streamlit製）です。

楽天の利用規約（自動投稿・スクレイピングの禁止）を遵守するため、本ツールは
**楽天公式APIを利用した商品情報の取得・管理** と **紹介文ドラフトの生成補助** に機能を限定しています。
楽天ROOMへの自動投稿や、楽天サイトのスクレイピングは一切行いません。

## 主な機能

1. **商品検索**: 楽天商品検索APIでキーワード検索し、商品情報をSQLiteに保存
2. **商品管理**: 投稿ステータス（未投稿/投稿済）、オリジナル写真の有無、メモを一覧編集
3. **紹介文AIジェネレーター**: 商品情報＋自分の感想から「AIに渡す指示文」を作成。Claude.aiやChatGPT（無料枠でも可）に手動でコピー&ペーストして紹介文を作ってもらい、結果をアプリに貼り戻して保存する方式のため、追加のAPI利用料は一切かかりません
4. **ランク維持トラッカー**: 今月のオリジナル写真投稿・いいね/フォロー活動をチェックボックスで記録

## セットアップ

```bash
cd rakuten_room_manager
pip install -r requirements.txt
```

楽天アプリケーションIDは以下のいずれかの方法で設定できます。

- **アプリ内の「⚙️ 設定」画面から入力する（推奨）** — SQLiteに保存され次回起動時も保持されます
- `.env.example` を `.env` にコピーして環境変数として設定する

## 起動方法

```bash
streamlit run app.py
```

ブラウザで `http://localhost:8501` が開きます。

## 必要なAPIキー

| 用途 | 取得先 |
| --- | --- |
| 楽天アプリケーションID | https://webservice.rakuten.co.jp/ |

紹介文生成にAPIキーは不要です（Claude.ai / ChatGPTなどに手動でコピー&ペーストして使う方式）。

## 注意事項

- 生成された紹介文は必ず内容を確認したうえで、手動で楽天ROOMに投稿してください。
- 本ツールはデータの取得・管理・下書き生成の補助のみを行い、投稿の自動化は行いません。

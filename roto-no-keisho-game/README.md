# ロトの継承 ― RPG(全16章版)

『ロトの継承』の設定資料一式(シナリオ資料集・群像譜・魔物図鑑・宝物庫・地誌譜)を土台にした、ブラウザで動くRPGです。ビルド不要・依存ライブラリなしの素のHTML/CSS/JavaScriptで実装しています。シナリオ資料集と同じボリューム――**序章+全14章+終章の16章、全13ロケーション、モンスター全60種、パーティ4人**――をそのままゲームに組み込んでいます。

## 遊び方

このフォルダ内で簡易サーバーを立てて `index.html` を開いてください(`file://` 直開きよりローカルサーバー経由を推奨します)。

```bash
cd roto-no-keisho-game
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

操作:矢印キー / WASD で移動、Z または Enter で決定・メニュー開閉、X または Esc でキャンセル。

**スマホ・タブレット**では、画面下に十字キーと「けってい / もどる」ボタンが自動で出ます(指で操作する端末を検出したときだけ表示され、マウス環境には出ません)。画面幅に合わせてゲーム画面も縮みます。

## 実装した範囲

- **全16章のシナリオ進行**(序章 → 第一〜十四章 → 終章)。章ごとにダイアログ・移動先マップ・完了条件(門への到達 or ボス撃破)が定義されており、自動で次の章へつながる
- **全13ロケーション**(街5・フィールド3・ダンジョン5)。フィールドは街道パターン、ダンジョンは接続保証済みの蛇腹通路、街は安全な広場としてジェネレータで生成
- **モンスター全60種**(雑魚54種+ボス5体、種族ごとに階層値からステータスを算出)。ロケーションごとの出現テーブルも自動生成
- **パーティ4人**(ロト・エルロード・セレスティア・ガライ)。シナリオの節目で自動的に仲間になり、戦闘は全員ぶん順番にコマンドを選ぶ方式
- コマンド式戦闘(たたかう/じゅもん/どうぐ/にげる)、ボスの全体攻撃技、道具のアリーターゲット選択(誰に使うか選べる)、受け流しによる防御
- **街の施設**:道具屋(道)・武器防具屋(武)・宿屋(宿)・教会(教)。街のタイルを踏むと開き、品揃えは街ごとに異なる
- **街の人々との会話**:王(王)と町人(紫)に話しかけられます。台詞は**章ごとに変わり**、同じ人物でも建国前と百年後では違うことを言います。ラダトーム王との謁見は、王位を辞して旅立つまでの一場面として進みます。まだ仲間になっていない人物は、その街には居ないものとして扱われます
- **装備システム**:武器/よろい/たて/かぶと/そうしょくひんの5部位。装備がこうげき・しゅび・すばやさに直接反映され、キャラごとに装備できる種別が決まっている(杖使いは盾を持てない等)
- パーティメニューからの装備の付け替え、DQ的な温情リスポーン(全滅してもHPが少し残った状態で継続)
- **セーブ/ロード**:パーティメニューから「ぼうけんのしょに きろくする」で保存。章の節目では自動保存も入る。タイトル画面に「つづきから」と進行状況が出る(保存先はブラウザの localStorage)
- **状態異常**:どく・ねむり・こんらんの3種。魔物図鑑で「毒を撒く」「眠りの種」などと書かれている13種の魔物が実際に仕掛けてくる
  - **どく** ― ラウンド終了ごとにダメージ。戦闘後も残り、8歩ごとに体力を削る(歩いて死なないよう HP1 で止まる)
  - **ねむり** ― 手番を飛ばされる。毎ターン一定確率で目を覚ます
  - **こんらん** ― 対象を選べず、敵味方かまわず殴る
  - 治療は どくけし草(毒)/ めざめの葉(眠り・混乱)/ せいすい(すべて)。加護の護符は次の1回だけ状態異常を防ぐ。宿屋・教会・章の休息でも回復する

## フォルダ構成

```
index.html              エントリーポイント(canvas + script読み込み)
css/style.css           最小限のページスタイル
js/data/                 設定資料から落とし込んだゲームデータ
  characters.js          群像譜・宝物庫 → プレイアブル4人のステータス・スキル・装備
  monsters.js             魔物図鑑 → 全60種の敵データ・出現テーブル・ボス
  items.js                 宝物庫 → 消耗品(全9種)
  equipment.js              宝物庫 → 武器・防具・装飾品
  shops.js                   街ごとの品揃えと宿代・蘇生費用
  npcs.js                     王・重臣・町人の会話(章ごとに差し替わる)
  maps.js                     地誌譜 → 全13ロケーションのタイルマップ生成
  chapters.js                  シナリオ資料集 → 全16章の進行データ
js/engine/                汎用エンジン部分(ゲーム固有ロジックを含まない)
  input.js                 キー入力管理(仮想ボタンからの入力もここへ流す)
  touch.js                  スマホ用の仮想パッド(DOM とスタイルを自前で組み立てる)
  renderer.js              タイル・パネル・文字・ゲージの描画部品
  game.js                   モード切替(タイトル/フィールド/戦闘/エンディング)とメインループ
js/systems/                ゲーム固有システム
  party.js                  パーティの実行時ステータス管理・仲間加入
  dialogue.js                メッセージウィンドウ
  battle.js                   パーティ全員ぶんのコマンド式バトルシステム
  field.js                     フィールド移動・エンカウント・門/ボス床/施設/NPC判定
  menu.js                       パーティメニュー(状態確認・装備の付け替え)
  shop.js                        道具屋・武器防具屋・宿屋・教会
  save.js                         ぼうけんのしょ(localStorage への保存・復元)
  story.js                         全16章の章・ステージ進行管理
js/main.js                起動処理
```

データはすべて `Game.Data.*` に集約しているので、内容を調整する際は `js/data/` 配下のオブジェクトを編集するだけで反映されます。

## プレースホルダーの範囲(後から差し替え可能)

キャラクター絵・マップのタイル絵・BGMは、いずれも今回の実装では「後から組み込む」ことを前提にした最小限のプレースホルダーです。

- **フィールド/街/ダンジョン**:現在は色面(緑=草原、茶=街道、灰=ダンジョン床、など)で描画しています。「地誌譜」の画像生成プロンプトで作ったタイル絵に差し替える場合は `js/engine/renderer.js` の `drawMap()` を画像描画に置き換えるだけで反映されます。マップの形状自体(`js/data/maps.js`)はそのまま使えます。
- **キャラクター**:戦闘・フィールドともに色付きの丸/パネルで表現しています。「群像譜」の立ち絵をスプライトとして描画する場合も、`renderer.js` の描画部分を差し替えるだけで済む構造です。
- **音楽**:効果音・BGMの再生は未実装です。「楽団譜」で用意したSUNO生成曲を音声ファイル化したら、`Game.Core` のモード切替(タイトル/フィールド/戦闘)のタイミングで `Audio` 要素を鳴らす処理を足すだけで組み込めます。

## テストについて

Playwright(Chromiumヘッドレス)で、タイトル→全16章→エンディングまでを自動移動・自動戦闘で通しプレイする検証を行っています。検証中に発見した「メッセージウィンドウを閉じた同じフレームの決定キー入力が、メニュー開閉やコマンド選択に二重に使われてしまう」というタイミングバグは修正済みです。

## 今後の拡張候補

### 章の分岐選択(アイデア段階・未実装)

現在は全16章とも一本道ですが、シナリオ資料集には分岐が想定されている場面がいくつかあります。実装するなら以下が候補です。

| 章 | 分岐 | 結果の差 |
|---|---|---|
| 第五章 | ガロズを **討伐する / 投降を受け入れる** | 投降ならガライとして後に加入、討伐なら第十章の反乱の展開が変わる |
| 第九章 | バロウズを **疑う / 善意の聖職者として受け入れる** | 終章までの伏線の見え方(プレイヤーがどこまで真相に近づけるか)が変化 |
| 第十章 | ガライを **信じる / 貴族の要求を飲んで退ける** | 退けた場合はガライが仲間にならず、パーティが3人のまま |
| 第十一章 | ヴァンスを **力づくで止める / 説得を試みる** | 終章での彼の描かれ方が変わる |

実装の要点:
- `js/data/chapters.js` の stage に `choices: [{label, next}]` を持たせ、`Game.Story` に選択待ちの view を足す
- 選んだ結果を `Game.Story` のフラグとして保持し、`Game.Save` の `story` に含めて保存する
- 分岐によって `onComplete.recruit` の有無が変わるため、パーティ人数に依存するボス調整(`js/data/monsters.js` のコメント参照)を見直す必要がある

# ロトの継承 ― RPGプロトタイプ

『ロトの継承』の設定資料(シナリオ資料集・群像譜・魔物図鑑・宝物庫・地誌譜)を土台にした、ブラウザで動く基盤RPGエンジンです。ビルド不要・依存ライブラリなしの素のHTML/CSS/JavaScriptで実装しています。

## 遊び方

このフォルダ内で簡易サーバーを立てて `index.html` を開いてください(ES機能は使っていませんが、ブラウザのセキュリティ制限を避けるため `file://` 直開きよりローカルサーバー経由を推奨します)。

```bash
cd roto-no-keisho-game
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

操作:矢印キー / WASD で移動、Z または Enter で決定・メニュー開閉、X または Esc でキャンセル。

## 今回実装した範囲

- タイトル画面 → フィールド探索 → ランダムエンカウント → コマンド式戦闘(たたかう/じゅもん/どうぐ/にげる)→ 経験値・ゴールド獲得 → フィールド復帰、のひとつながりの流れ
- パーティステータスの確認メニュー
- ゲームオーバー時のDQ的な温情リスポーン(街道入口でHPが少し残った状態から再開)

舞台は「地誌譜」の**東方街道**、戦闘は「魔物図鑑」の序盤モンスター(ちびスライム、あかスライム、野良ゴブリンなど)を使用しています。

## フォルダ構成

```
index.html              エントリーポイント(canvas + script読み込み)
css/style.css           最小限のページスタイル
js/data/                 設定資料から落とし込んだゲームデータ
  characters.js          群像譜 → プレイアブルキャラのステータス・スキル
  monsters.js             魔物図鑑 → 敵データと出現テーブル
  items.js                 宝物庫 → 消耗品
  maps.js                   地誌譜 → タイルマップ(東方街道)
js/engine/                汎用エンジン部分(ゲーム固有ロジックを含まない)
  input.js                 キー入力管理
  renderer.js              タイル・パネル・文字・ゲージの描画部品
  game.js                   シーン切り替えとメインループ
js/systems/                ゲーム固有システム
  party.js                  パーティの実行時ステータス管理
  dialogue.js                メッセージウィンドウ
  battle.js                   コマンド式バトルシステム
  field.js                     フィールド移動・エンカウント判定
  menu.js                       パーティ確認メニュー
js/main.js                起動処理
```

データはすべて `Game.Data.*` に集約しているので、新しい章のフィールド・モンスター・アイテムを追加する際は `js/data/` 配下にオブジェクトを足すだけで拡張できます。

# 画素譜 ― 画像素材のプロンプト生成

ゲームに要る画像素材110点ぶんの生成プロンプトを組み立て、「画素譜」のページを書き出す道具です。

```bash
python3 build_gaso.py   # monsters.json → prompts.json / sections.json
python3 build_page.py   # prompts.json  → gaso-fu.html
python3 process_art.py  # 受け取った画像をマゼンタ抜き＋リサイズして assets/ へ
```

## 目指している絵柄

スーパーファミコン期(1990年代前半)のドラゴンクエストのドット絵です。
「ドット絵風のイラスト」に倒れないよう、共通ルールを全プロンプトに埋め込んでいます。

- 1ドットが四角くはっきりしていて、粒の大きさが揃っている。にじみ・ぼかし・グラデーションなし
- ひとつの素材に色は3つまで(基本色・影色・明色)。画像全体で12〜16色
- 人物は**2頭身**。首は描かず、手足は太さ2〜3ドット、指は描かない。胴は太く、肩幅は頭とほぼ同じ
- **髪(かぶり物)は顔の左右へ1〜3ドット張り出す塊**。この輪郭だけで誰か分かるようにする
- 目は**幅1ドット×高さ2ドットの縦長**をふたつ。あいだに明るい肌色を1〜2ドット。
  白目・瞳孔・まつげ・眉・鼻は描かない。位置は「見えている顔」の縦のまんなか
- **骨格は左右対称、崩すのは持ち物とそれを持つ腕だけ**。長い得物は必ず左右どちらかへ寄せる
- 32ドットで潰れる細部(刀傷、片眼鏡、紋章、布の皺)は最初から描かない。
  残すのは**シルエット・髪の色・服の色・持ち物の形**の4つ

この4つで人物を見分けられるように、`CHARS` / `NPCS` の外見記述もそこまで絞ってあります。
魔物とボスは96/160ドットあるので、専用の `FOE_BODY` / `STYLE_FACE_FOE` / `STYLE_OMIT_FOE`
で色数を5〜7色まで許し、牙・角・触手のようにシルエットとして効く出っ張りは残します。

## 枠の寸法 ― ここを間違えると絵柄が崩れる

**立ち絵と歩行シートは 32×48ドット**で描いてもらいます。ゲームの枠がその寸法だからです
(`js/engine/assets.js` の `SPRITE_W=32, SPRITE_H=48`、描画は `renderer.js` の `drawSprite`)。
人物は枠の**下から30〜34ドット**に収め、上は余白のまま残してもらいます。

以前は 32×32 で頼み、`process_art.py` が余白を切り落として縦を48に引き伸ばしていました。
これだと 2頭身で描いてもらっても**縦1.5倍に伸びて3頭身になり、縮小の倍率が半端になって
ドットの格子まで壊れます**(`assets/chars/rota.png` がその状態のまま残っています)。
いまは枠ごと整数倍で落とすので、1ドットがちょうど1ピクセルに乗ります。

歩行シートは3コマ横並びで **96×48ドット**。1コマぶんの縦横比が 2:3 でないと、
`drawSprite` が `img.width/frames` で切り出して 32×48 に描くときに歪みます。

## 背景 ― 320×240 で描いて、2倍に伸ばす

届いた5枚(タイトル・断崖・地下・洞窟・渦)は、いずれも**320×240ドット**で描かれていました。
キャンバスは 640×480 なので、**320×240 まで落としてから NEAREST で2倍**に伸ばせば、
1ドットがちょうど2×2ピクセルに乗り、格子が一切崩れません。
1200→640 のような半端な縮小をすると、そこでドット絵が溶けます。

どの場所でどの背景を敷くかは `js/engine/assets.js` の `BG_FOR_MAP`。
載っていない場所は、いままでどおり無地の色面に落ちます。

| 背景 | 使う場所 |
|---|---|
| `battle_field` | 東方街道・蒼穹平原 ―― **未着** |
| `battle_cliff` | 断崖の道 |
| `battle_dungeon` | はぐれオーガの野営地・学院地下祭壇 |
| `battle_cave` | 業の底 |
| `battle_ritual` | 蒼穹の塔・禁呪暴走空間 |
| `title` | タイトル画面 |

## まだゲームが読めない素材

- **魔物54種・ボス5体** ―― 戦闘画面に敵の絵を描く処理がまだありません
  (いまは金色の丸で代用)。背景は入ったので、次はここです
- **開封後の宝箱** ―― 開けた宝箱は `story.js` の `openedChests` に記録されるだけで、
  マップの文字は `'T'` のまま。仕掛け(`'L'`→`'l'`)と同じ書き換えを入れれば描けます

## 背景マゼンタ

生成時の背景は透過ではなく `#FF00FF` のベタ塗りにしてもらい、`process_art.py` で抜きます。
被写体にこの色を使わないことがプロンプト側の絶対条件です。

## 歩行シート

左右は絵を反転して使うので、向きは 前 / 後ろ / 横 の3枚。1枚に3コマ(左足・立ち・右足)。
各コマ32×48ドットの枠で、人物は下から32ドットぶん。向きごとに顔の指示を分けています
(後ろ向きは目を描かない、横向きは目の点ひとつ)。
